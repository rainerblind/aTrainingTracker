# Google Play Store Presence - Japanese

**App Title**: aTrainingTracker: バイク＆スポーツ (26/30)

**Short Description**:
ANT+、BLE、.FIT、Strava対応、プライバシー重視のスマートサイクルコンピューター。 (48/80)

**Full Description**:
<b>aTrainingTracker – スマートフォンのためのインテリジェントなスポーツトラッカー</b>

トレーニングに集中しましょう。テクノロジーは aTrainingTracker に任せてください。

aTrainingTracker は、Android スマートフォンを高精度でプライバシー重視の本格派サイクルコンピューター＆マルチスポーツトラッカーに変えます。高度なテレメトリ、自動化、データ主権を求めるサイクリストやランナーのために開発されました。強制的なクラウドやアカウント登録は不要で、100% 広告なしで動作します。

<b>インテリジェントなセンサー管理＆ハードウェア調停</b>
複数の Bluetooth® LE および ANT+® センサー（心拍数、ケイデンス、スピード、パワーメーター、温度計）を同時に接続可能です。
• <b>ハードウェア優先</b>：ミリ単位の精度を実現するため、専用ホイールスピードセンサーが GPS よりも自動的に優先されます。
• <b>シームレスなフェイルオーバー</b>：万が一センサーの接続が切れても、即座に GPS が引き継ぎデータを途切れさせません。
• <b>デュアルプロトコルの信頼性</b>：最新の BLE センサーと ANT+ 機器を干渉なく共存接続できます。

<b>高度なスポーツサイエンス＆運動生理学</b>
専用デスクトップソフトに匹敵する高度な分析を手元のスマホで実現：
• <b>Coggan パワー分析</b>：ノーマライズドパワー (NP)、強度係数 (IF)、トレーニングストレススコア (TSS)、変動指標 (VI)。
• <b>Skiba W' バランス</b>：2ポイント Critical Power (CP/W') モデルによる無酸素バッテリー残量のリアルタイム表示。
• <b>長期パフォーマンス管理 (PMC)</b>：フィットネス (CTL)、疲労 (ATL)、フォーム (TSB)、ACWR の時系列トラッキング。
• <b>有酸素効率</b>：効率係数 (EF) および有酸素デカップリング (Pw:Hr %) のリアルタイムモニタリング。

<b>ナビゲーション・お気に入りルート・ライブセグメント</b>
• <b>ルート自動認識 (Lieblingsstrecken)</b>：頻繁に走るコースを自動検出・命名し、自己ベストタイムと比較。
• <b>Strava ライブセグメント＆クライム</b>：自己ベスト (PR) や KOM とのタイム差を高低図とともにリアルタイム表示。
• <b>ルート案内</b>：GPX ファイルや Strava ルートを読み込み、鮮明なマップ上でナビゲーション。
• <b>気圧高度補正</b>：登録済みの基準地点による高精度な気圧高度自動キャリブレーション。
• <b>電子ベル機能</b>：ハンドルバーからワンタップで鳴らせる電子バイクベルを搭載。

<b>Periods 2.0＆複数年アクティビティ分析</b>
• <b>年間コントリビューショングリッド</b>：GitHub スタイルの草マップでスポーツごとの練習の継続性を可視化。
• <b>Jetpack Compose UI</b>：省電力な AMOLED ダークモードを備えた最新の Material 3 デザイン。

<b>完全なデータ主権＆3大クラウド連携</b>
データはあなたのものです。すべてのワークアウトは端末内のローカル SQLite データベースに安全に保存されます。
• <b>ネイティブ .FIT 対応</b>：業界標準の FIT ファイルのインポート／エクスポートに加え、TCX、GPX、CSV を完全サポート。
• <b>選べるクラウドバックアップ</b>：Google Drive（Google ドライブ）、Dropbox、Strava への自動アップロードに対応。
• <b>100% 広告なし＆高いプライバシー</b>：アカウント登録不要、第三者トラッカーなし。
