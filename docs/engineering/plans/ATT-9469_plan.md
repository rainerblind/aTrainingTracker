## 1. SWE.2 Architectural Decomposition & Concurrency Model

- **Single Pure-JVM Domain Component (`PhoneCarriageClassifier.kt`, `1,175 -> ~1,225 / 1,500` LoC)**:
  - All methods remain `@Synchronized` with zero Android framework or I/O dependencies, preserving pure-JVM offline replay (`OfflineTelemetryReplayHarness`) and `ArchitectureConformanceContractTest` compliance.
  - **Single-Pass Evaluation (`RawEvaluation`)**: Change private `evaluateRawCandidate(nowMs): PhoneCarriageMode` to `evaluateRawCandidate(nowMs): RawEvaluation(val mode: PhoneCarriageMode, val unambiguousMotionExit: Boolean)` so `quietImu`, `wheelActiveMoving`, `effectiveSpeed`, `gnssFresh`, `poorGnssAccuracy`, and `isPositionStagnant(nowMs)` are computed once per `classify()` call with zero duplicate window scans.
  - **Accuracy Validation, Buffer Gating & Monotonicity (`REQ-FIL-042.3`, `REQ-FIL-043.3`)**:
    - Define `private fun isAccuracyTrusted(acc: Double?): Boolean = acc == null || (acc.isFinite() && acc > 0.0 && acc <= STATIONARY_FAST_EXIT_MAX_GNSS_ACCURACY_M)` (`20.0 m`). Omitted `null` remains compatible with speed-only callers & `triggerDecayTick`, while `Double.NaN`, `±Infinity`, `0.0` (Android unknown-accuracy sentinel), `< 0.0`, and `> 20.0` are rejected.
    - Add `private var lastGnssAccuracyMeters: Double? = null` (cleared in `reset()`). Under `isNewerOrEqualGnss && speedMps.isFinite() && speedMps >= 0.0`, persist raw `lastGnssAccuracyMeters = accuracyMeters` (NEVER collapse invalid non-null accuracy to `null`).
    - Gate `positionSamples.addLast(...)` in `ingestGnssSpeed()` on `isAccuracyTrusted(accuracyMeters)` (matching `SpeedAndLocationDevice_ATTFused.kt:501` & `OfflineTelemetryReplayHarness.kt:495`) so coarse/invalid coordinate jumps never poison `isPositionStagnant(nowMs)`.
    - Add `poorGnssAccuracy = gnssFresh && !isAccuracyTrusted(lastGnssAccuracyMeters)` to the `quietImu` stationary guard (`!wheelActiveMoving && (hasOrientation || hasGyro) && quietImu && (effectiveSpeed <= 1.8 || isPositionStagnant(nowMs) || poorGnssAccuracy) -> STATIONARY`).
  - **Continuous Non-Stationary Dwell, `UNKNOWN`-Gap Reset & Fast Exit (`REQ-FIL-043.1`, `REQ-FIL-043.2`)**:
    - Add `private var nonStationarySinceMs: Long = Long.MIN_VALUE` (cleared in `reset()`, on `rawCandidate == PhoneCarriageMode.UNKNOWN`, on `rawCandidate == committedMode`, on `0 ms` wrist glance, and upon exiting `STATIONARY`).
    - Define `hasConfirmedDisplacement(nowMs)`: guards `positionSamples.size >= 2` and `(nowMs - last.timestampMs) <= STALENESS_MS`, then checks max Euclidean spread `>= 10.0 m` from `positionSamples.peekFirst()` (all buffered samples are already `isAccuracyTrusted`). Empty/stale `positionSamples` returns `false`.
    - Define `unambiguousMotionExit = wheelActiveMoving || (effectiveSpeed != null && effectiveSpeed >= 3.2 && gnssFresh && isAccuracyTrusted(lastGnssAccuracyMeters) && !isPositionStagnant(nowMs) && (!quietImu || hasConfirmedDisplacement(nowMs)))`.
    - In `classify(nowMs)`:
      - If `rawCandidate == PhoneCarriageMode.UNKNOWN`: set `nonStationarySinceMs = Long.MIN_VALUE` and return `committedMode`.
      - When `committedMode == PhoneCarriageMode.STATIONARY` (and `rawCandidate != STATIONARY && rawCandidate != UNKNOWN`): seed `nonStationarySinceMs = effectiveNowMs` if `Long.MIN_VALUE` (NEVER reset when `rawCandidate` flips among non-stationary subclasses!), compute `exitDwellMs = if (rawEval.unambiguousMotionExit) minOf(dismountHysteresisMs, 1_000L) else dismountHysteresisMs`, and once `effectiveNowMs - nonStationarySinceMs >= exitDwellMs`, commit synchronously: `committedMode = rawCandidate; candidateMode = rawCandidate; candidateSinceMs = Long.MIN_VALUE; nonStationarySinceMs = Long.MIN_VALUE`.
- **Continuous SWE.2 / SWE.3 Maintenance**: No new subsystem/service/repository and `0` edits to `TrackerService.java`/`BANALService.java`/`MyBTLEDevice.java` -> no updates needed to `docs/architecture.md` or `docs/architecture/detailed_design/*`.
