## 1. Architecture, Package Boundaries & Threading Invariants
- **Package Layering (`ArchitectureConformanceContractTest`)**:
  - Place `BaseDatabaseManager.java`, `SqliteSchemaUtils.kt`, and `DatabaseExtensions.kt` in `com.atrainingtracker.database` (alongside `CursorProvider.java` & `SuppressCursorAudit.java`) so `banalservice/database/`, `trainingtracker/database/`, `exporter/db/`, `segments/`, `smartwatch/pebble/`, `migration/`, `tracker/`, and `ui/` share them with `0` upward `.ui.*` imports and `0` `banalservice -> trainingtracker` dependency.
  - Place `StreamSummaryCalculator.kt` in `com.atrainingtracker.trainingtracker.util` (`docs/coding_standards.md` §1.1) so `WorkoutSummariesDatabaseManager` and `ErtsPostWorkoutRecomputer` delegate polyline/stream encoding without adding any `database -> ui.*` imports (allowing `ErtsPostWorkoutRecomputer.kt` to ratchet out of `BASELINE_ALLOWED_DATABASE_UPWARD_UI_IMPORTS` `10 -> 9`).
- **Concurrency & Lifecycle**: `BaseDatabaseManager<H>` uses `protected volatile SQLiteDatabase mDatabase` + `synchronized (this)` DCL with `ATT-289` `mDbHelper.close()` before `mDbHelper.getWritableDatabase()` whenever `mDatabase != null && !mDatabase.isOpen()`. `TrackingViewsRepository.mutateViewConfig` executes DB writes on `Dispatchers.IO` and increments `configUpdateTrigger` on `Dispatchers.Main` preserving return value `T`.
- **Cursor Safety (`REQ-DAT-043`)**: All Kotlin `SqliteSchemaUtils` and `DatabaseExtensions.mapRows` queries close cursors via `.use { ... }`; Java managers keep `try (Cursor ...)` / `CursorUtils` so `TryWithResourcesCursorAuditTest` stays at `0` violations.
