## 1. SWE.2 Architectural Decomposition & Concurrency Model

- **Layer 1 — `PhoneCarriageClassifier.kt` (`1,264 -> ~1,302 / 1,500` LoC, pure-JVM `@Synchronized`)**:
  - Add `private const val RUN_MIN_SPEED_MPS = 1.60` (aligned with `CONFIRMED_NO_FOOTSTRIKE_WALK_SUPPRESS_SPEED_MPS = 1.6` & `EASY_RUN_MIN_SPEED_MPS = 1.65`).
  - Expose `@Synchronized fun hasActiveRunFootstrike(nowMs: Long = lastEventTimestampMs): Boolean`:
    - Guard **`if (nowMs == Long.MIN_VALUE || firstSampleTimestampMs == Long.MIN_VALUE) return false`** BEFORE computing `effectiveNowMs` / `pruneWindows(effectiveNowMs)` (matching `classify():400`, preventing `Long.MIN_VALUE - windowMs` signed underflow on fresh/reset classifiers).
    - Apply `REQ-FIL-042.3` monotonic `effectiveNowMs` clamp, prune windows, and return `true` iff `(currentStepFrequencyHz(effectiveNowMs) ?: 0.0) >= ACTIVE_FOOTSTRIKE_MIN_HZ` OR `(evaluateAccelFootstrike(effectiveNowMs).footstrikeFreqHz ?: 0.0) >= ACTIVE_FOOTSTRIKE_MIN_HZ` (periodic dual-path footstrikes only).
  - In `evaluateRawCandidate(nowMs)`:
    1. Define `hasActiveRunningCadence = effectiveRunStepFreqHz != null && effectiveRunStepFreqHz >= ACTIVE_FOOTSTRIKE_MIN_HZ`.
    2. **Sub-running speed floor (`REQ-FIL-044.1a`)**: Inside Step 2 (`if (!wheelActiveMoving)`), add `if (!easyRunSuppressWalk && effectiveSpeed != null && effectiveSpeed < RUN_MIN_SPEED_MPS && !hasActiveRunningCadence) return RawEvaluation(PhoneCarriageMode.WALKING_TRANSITION, unambiguousMotionExit)` (closes `(0.15, 0.35)` speed gap & non-pendulum handling fallthrough while preserving Step 1 `STATIONARY` and treadmill `effectiveSpeed == null`).
    3. **Footstrike-confirmed `RUN_*` suppression (`REQ-FIL-044.1b`)**: Define `suppressRunningForNoFootstrikes = !suppressCycling && confirmedNoFootstrikes && sportHint != SportContextHint.RUNNING`. Mask `sRunWaist`/`sRunBicep`/`sRunHandheld` to `Double.NEGATIVE_INFINITY` (making stale `RUN_*` `committedScore` non-sticky) and zero-IMU fallback to `BIKE_HANDLEBAR`, preserving `Sport = RUN` (`TST-FIL-035.1`) and trail `impactRms >= 1.8` batching (`TST-FIL-039.1`).
    4. **Gated handheld glance bonus (`REQ-FIL-044.1c`)**: Pass `allowHandheldGlanceBonus = hasActiveRunningCadence || sportHint == SportContextHint.RUNNING || committedMode.isRunningMode()` to `scoreRunHandheld(...)`, awarding `+3.8` strictly when `allowHandheldGlanceBonus && glanceCount >= 1` (else `-1.8`).
- **Layer 2 — `MultisportTransitionDetector.kt` (`366 -> ~445 / 1,500` LoC, pure-JVM `@Synchronized`) + Wiring**:
  - Add `private const val MIN_RUN_SPEED_MPS = 1.60` and `@JvmOverloads hasActiveRunFootstrike: Boolean? = null` to `onTick(...)`.
  - Add `private data class CandidateWindowSample(val activeMs: Long, val totalDistanceM: Double, val cumulativeCorroboratedMs: Long, val anchor: MultisportTelemetryAnchor)` with bounded `ArrayDeque<CandidateWindowSample>` trailing active-unpaused sliding windows for BOTH Phase 1 (`initialWindow`, span `establishWindowMs`) and Phase 2 (`candidateWindow`, span `confirmationWindowMs`), cleared in `clearInitialCandidate()`, `clearTargetCandidateOnly()`, and `reset()`.
  - Define O(1)-amortized `pruneSlidingWindow(window, currentActiveMs, spanMs)` keeping the newest sample with `currentActiveMs - sample.activeMs >= spanMs` as `window.peekFirst()`, plus finite non-negative `safeDistanceDeltaM(from, to)` and `isRunCorroboratedTick = hardwareSignals.hasActiveRunHardware || kinematicSport == BSportType.RUN || hasActiveRunFootstrike == true`.
  - **Unified Trailing-Window Gate (`evaluateRunWindow`)**: Given `(window, currentActiveMs, currentCorroboratedMs, currentAnchor, spanMs, minCorroborationMs, hasActiveRunHardware)`:
    - Computes `head = window.peekFirst() ?: return null`, `windowActiveMs = currentActiveMs - head.activeMs`, `windowActiveSec = windowActiveMs / 1000.0`, `windowDistM = safeDistanceDeltaM(head.totalDistanceM, currentAnchor.totalDistanceM)`, `windowCorroboratedMs = (currentCorroboratedMs - head.cumulativeCorroboratedMs).coerceAtLeast(0L)`.
    - **Zero-duration guard**: Require `windowActiveMs >= spanMs`; if `hasActiveRunHardware || spanMs <= 0L` return `head.anchor`; otherwise require **`windowActiveSec > 0.0`**, `windowDistM >= MIN_RUN_SPEED_MPS * (spanMs / 1000.0)` (`4.8 m` at `3 s`; `24.0 m` at `15 s`), **`windowDistM / windowActiveSec >= MIN_RUN_SPEED_MPS`**, AND `windowCorroboratedMs >= minCorroborationMs` (`Phase 1: minOf(establishWindowMs, (establishWindowMs * 2L) / 3L)` = `2_000 ms` at `3 s`; `Phase 2: minOf(confirmationWindowMs, (confirmationWindowMs * 3L) / 5L)` = `9_000 ms` at `15 s`).
    - **Eliminates BOTH Gate 3 failure modes**: (A) Phase 1 & Phase 2 post-low-speed recovery (`15 s` slow ticks then `15 s` `2.0 m/s` jog prunes slow ticks smoothly and confirms at `+15 s` with `confirmedEnter = qualifyingHeadAnchor` while `exitAnchor` stays untouched), and (B) corroboration dilution (`60 s` uncorroborated roll + `5 s` noise burst has `windowCorroboratedMs = 5_000 < 9_000 ms` -> `0` false triggers).
  - **Caller Wiring (`Coding Standards §5.3`)**: Preserve **`@JvmStatic @JvmOverloads`** on `MultisportTransitionBridge.evaluateAndDispatch(..., hasActiveRunFootstrike: Boolean? = null)` (`235 -> ~239` LoC, keeping 5-arg & 6-arg Java static bytecode signatures) and wire `SpeedAndLocationDevice_ATTFused.evaluateMultisportTransitionIfDue()` (`:1328-1330`, `1,472 -> 1,473 / 1,500` LoC) passing **monotonic `timestampMs`** (not UTC epoch ms) into `carriageClassifier.hasActiveRunFootstrike(timestampMs)`.
- **Continuous SWE.2 / SWE.3 Maintenance**: No new subsystem/service/repository and `0` edits to `TrackerService.java`/`BANALService.java` -> no updates needed to `docs/architecture.md` or `docs/architecture/detailed_design/*`.
