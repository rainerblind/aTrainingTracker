## 1. Architecture, Threading & UI Consistency (`docs/design_guidelines.md`)
- **Layering (`Rule 8.7`)**: `PolarH10RetrySyncBanner.kt` (`ui/aftermath/`, outside `BASELINE_ALLOWED_UI_DB_CALLERS`) delegates pairing queries exclusively to encapsulated `DeviceDataRepository.isPolarRetrySensorPaired(...)` (allowlisted, zero `*DatabaseManager`/`Cursor` getters exposed). `DevicesDatabaseManager.java` (`1,669/1,671`) and `WorkoutRepository.kt` (`4,986/5,117`) remain untouched.
- **Threading & Reactivity**: Pairing lookup runs on `Dispatchers.IO` inside `LaunchedEffect(polarDeviceId, isVeritySense, allDevices, resumeRefreshTick, checkSensorPaired)` triggered by both `DeviceDataRepository.allDevices` (`StateFlow`) and `Lifecycle.Event.ON_RESUME` (`DisposableEffect(lifecycleOwner)`). State starts at `null` (`initialValue = null` $\rightarrow$ `resolvedPaired ?: true`) to prevent Frame-0 false-unpaired flicker (`docs/coding_standards.md` §5.10) without unmounting `WorkoutDetailTabbedContent` (§5.9).
- **UI Consistency (§5.1–§5.5)**: Reuse `WorkoutDetailTabbedContent.kt:675-700` semantic alert surface (`Surface(color = MaterialTheme.colorScheme.errorContainer, shape = RoundedCornerShape(8.dp))`, `12.dp`/`8.dp` padding, `Icons.Default.WarningAmber` `20.dp` tinted `error`, `bodySmall` text in `onErrorContainer`, zero inline emojis per `ATT-5400`). Primary `Button` (*"Jetzt synchronisieren"*) uses `enabled = !isSyncing && isSensorPaired` with `maxLines = 1, softWrap = false, overflow = TextOverflow.Ellipsis`; secondary `OutlinedButton` (*"Ignorieren"*) stays `enabled = !isSyncing`. Add Light & Dark `@Preview`s for unpaired H10 and Verity Sense states.
