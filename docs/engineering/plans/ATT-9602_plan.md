## 1. SWE.2 Architectural Decomposition & Threading Model

- **Pure-Kotlin Helper `BarometricBucketDispersion.kt` (`com.atrainingtracker.banalservice.odometry`)**:
  - Zero Android dependencies; invoked strictly under `AltitudeAndSlopeDevice_ATTFused`'s `@Synchronized` monitor (zero extra locks or threads).
  - Maintains (a) current 1-Hz bucket list `bucketSamples: MutableList<Double>` and (b) bounded rolling raw window `rollingWindow: ArrayDeque<Sample>` (`MULTI_SECOND_WINDOW_MS = 3_000L`, `MAX_ROLLING_SAMPLES = 128`, pruned deterministically by `timestampMs`, never wall-clock).
  - On `flushBucket(timestampMs, speedMps)`: computes `span = max - min`, `iqr` (linear quartile `Q3 - Q1` for `size >= 4`, `0.5 * span` for `size in 2..3`, `0.0` for `size < 2`), `physicalSpan = max(2.5, 0.20 * max(0.0, speedMps))`, `excessSpread = max(0.0, iqr - physicalSpan)`, `targetDispVar = if (excessSpread > 0.0) min(2500.0, 2.0 * excessSpread * excessSpread) else 0.0`, asymmetric attack/decay `dispersionVarM2` (immediate attack; decay `target + 0.65 * (curr - target)`, zero below `0.05`).
  - Representative altitude: exact 1-Hz bucket median when `excessSpread == 0.0 && dispersionVarM2 == 0.0` (`0` extra lag on calm/handlebar rides); interquartile trimmed mean (`[Q1..Q3]` mean) across `rollingWindow` when `excessSpread > 0.0 || dispersionVarM2 > 0.0` (suppresses `~0.92 Hz` vs `1.00 Hz` asymmetric beat aliasing across `~3` pedal cycles).
- **Live Device Integration & Startup Grace (`AltitudeAndSlopeDevice_ATTFused.kt`)**:
  - Replaces bare `mBaroBucketAltitudes` with `baroBucket = BarometricBucketDispersion()` (cleared in `shutDown()`).
  - Tracks `mFirstBaroTimestampMs` (set on first baro sample, cleared in `shutDown()`). `handlePressureMeasurement()` still initializes `ekf` immediately (`ekf.isInitialized == true`), while `publishAltitudeAndMetrics(speedMps, nowMs)` defers sensor updates while `ekf.is3StateMode && !ekf.hasReferenceAnchor && mFirstBaroTimestampMs >= 0L && (nowMs - mFirstBaroTimestampMs) in 0L until STARTUP_REFERENCE_GRACE_MS` (`5_000L`).
  - Passes `slewSpeed = if (dispersionVarM2 > 0.0) 0.0 else speed` to `baroFilter.filterSlewOnly(alt, ts, slewSpeed)` and `varBaro = mEffectiveRBaro + dispersionVarM2` to `ekf.updateBarometer(...)`.
- **EKF Corrupted-Baro DEM Guard (`KinematicAltitudeSlopeEkf.kt`)**:
  - Tracks `lastBaroVarM2: Double = rBaro` (updated in `updateBarometer()`, reset in `reset()`/`reanchorOnResume()`/`setMode()`); gates `computeStepGatedRefVariance()` on `lastBaroVarM2 <= DEM_BARO_TRUST_VAR_THRESHOLD` (`16.0 m²`) so pocket-corrupted baro never vetoes true flat DEM while preserving 100% of `REQ-FIL-037.2` when healthy.
- **ERTS Low-Speed Braking Damping (`ExtendedRtsAltitudeSlopeSmoother.kt`)**:
  - Keeps `LOW_SPEED_SLOPE_THRESHOLD_MPS = 1.2` and `lowSpeedSlopeGainFactor()` untouched (`TST-FIL-033.1`).
  - Tracks `prevSpeedMps` and `brakingHoldSec` (`accel <= -0.25 m/s²` sets `4.0 s` hold; standstill clears; steady riding decays by `dtSec`): inflates `effectiveVarBaro` (`8.0×` with ref, `4.0×` without ref below `2.5 m/s`) and scales `qgVal` & baro `k1` by `(speedMps / 2.5)^2` when `!isStandstill && brakingHoldSec > 0.0 && speedMps < 2.5`.
