## 1. Architecture, Concurrency & Monolith Budget (`ArchitectureConformanceContractTest`)
- **Lock-Free Arbitration**: `HrSensorHealthProvider` exposes strictly `@Volatile`/atomic reads (`getHrHealthTier(nowMs)`, `getHrModality()`, `isHrStreamDegraded()`). `MySensorManager` reads these lock-free inside `synchronized (this)` in `getBestSensor(SensorType.HR)` and invokes `ProxySensor.setSourceSensor(...)` strictly **outside** `synchronized (this)` in `setBestSensorForProxySensor(SensorType.HR)` / `reevaluatePrimaryHrSensor()`.
- **Monolith Headroom**: `PolarOnlineStreamingBridge.kt` is currently `1,492 / 1,500` LoC (`8` LoC headroom). We extract ALL health/staleness/flatline/RR-clear state into new pure-JVM `PolarHrStreamHealthMonitor.kt`, extract arbitration into new pure-JVM `PrimaryHrSensorArbitrator.kt` + `HrSensorHealthProvider.kt`, and offload pure helper logic (e.g., `resolveGyroSetting` / `handleDisCharacteristic` / `unregisterImuCadenceSensors` cleanup) to `PolarPmdStreamCoordinator.kt` (`497/1,500`) so `PolarOnlineStreamingBridge.kt` stays `<= 1,490 / 1,500` LoC with **unchanged constructor & public JVM signatures** (`InterfaceSignatureDriftContractTest`).
- **Untouched Monoliths (`0` edits)**: `DeviceManager.java` (`1,707/1,708`), `TrackerService.java` (`3,551/3,559`), `DevicesDatabaseManager.java` (`1,669/1,671`), `PolarVeritySenseOfflineController.kt` (`1,483/1,500`).
