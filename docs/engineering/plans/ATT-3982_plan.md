## 1. Problem Description & Background

In `MigrationEngine.performFullRestore()` and `ImportEngine.unzipBackup()`, archive extraction constructs destination files using `File(destDir, entry.name)` without path normalization or boundary validation. If an incoming `.attbackup` archive contains directory traversal elements (`../`), target file construction escapes `destDir` and writes into arbitrary locations in the app private sandbox.
Crucially, in `ImportEngine.analyzeBackup()`, `unzipBackup()` is executed automatically as soon as an athlete selects a backup file to preview its metadata. A malicious archive can compromise internal databases, shared preferences, or libraries during analysis even before user confirmation!
Furthermore, `LegacyImportEngine.kt:413` downloads Google Drive files using `File(workerDir, entry.name)` without sanitizing path traversal sequences in Drive file names.

### Auditor Feedback Incorporation (Revision 2)
In response to Independent Auditor feedback on Gate 3, this revised plan addresses:
1. **Path Normalization over `canonicalFile`**: Relying solely on `canonicalFile` is susceptible to symlink traversal and TOCTOU. We utilize `java.nio.file.Path.normalize()`, verify `entryPath.startsWith(destPath)`, and strictly reject any symbolic link via `Files.isSymbolicLink(entryPath, LinkOption.NOFOLLOW_LINKS)`.
2. **Streaming `CountingInputStream`**: Real-time streaming byte counting to preemptively abort zip bomb attempts before uncompressed data accumulates.
3. **Strict Drive Name Validation**: Explicitly reject filenames containing `/`, `\`, or `..`.
4. **Symlink Rejection Test**: Dedicated test `TST-MIG-037.8` for archive symlink rejection.
5. **Atomic File Writes**: Write entry bytes to a staging `.tmp` file and perform atomic move (`StandardCopyOption.ATOMIC_MOVE`) to the target `entryPath`.

## 4. Proposed Architectural Changes (SWE.2)

### Component 1: `SecureZipExtractor.kt`
Create a centralized security utility object `com.atrainingtracker.trainingtracker.migration.SecureZipExtractor`:
```kotlin
object SecureZipExtractor {
    const val MAX_ENTRY_COUNT = 10_000
    const val MAX_SINGLE_FILE_BYTES = 512L * 1024L * 1024L // 512 MB
    const val MAX_TOTAL_UNCOMPRESSED_BYTES = 1024L * 1024L * 1024L // 1024 MB (1 GB)
    val DEFAULT_ALLOWED_TOP_LEVEL_DIRS = setOf("databases", "shared_prefs", "datastore")

    fun extractBackupArchive(
        backupFile: File,
        destDir: File,
        allowedTopLevelDirs: Set<String> = DEFAULT_ALLOWED_TOP_LEVEL_DIRS
    )
}
```

**Hardened Extraction Algorithm**:
1. Check `destDir`: ensure it exists or create directories via `Files.createDirectories(destDir.toPath())`.
2. Compute normalized absolute destination path:
   ```kotlin
   val destPath = destDir.toPath().toAbsolutePath().normalize()
   ```
3. Maintain real-time tracking counters:
   ```kotlin
   var entryCount = 0
   var totalBytesRead = 0L
   ```
4. Wrap extraction execution in `try { ... } catch (e: Exception) { destDir.deleteRecursively(); throw e }` for fail-safe cleanup.
5. In the entry loop of `ZipInputStream`:
   - Increment `entryCount`. If `entryCount > MAX_ENTRY_COUNT`, throw `SecurityException("Archive entry limit exceeded (max $MAX_ENTRY_COUNT): $entryCount")`.
   - Validate entry name characters: reject if containing raw control characters or null bytes.
   - Resolve target path:
     ```kotlin
     val entryPath = destPath.resolve(entry.name).normalize()
     ```
   - **Boundary Assertion**: Verify `if (!entryPath.startsWith(destPath)) throw SecurityException("Zip-slip path traversal attempt detected: ${entry.name}")`.
   - **Symlink Check**: Verify `if (Files.isSymbolicLink(entryPath, LinkOption.NOFOLLOW_LINKS)) throw SecurityException("Symbolic links are strictly prohibited in backup archives: ${entry.name}")`. Also verify parent directories along `entryPath` within `destPath` are not symbolic links.
   - **Whitelist Validation**:
     ```kotlin
     val relativePath = destPath.relativize(entryPath).toString().replace('\\', '/')
     val topLevelDir = relativePath.substringBefore('/')
     if (topLevelDir !in allowedTopLevelDirs) {
         throw SecurityException("Invalid backup entry outside whitelisted directories: ${entry.name}")
     }
     ```
   - **Directory Entries**:
     - If `entry.isDirectory`: `Files.createDirectories(entryPath)`.
   - **File Entries**:
     - Ensure parent directory exists: `Files.createDirectories(entryPath.parent)`.
     - Write entry content using a streaming byte counter and atomic file replacement:
       ```kotlin
       val tempFilePath = Files.createTempFile(entryPath.parent, "entry_", ".tmp")
       try {
           var singleFileBytes = 0L
           Files.newOutputStream(tempFilePath).use { output ->
               val buffer = ByteArray(8192)
               var bytesRead: Int
               while (zipIn.read(buffer).also { bytesRead = it } != -1) {
                   singleFileBytes += bytesRead
                   totalBytesRead += bytesRead
                   if (singleFileBytes > MAX_SINGLE_FILE_BYTES) {
                       throw SecurityException("Single file size limit exceeded: $singleFileBytes > $MAX_SINGLE_FILE_BYTES")
                   }
                   if (totalBytesRead > MAX_TOTAL_UNCOMPRESSED_BYTES) {
                       throw SecurityException("Total uncompressed archive size limit exceeded: $totalBytesRead > $MAX_TOTAL_UNCOMPRESSED_BYTES")
                   }
                   output.write(buffer, 0, bytesRead)
               }
           }
           Files.move(tempFilePath, entryPath, StandardCopyOption.ATOMIC_MOVE, StandardCopyOption.REPLACE_EXISTING)
       } finally {
           Files.deleteIfExists(tempFilePath)
       }
       ```
