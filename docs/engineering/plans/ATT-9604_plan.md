## 1. SWE.2 Architectural Decomposition & Threading Model

- **Channel Extension (`PhoneRawTelemetryRow.kt`)**: Add `PhoneRawChannel.GNSS_FUSED` with identical 6-field numeric validation (`v0..v5`) and `parseChannel("GNSS_FUSED")`. Exact 9-column `CSV_HEADER` and `schemaVersion = 1` remain untouched so `PhoneRawSidecarRecovery`, `PhoneRawTelemetryReader`, and historical `v1` sidecars (`2026-11-22_081402.phone_raw.csv.gz`) stay 100% backwards-compatible.
- **Per-Channel Zero-Allocation Dedup (`SmartphoneRawTelemetryRecorder.kt`)**:
  - Instance-scoped `locationDedupLock = Any()` protecting two 4-slot primitive ring buffers (`GNSS` and `GNSS_FUSED`, each holding `LongArray(4)` `elapsedNs`, `LongArray(4)` `epochMs`, `BooleanArray(4)` `hasLocNs`, and `Int` cursor; zero heap allocations per fix, automatically reset per recorder instance/session).
  - `shouldAcceptLocation(channel, elapsedNs, epochMs, hasLocationElapsedNs)`: when `hasLocationElapsedNs == true` (`location.elapsedRealtimeNanos > 0L`), rejects duplicates matching any slot with `slotHasLocNs && slotElapsedNs == elapsedNs` (immune to `location.time == 0L` 1-ms wall-clock drift and immune to interleaved `GNSS_FUSED` or out-of-order thread callbacks); when `hasLocationElapsedNs == false`, matches `!slotHasLocNs && slotElapsedNs == elapsedNs && slotEpochMs == epochMs`. Suppressed duplicates return before `Channel.trySend` (never incrementing `droppedFrameCount`).
  - Backwards-compatible `@JvmStatic @JvmOverloads fun recordLocation(location: Location, epochMs: Long, channel: PhoneRawChannel = resolveLocationChannel(location))` (plus `@JvmOverloads` `channel: PhoneRawChannel = PhoneRawChannel.GNSS` on `recordGnss`); `resolveLocationChannel` catches plain-JVM mock exceptions safely and maps `"fused"` (case-insensitive) -> `GNSS_FUSED`, else `GNSS`.
- **Authoritative Device-Type Tagging (`SpeedAndLocationDevice.java`, `SpeedAndLocationDevice_ATTFused.kt`)**:
  - `SpeedAndLocationDevice.onNewLocation()` tags `DeviceType.SPEED_AND_LOCATION_GOOGLE_FUSED` -> `PhoneRawChannel.GNSS_FUSED` and other non-direct subclasses (`GPS`) -> `PhoneRawChannel.GNSS`.
  - `SpeedAndLocationDevice_ATTFused.onLocationChanged()` passes `PhoneRawChannel.GNSS` explicitly on line 504 (`+0` net LoC), preserving pre-EKF raw capture before feature guards (`ATT-9348`).
- **Backwards-Compatible Offline Replay (`app/src/test/.../replay/` + `app/build.gradle`)**:
  - Add `enum class ReplayGnssSource { AUTO, GPS, FUSED }` and defaulted `ReplayConfig.gnssSource = ReplayGnssSource.AUTO` (`0` bytes added to production APK).
  - `OfflineTelemetryReplayHarness.replayParsed()` resolves `activeGnssChannel` (`AUTO` -> `GNSS` if any `GNSS` row exists, else `GNSS_FUSED`), ignores the non-selected GNSS channel, and skips exact consecutive duplicate GNSS rows (`elapsedRealtimeNs`, `epochMs`, `v0`, `v1` identical) so legacy `v1` sidecars also replay cleanly without duplicate GPS timing distortion.
  - `OfflineReplayCli` & `:app:replayRawTelemetry` accept optional `--gnss-provider <auto|gps|fused>` / `-PgnssProvider=...` (default `auto`; invalid value exits `2`).
