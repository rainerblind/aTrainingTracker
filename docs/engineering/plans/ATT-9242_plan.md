## 2. Backward-Compatible Interface Contracts
- `RawOdometrySample(..., val isPauseGap: Boolean = false)` & `RawAltitudeSample(..., val isPauseGap: Boolean = false)` (trailing defaults).
- `ExtendedRtsOdometrySmoother.smoothSnapshots(..., pauseGapMask: BooleanArray? = null)` preserves `@JvmOverloads` (3/4/5/6-arg callers).
- `ErtsPostWorkoutRecomputer.reconstructTimestamps(samples, fallbackStartMs)` delegates to `reconstructTimingWithPauses(..., emptyList(), ...).timestampsMs`.
- `ErtsPostWorkoutRecomputer.computeAuthoritativeAverageSpeedMps(..., pauseGapMask: BooleanArray? = null)` preserves 3-arg compatibility while excluding flagged short pauses when `TIME_ACTIVE_s` is null in both `updateWorkoutSummaries()` (`:801`) and `updateExtrema()` (`:916`).
- Overflow-free gap helper in both smoothers: `currTs > prevTs && prevTs <= Long.MAX_VALUE - MAX_ACTIVE_SAMPLE_GAP_MS && currTs > prevTs + MAX_ACTIVE_SAMPLE_GAP_MS`.

## 3. Atomic Implementation Steps
1. **Step 1 — `ExtendedRtsOdometrySmoother.kt` (`REQ-FIL-045.2`)**:
   - Add `isPauseGap: Boolean = false` to `RawOdometrySample`, `const val MAX_ACTIVE_SAMPLE_GAP_MS = 5_000L`, and `internal fun isTimestampPauseGap(prevTimestampMs: Long, currTimestampMs: Long): Boolean`.
   - Fix `resolveInitialHeadingRad()` (`:674-708`): compute `val (firstEast, firstNorth) = latLngToEnu(samples[firstValidIdx].latitude!!, samples[firstValidIdx].longitude!!, refLat, refLon)` and use `dE = eastM - firstEast`, `dN = northM - firstNorth`, `dist = hypot(dE, dN)`, `atan2(dN, dE)` so Segment 1+ computes relative segment heading instead of vector from Home `(refLat, refLon)`.
   - In `smoothSnapshots()`, add `@JvmOverloads pauseGapMask: BooleanArray? = null`; when `isPauseBoundary(k + 1)` in backward loop, re-initialize `smoothedStates[k]`/`smoothedCovs[k]` strictly from `snapshots[k]` posterior (applying stationary & `maxSpeedEnvelope` guards) and `continue`; in output loop set `deltaDist = 0.0` when `k == 0 || isPauseBoundary(k)`.
   - Partition `samples` in `smoothSamples()` at every pause boundary (`samples[i].isPauseGap || isTimestampPauseGap(samples[i - 1].timestampMs, samples[i].timestampMs)`) using zero-copy `subList(segStart, segEnd)`; call `smoothContiguousSegment()` passing `explicitInitialHeadingRad = if (segStart == 0) initialHeadingRad else Double.NaN` and falling back to `(fallbackEast, fallbackNorth, fallbackHeadingRad)` when `segFirstValidIdx < 0` (no-GNSS segment).
2. **Step 2 — `ExtendedRtsAltitudeSlopeSmoother.kt` (`REQ-FIL-045.3`)**:
   - Add `isPauseGap: Boolean = false` to `RawAltitudeSample`, `const val MAX_ACTIVE_SAMPLE_GAP_MS = 5_000L`, and `internal fun isTimestampPauseGap(prevTimestampMs: Long, currTimestampMs: Long): Boolean`.
   - Partition `samples` in `smooth()` at every pause boundary; extract `smoothContiguousSegment(segment, fallbackInitialAlt, inheritedBaroBias, ascentOffset, descentOffset)` returning `(points, endAlt, endBaroBias, endAscent, endDescent)`.
   - Handle `n == 1` cleanly: resolve `alt = s0.referenceAltitudeM?.takeIf { it.isFinite() } ?: s0.rawAltitudeM.takeIf { it.isFinite() }?.let { if (inheritedBaroBias.isFinite()) it - inheritedBaroBias else it } ?: fallbackInitialAlt`, emit `ascentM = ascentOffset`, `descentM = descentOffset`, `verticalSpeedMps = 0.0`, and return `endBaroBias = inheritedBaroBias`.
   - For `n > 1`: scan `segment` for first finite `rawAltitudeM` when `!hasReference && hasBaroData && inheritedBaroBias.isFinite()` (`x[0] = firstRawBaro - inheritedBaroBias`, `x[2] = inheritedBaroBias`), reset `standstillDurationSec`/`brakingHoldSec`, start fresh `anchorAlt = alt` while adding `ascentOffset`/`descentOffset` monotonically, and propagate `endBaroBias = if (hasBaroData) smoothedStates.last()[2] else inheritedBaroBias` across `!hasBaroData` (DEM-only) segments.
3. **Step 3 — `ErtsPostWorkoutRecomputer.kt` (`REQ-FIL-045.1`)**:
   - Add `PAUSE_TIME_DIFF_THRESHOLD_SEC = 2L`, `RawSampleRow.isPauseGap: Boolean = false`, and `internal data class ReconstructedTiming(val timestampsMs: LongArray, val pauseGapMask: BooleanArray)`.
   - Read `SensorType.TIME_ACTIVE.name` in `readWorkoutSamples()`; implement `reconstructTimingWithPauses()` merging `wallPauseTs`, `timeTotalPauseTs`, and `timeActivePauseTs = oneHzTs + extraPairGapSec * 1000L` via `max(...)` whenever `deltaTotal > 0L && deltaActive >= 0L && (deltaTotal - deltaActive) > 2L && extraPairGapSec >= 2L` (where `extraPairGapSec = deltaTotal - (i - prevPairIdx)`), setting `pauseGapMask[i] = true` on any pause branch or `ts - prevTs > 5_000L`, AND resetting `prevPairTotalSec = null; prevPairActiveSec = null; prevPairIdx = -1` whenever `pauseGapMask[i] && (timeTotalSec == null || timeActiveSec == null)`.
   - In `resolveCarriageModesAndFilterBaro()`: reset `baroFilter.reset()` at pause boundaries; run `detectAndCompensateBaroResetSteps()` independently per pause-delimited contiguous segment (preventing null-baro masking, cross-pause `preVals`/`postVals`, and Segment 1 `cumulativeShift` leakage while keeping `<= 5 s` non-pause crash-recovery steps intact); stop `inferLegacyCarriageModeAt()` from crossing pause boundaries.
   - Propagate `isPauseGap` to `RawOdometrySample` / `RawAltitudeSample`, pass `pauseGapMask` to `computeAuthoritativeAverageSpeedMps()` in BOTH `updateWorkoutSummaries()` (`:801`) and `updateExtrema()` (`:916`), and guard `!rawRows[i].isPauseGap` in `estimateRawReferenceDistanceMeters()`.
