## 1. SWE.2 Architectural Decomposition & Threading Model

- **Pure-Kotlin Monotonic Normalizer (`AttFusedTimestampNormalizer.kt`, new `~140` LoC in `banalservice.odometry`)**:
  - Injected with `elapsedRealtimeNanosProvider: () -> Long` (returns `> 0L` on Android/Robolectric, `0L` when `SystemClock` is unmocked on plain JVM) and `wallClockMillisProvider: () -> Long` (for plain-JVM fallback & UTC anchors). Synchronized internally via private `lock` (never acquires `this` or `ekf`, zero lock-ordering risk).
  - Constants: `OEM_CLOCK_DIVERGENCE_THRESHOLD_MS = 5_000L`, `MAX_LOCATION_DOMAIN_SKEW_MS = 300_000L`, `UNIX_EPOCH_MS_FLOOR = 1_500_000_000_000L`.
  - `currentMonotonicMs()`: uses `platformNs / 1_000_000L` (non-rewinding vs `lastResolvedMonotonicMs`) when `platformNs > 0L`, else `wallClockMillisProvider()`.
  - `resolveLocationTimestampMs(locationElapsedRealtimeNanos, locationTimeMs)`: prefers `locationElapsedRealtimeNanos / 1_000_000L` whenever `> 0L` (guarding against clearly broken epoch-ns or `> 300 s` skewed location HALs when `platformNs > 0L`); when `locationElapsedRealtimeNanos <= 0L`, preserves synthetic `< 1.5e12` test timestamps or plain-JVM `locationTimeMs > 0L`, while mapping real Android epoch timestamps (`>= 1.5e12`) onto `platformMonoMs`. Enforces per-stream non-decreasing `lastResolvedLocationMs`.
  - `resolveSensorEventTimestampMs(sensorType, sensorTimestampNs)`: latches per-`sensorType` OEM offset (`0L` when `|sensorMs - refNowMs| <= 5_000 ms`, else `refNowMs - sensorMs`); re-anchors forward when `refNowMs - alignedMs > 5_000 ms` (e.g., `uptimeMillis` deep-sleep pause) or when `platformAdvanced && alignedMs - refNowMs > 5_000 ms` (epoch-ns NTP jump on live ticking clock — never triggered by Robolectric's frozen `100 ms` clock); enforces per-`sensorType` non-decreasing `lastResolvedSensorMsByType`.
  - `resolveWheelTimestampMs(incomingTimestampMs)`: maps production wall-clock `MySensorManager` timestamps (`>= 1.5e12` when `platformNs > 0L`) onto `platformMonoMs` while preserving explicit monotonic or synthetic `< 1.5e12` test timestamps.
  - `toWallClockEpochMs(monotonicMs)`: lazily anchors `(monoOriginMs, wallOriginMs)` on live monotonic devices so `MultisportTelemetryAnchor.timestampMs` emits authentic, NTP-rewind-immune UTC epoch ms (`wallOriginMs + (monotonicMs - monoOriginMs)`), passing through synthetic test timestamps unchanged.
  - `reset()`: clears all cached offsets, anchors, and monotonic high-water marks (invoked from `resetOriginAndEkf()`).
- **Device Integration (`SpeedAndLocationDevice_ATTFused.kt`, `1,498 -> ~1,475 / 1,500` LoC)**:
  - Add `protected open fun elapsedRealtimeNanos(): Long` (try/catch `SystemClock.elapsedRealtimeNanos()` -> `0L` on plain JVM) and `internal val timestampNormalizer = AttFusedTimestampNormalizer(::elapsedRealtimeNanos, ::currentTimeMillis)`.
  - Remove legacy `MAX_CLOCK_DOMAIN_SKEW_MS`, `mSensorTimestampEpochOffsetMs`, `mSensorTimestampEpochOffsetMsByType`, `mLastResolvedSensorMsByType`, and 32-line `resolveSensorEventTimestampMs()` (`-38` LoC), delegating `onSensorChanged()`, `onLocationChanged()`, `onWheelMeasurement()` (3-arg & 2-arg), `mSportChangedReceiver`, `triggerDecayTick()`, and `ingestImuMeasurement()` default arg to `timestampNormalizer`.
  - Preserve external UTC boundaries: `SmartphoneRawTelemetryRecorder.recordLocation(..., if (location.time > 0L) location.time else currentTimeMillis(), GNSS)`, `recordWheel(..., timestampMs, ...)`, `updateCarriageMode(mode.code, currentTimeMillis())`, and `MultisportTransitionBridge.evaluateAndDispatch(..., timestampNormalizer.toWallClockEpochMs(timestampMs))`.
- **Classifier & EKF Monotonic Hardening (`PhoneCarriageClassifier.kt`, `UnicycleOdometryEkf.kt`)**:
  - In `PhoneCarriageClassifier.classify(nowMs)`: compute `effectiveNowMs = if (lastEventTimestampMs != Long.MIN_VALUE && nowMs < lastEventTimestampMs) lastEventTimestampMs else nowMs` and use `effectiveNowMs` across window pruning, warmup, `candidateSinceMs` seeding, and dwell checks. Guard `ingestGnssSpeed()` against older out-of-order `timestampMs < lastGnssTimestampMs`.
  - In `UnicycleOdometryEkf.kt`: add `private fun advanceTimestamp(timestampMs: Long)` (`if (timestampMs > currentTimestampMs) currentTimestampMs = timestampMs`) across `predict`, `updateSpeed`, `applyZeroVelocityUpdate`, `updateGnssPosition`, `seedInitialHeading`, and `applyHeadingMeasurement`.
