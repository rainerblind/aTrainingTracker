## 1. SWE.2 Architectural Decomposition & Leaf-Only Lock Model (Gate 3 Revision)

- **Layer 1 — `SmartRadarLightEngine.kt` (`483 -> ~590 / 1,500` LoC)**:
  - **Leaf-Only `engineLock` (Finding 5a)**: Remove `@Synchronized` from `start()`, `startListening()`, `stopListening()`, and `stop()`. Introduce `private val engineLock = Any()` and `private var listenEpoch: Long = 0L`, plus `@Volatile` flags (`isAutomationEnabled`, `isTunnelActive`, `currentSolarProfile`, `currentThreatStage`, `isManualOverridden`, `lastDispatchedMode`, `isWorkoutActive`, `isWorkoutPaused`, `isListening`). `engineLock` MUST NEVER be held across `SensorManager.registerListener`/`unregisterListener`, `CoroutineScope.launch`/`cancel`, `Handler`, `RadarLightController`, or `RadarStateRepository`:
    - `start(context)`: under `engineLock`, set `appContext = appCtx`, `isWorkoutActive = true`, `isWorkoutPaused = false`, create `newScope = if (observationScope == null) CoroutineScope(SupervisorJob() + coroutineDispatcher).also { observationScope = it } else null`, snapshot `shouldListen = isAutomationEnabled`, release `engineLock`. Outside lock: if `newScope != null`, launch `threatState` and `radarSmartLightAutomationFlow` collectors (guarding `radarSmartLightAutomationFlow` with `if (!RadarLightController.shouldIgnoreStaleDataStoreAutoMode(enabled)) { if (enabled) clearManualOverrideForExternalAuto(); isAutomationEnabled = enabled }`); if `shouldListen`, call `startListening(appCtx)`.
    - `startListening(...)`: under `engineLock`, if `isListening` return, capture `expectedEpoch = ++listenEpoch`, release lock. Outside lock: resolve `SensorManager`/`PowerManager`, register `TYPE_LIGHT`/`TYPE_PROXIMITY`. Re-acquire `engineLock`: if `listenEpoch == expectedEpoch`, commit `(sensorManager = sm, powerManager = pm, isListening = true)`; else release lock and immediately `sm.unregisterListener(this)` to eliminate race leaks!
    - `stopListening()`: under `engineLock`, `listenEpoch++`, snapshot & clear `(sm = sensorManager, sensorManager = null, powerManager = null, isListening = false)`, release lock, then `sm?.unregisterListener(this)` outside lock.
    - `onWorkoutPaused()` (Finding 4): under `engineLock`, set `isWorkoutPaused = true`, clear `pendingModeToDispatch = null`, release lock, cancel `rateLimitFlushRunnable`, and call `stopListening()` outside lock (keeping `observationScope`/`appContext` intact for resume).
    - `stop()` (Finding 3 + 5a): under `engineLock`, set `isWorkoutActive = false`, `isWorkoutPaused = false`, `isAutomationEnabledField = false` (no dispatch!), `lastDispatchedMode = null`, `pendingModeToDispatch = null`, snapshot & clear `(scopeToCancel = observationScope, observationScope = null, appContext = null)`, release lock; cancel `rateLimitFlushRunnable`, call `stopListening()`, and `scopeToCancel?.cancel()` outside lock.
  - **Threat Sync, Preview & Dispatch Core**:
    - `setAutomationEnabledInternal(enabled: Boolean, evaluate: Boolean)`: writes backing field; if `enabled`, snapshots `(canListen = isWorkoutActive && !isWorkoutPaused, ctx = appContext)` under `engineLock`, releases lock, calls `if (canListen && ctx != null) startListening(ctx)` (**never** registers sensors while paused — Finding 4!), and if `evaluate` calls `evaluateAndDispatchInternal(safeElapsedRealtime(), forceImmediate = false)`. Public `isAutomationEnabled` setter delegates to `setAutomationEnabledInternal(value, evaluate = true)` (and `stopListening()` when `false`).
    - `internal fun clearManualOverrideForExternalAuto()`: sets `isManualOverridden = false` cleanly without evaluating (called by external `onPreferencesUpdated()` BEFORE setting `isAutomationEnabled = true` — Finding 5c).
    - `internal fun syncThreatStageFromRepository(nowMs: Long)` & `internal fun previewTargetMode(nowMs: Long): RadarLightMode` (side-effect-free live threat stage + `computeTargetMode`).
    - `internal fun evaluateAndDispatchInternal(nowMs: Long, forceImmediate: Boolean): Boolean`: guards `!isAutomationEnabled || isManualOverridden || RadarLightController.isBrakeActive`; computes `targetMode` & `effectiveTarget = RadarLightController.resolveStvzoMode(targetMode)`; when `!forceImmediate && targetMode == lastDispatchedMode && effectiveTarget == RadarLightController.currentMode.value` returns `false`; if `forceImmediate || nowMs - lastDispatchRealtimeMs >= RATE_LIMIT_INTERVAL_MS`, cancels `rateLimitFlushRunnable`, clears `pendingModeToDispatch`, and calls `dispatchMode(targetMode, nowMs)`; else queues `pendingModeToDispatch = targetMode` + `rateLimitFlushRunnable`. Public `evaluateAndDispatch(nowMs)` (`Unit`) delegates with `forceImmediate = false`.
    - `dispatchMode(mode, nowMs): Boolean`: calls `val committed = RadarLightController.setAutomationLightMode(mode)`. Strictly when `committed == true`, sets `lastDispatchedMode = mode`, `lastDispatchRealtimeMs = nowMs`, `pendingModeToDispatch = null`; else clears `lastDispatchedMode = null` and returns `false`.
    - `@JvmStatic fun resumeAutomation()` (`Unit`): cancels `rateLimitFlushRunnable`, clears `pendingModeToDispatch = null`, calls `syncThreatStageFromRepository(nowMs)`, clears `isManualOverridden = false`, calls `setAutomationEnabledInternal(enabled = true, evaluate = false)`, and calls `evaluateAndDispatchInternal(nowMs, forceImmediate = true)`.
    - Harden `onManualOverride(mode)` (clear `pendingModeToDispatch = null`, cancel `rateLimitFlushRunnable`) and `flushPendingDispatch()` (re-check `isAutomationEnabled && !isManualOverridden && !RadarLightController.isBrakeActive` before calling `evaluateAndDispatchInternal(safeElapsedRealtime(), forceImmediate = false)`).
