h2. 1. Technical Architecture & Components

The feature delivers an end-to-end management experience for geographical workout start locations stored in {{StartLocation2Altitude.db}} (Schema V5).

h3. 1.1 Navigation & Routing Architecture
# *Drawer Navigation*:
* Integrated into {{AppNavigationDrawer.kt}} under {{drawer__maps}} destinations:
** Item ID: {{R.id.drawer_start_locations}}
** Destination Route: {{NavRoutes.START_LOCATIONS}}
** Icon: {{Icons.Default.Place}}
** Title: {{@string/drawer_start_locations}} ("Start Locations" / "Startorte")
# *NavHost Registration*:
* Register route in {{NavRoutes.kt}} ({{const val START_LOCATIONS = "start_locations"}}).
* Wire route in {{ATrainingTrackerApp.kt}} {{composable(NavRoutes.START_LOCATIONS)}} instantiating {{KnownLocationsScreen}}.

h3. 1.2 Reverse Geocoding & Human-Readable Auto-Naming (LocationNameResolver.kt)
# *Android Geocoder Integration*:
* Encapsulate address resolution in {{com.atrainingtracker.trainingtracker.location.LocationNameResolver}}.
* Queries {{android.location.Geocoder}} on {{Dispatchers.IO}}:
** Combines address elements hierarchically: feature name + locality, thoroughfare + locality, or locality.
** Fallback on offline/error/empty: Localized coordinates string {{@string/known_location_unnamed_format}} (e.g. "Startort (48.137, 11.576)").
# *Discovery & Healing Integration*:
* When {{AltitudeFromPressureDevice}} discovers a new start location or legacy healing detects a placeholder ("Internet DEM start", "Auto-learned start", or blank), it resolves a human-readable name asynchronously.
* User-customized names ({{source == MANUAL_USER}} or user edits) are *strictly preserved* and immune to automatic overwriting.

h3. 1.3 Concurrency & Single-Threaded SQLite Repository (KnownLocationsRepository.kt)
# *Thread Confinement Invariant*:
* To eliminate coroutine thread hopping and avoid deadlocks with Java {{synchronized}} blocks in {{KnownLocationsDatabaseManager}}, all SQLite operations are confined to a dedicated single-threaded dispatcher ({{Executors.newSingleThreadExecutor("KnownLocationsDB-Thread").asCoroutineDispatcher()}}).
# *Repository API*:
* {{getLocationsFlow(): Flow<List<KnownLocationItem>>}}: Emits reactive list of stored locations.
* {{suspend fun updateLocation(id: Long, name: String, altitude: Double, source: ElevationSource)}}: Atomically updates name, altitude, source, and sets {{is_locked = (source == MANUAL_USER)}}.
* {{suspend fun deleteLocation(id: Long)}}: Deletes location and refreshes flow.
* {{suspend fun refreshDem(id: Long, latLng: LatLng): ElevationResult}}: Invokes {{ElevationService.fetchElevation()}}.

h3. 1.4 State Management & Viewport Bounds Culling (KnownLocationsViewModel.kt)
* {{KnownLocationsUiState}} captures active locations, search filter, tab selection, metric/imperial units, and editing states.
* Viewport culling ({{onViewportBoundsChanged(bounds: LatLngBounds)}}) filters markers strictly inside the visible region, capping rendered map markers at 100 for 60 FPS performance.

h3. 1.5 Dual-Perspective Jetpack Compose Screen (KnownLocationsScreen.kt)
# *List Perspective*:
* Search/filter bar and location count badge.
* High-density Material 3 cards: Location Name, Altitude (m/ft), Provenance Source badge ({{INTERNET_DEM}}, {{MANUAL_USER}}, {{AUTO_LEARNED}}, {{GPS_FALLBACK}}, {{LEGACY_RAW}}), Hit Count badge, coordinates (5 decimals), and Action overflow menu (Edit, Show on Map, Delete).
# *Map Perspective*:
* Google Map rendering markers and 200m circular geofence overlays ({{CircleOptions}}, radius 200.0m, {{TTAlpha.HeatmapLow}} fill).
* Tapping a marker opens a bottom sheet with summary and "Bearbeiten" action.

h3. 1.6 Modal Edit Dialog (EditKnownLocationDialog.kt)
* Outlined text fields for Name and Altitude.
* "Fetch from Internet (DEM)" button with inline progress indicator.
* Save / Cancel actions: saving a manual edit automatically persists {{source = MANUAL_USER}} and {{is_locked = 1}}.

h3. 1.7 Unit Conversion Precision & Invariants
* Database storage strictly SI meters ({{Double}}).
* Metric manual edit preserves 0.1m precision.
* Imperial conversions: foot to meter manual save h_m = round(h_ft * 0.3048 * 10.0) / 10.0; display h_ft = round(h_m / 0.3048).

h3. 1.8 100% 9-Language Localization
* 16 new localized string resources across EN, DE, ES, FR, IT, JA, NL, PL, PT.
