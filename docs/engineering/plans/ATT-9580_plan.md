## 1. SWE.2 Architectural Decomposition & Threading Model

- **Constructor & Field Ordering (`WorkoutClusterRepository.kt:68-110`, strictly ABOVE `init {}`)**:
  - Add optional 3rd parameter `private val ioDispatcher: CoroutineDispatcher = Dispatchers.IO` to `internal constructor` (`getInstance(context)` and `getInstance(context, scope)` signatures unchanged, defaulting to `Dispatchers.IO`). Use `ioDispatcher` in `init`, `loadAllClustersLightweight()`, `refreshClusters()`, `refreshClustersAsync()`, `refreshClusterStats()`, and remaining repository IO `withContext` calls.
  - **Mandatory Declaration Above `init {}` (`:78-109`)**: Declare `private val hasCompletedFullRefresh = AtomicBoolean(false)`, `private val clusterStateVersion = AtomicLong(0L)`, and `private val statePublishLock = Any()` **before `init {}`** alongside `lightweightLoadMutex` and `_allClusters`/`_migrationStatus`/`_clusterStats` so synchronous `init` execution under `Dispatchers.Unconfined` never hits uninitialized fields.
  - `statePublishLock` strictly guards in-memory `StateFlow` assignments and `clusterStateVersion` bumps (ZERO SQLite I/O, ZERO suspending calls -> deadlock-free with recursive `refreshClusters()` -> `recalculateClustersWithProgress()` -> `refreshClusters()` and synchronous `ATT-9607` `syncClusterAfterWorkoutDeletion()`).
- **Concurrency, `yield()`, `try/finally` & Writeback Rules (`WorkoutClusterRepository.kt`)**:
  1. **`init` (`:135-147`)**: Launches on `ioDispatcher` and calls `loadAllClustersLightweight()` only if `_allClusters.value.isEmpty() && !hasCompletedFullRefresh.get()`.
  2. **`loadAllClustersLightweight()` (`:154-195`)**: Inside `lightweightLoadMutex.withLock`, runs a bounded retry loop `for (attempt in 0..1)`:
     - Captures `val startVersion = clusterStateVersion.get()` BEFORE `clusterDb.getAllClusters()`.
     - Reads `cached = clusterDb.getAllClusters()`; if `cached.isEmpty()`, returns `emptyList()`.
     - **Stale SQLite Writeback Guard**: Before `healUntrimmedClusterNames(cached)` and before each `clusterDb.updateCluster(updated)` (`hitCount` heal), checks `if (clusterStateVersion.get() != startVersion)`: if changed, aborts stale DB writebacks immediately; if `attempt == 0 && _allClusters.value.isEmpty() && !hasCompletedFullRefresh.get()`, `continue`s for **1 bounded retry** with fresh SQLite rows, otherwise returns `_allClusters.value`.
     - Hydrates `_clusterStats` (when empty) inside `synchronized(statePublishLock)` strictly if `clusterStateVersion.get() == startVersion && _clusterStats.value.isEmpty()`.
     - Publishes `_allClusters.value = sorted` inside `synchronized(statePublishLock)` strictly if `clusterStateVersion.get() == startVersion`; on mismatch, applies the same single-retry condition (`attempt == 0 && _allClusters.value.isEmpty() && !hasCompletedFullRefresh.get()`) or returns `_allClusters.value`.
  3. **`refreshClusters()` (`:229-394`)**:
     - Computes `val needsEnrichment = currentClusters.any { it.previewPaths.isEmpty() && it.hitCount > 0 }` and `val showProgress = forceShowProgress || (needsEnrichment && !hasCompletedFullRefresh.get())`.
     - **Fast Path FIRST (before any `_migrationStatus` write)**: `if (!needsEnrichment && !forceShowProgress && !forceCheckIntegrity)` loads `stats` and sorts `currentClusters`, then inside `synchronized(statePublishLock)` sets `_clusterStats`, `_allClusters`, `clusterStateVersion.incrementAndGet()`, `hasCompletedFullRefresh.set(true)`, and returns silently.
     - **Enrichment / Integrity Path (`try/finally` wrapping first `_migrationStatus` write)**: Opens `try { ... } finally { if (showProgress) _migrationStatus.value = null }` **immediately before** setting `Loading (0.0f)`. Whenever `showProgress == true`, calls cooperative `kotlinx.coroutines.yield()` immediately after setting `Loading (0.0f)`, `Healing (0.1f)`, and each `Previews` (`index % 5 == 0`) update — guaranteeing zero `StateFlow` conflation under `Dispatchers.Unconfined` / `StandardTestDispatcher` AND providing true cooperative cancellation checkpoints (`REQ-PER-057.3`). On completion, loads `stats`, sorts `enriched.filterNotNull()`, and inside `synchronized(statePublishLock)` publishes `_clusterStats`, `_allClusters`, increments `clusterStateVersion`, and sets `hasCompletedFullRefresh.set(true)` BEFORE `finally` clears `_migrationStatus` (`Rule 74`). On error/cancellation, `finally` clears `_migrationStatus` while `hasCompletedFullRefresh` stays `false`.
  4. **`refreshClusterStats()` (`:405-407`), `syncClusterAfterWorkoutDeletion()` (`ATT-9607`, `:414-447`) & `propagateClusterRename()` (`:511-534`)**: Perform DB queries outside `statePublishLock`; wrap in-memory `_allClusters`/`_clusterStats` writes (+ `clusterStateVersion.incrementAndGet()` in deletion/rename) inside `synchronized(statePublishLock)`.
- **Deterministic Test Architecture (`WorkoutClusterPreviewPersistenceTest.kt` & `WorkoutClusterRepositoryTest.kt`)**:
  - Use `ioDispatcher = Dispatchers.Unconfined` + `async(Dispatchers.Unconfined, start = CoroutineStart.UNDISPATCHED)` in `TST-PERF-010` and `TST-PERF-003`/`009`: `init` synchronously hydrates `_allClusters` with un-enriched rows before `refreshClusters()`, and `yield()` delivers every `MigrationStatus` phase deterministically without conflation.
  - Real-`Dispatchers.IO` multi-run stress test (`TST-PER-057.4`) asserts deterministic state/persistence invariants (`previewPaths` enriched & persisted in SQLite & published in `_allClusters.value`, `migrationStatus.value == null` on exit, warm restart strictly silent — zero unsynchronized cross-thread intermediate `StateFlow` assertions).
