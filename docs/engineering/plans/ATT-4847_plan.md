## 1. Problem Description & Background
Recurring route clusters (*Lieblingsstrecken* / `WorkoutCluster`) automatically generated by `WorkoutClusterEngine` are not visible on the General Map (`MapScreenWithTrack`) or the Cockpit live tracking map (`TrackingMapContainer`). We add `GeneralMapLayer.CLUSTERS`, wire `WorkoutClusterRepository.allClusters` into both map pipelines with referentially stable `latLngs` memoization (`REQ-MAP-051`), and render favorite tracks with distinct styling, decluttering controls, and inspection support.

## 3. System Invariants & Invariant Protections
1. **Referential Identity & Polyline Tessellation (`REQ-MAP-051.2`)**: Precompute decoded `latLngs` using a `ConcurrentHashMap<String, List<LatLng>>` cache to prevent OOM in Maps SDK vertex buffers.
2. **Static Layer Flow Decoupling (`REQ-MAP-051.1`)**: `WorkoutClusterRepository.allClusters` joins `staticMapLayerFlow` via `distinctUntilChanged()`, strictly avoiding re-allocation during 1-Hz `currentTrack` / `currentSpeed` updates.
3. **Recomposition Barrier Integrity (`REQ-UI-326`)**: `TrackingMapContainer` memoizes `mapContent` inside `remember` including `mapClusters`. Zero snapshot state writes in composition (Rule 66).
4. **Clean-Room Test Pass Rate**: 100% pass across targeted unit tests without `--rerun-tasks`.
5. **UI Consistency (Rule 23)**: Closest reference `MapScreenWithTrack.kt` floating layer menu. Uses `TTColor.Cluster` (`#8E24AA`), standard `DropdownMenuItem` with `12.dp` swatch, and `MaterialTheme` typography.
