## 1. SWE.2 Architectural Decomposition & Threading Model

- **Pure-JVM Main Cleanup (`banalservice/devices/bluetooth_le/polar/`)**: Remove `android.util.Log`, `org.json.JSONObject`, and `org.json.JSONException` from `PolarRawMetadata.kt` and `PolarRawTelemetryReader.kt` using pure-Kotlin JSON serialization/parsing and small-chunk `GZIPInputStream` reads (mirroring `PhoneRawMetadata` & `PhoneRawTelemetryReader`, strictly dropping non-newline-terminated trailing bytes). Preserves 100% public API & JSON schema parity.
- **Test-Scoped Replay Package (`app/src/test/java/com/atrainingtracker/banalservice/replay/`)**:
  - `OfflineReplayModels.kt`: Pure-JVM DTOs (`ReplayConfig`, `ReplayInputs`, `OfflineReplayScorecard`, `CadenceStats`, `CadencePairComparison`, `OfflineReplayDiff`, `OneHzReplayRow`, `GroundTruthSpec`, `GroundTruthCheckResult`) with deterministic dot-decimal formatting (`Locale.US`).
  - `OfflineTelemetryReplayHarness.kt`: Single-threaded deterministic chronological merger aligning smartphone `CLOCK_BOOTTIME` (`tRelMs = (elapsedRealtimeNs - firstPhoneNs) / 1_000_000L`) and Polar `elapsedMs` via stable `(tRelMs, sourceOrder, seqIndex)` sort, driving all production pure-Kotlin estimators (`PhoneCarriageClassifier`, `QuaternionGyroProjector`, `SmartphoneImuCadenceEstimator`, `KinematicSportTypeDiscriminator`, `UnicycleOdometryEkf(recordSnapshots = true)`, `KinematicAltitudeSlopeEkf`, `ExtendedRtsOdometrySmoother`, `ExtendedRtsAltitudeSlopeSmoother`, `PolarLiveRunningCadenceEstimator`, `PolarH10RunningDynamicsEstimator`) and producing scorecard + 1-Hz series.
  - `OfflineReplayGroundTruth.kt`: Pure-JVM JSON ground-truth parser & bound evaluator (`expectedDominantMode`, `minDominantModePct`, `maxTransitions`, `expectedDistanceM` ± tol, `expectedAscentM` ± tol, `maxCadenceMaeSpm`).
  - `OfflineReplayCli.kt`: Pure-JVM `main(args: Array<String>)` accepting `--phone`, `--polar`, `--polar2`, `--csv`, `--truth`, `--json`, printing formatted scorecard, writing optional CSV/JSON, and exiting non-zero on ground-truth violation or invalid args.
- **Lazy Gradle CLI Task (`app/build.gradle`)**: `tasks.register("replayRawTelemetry", JavaExec)` wired lazily in `afterEvaluate` to `testDebugUnitTest`'s classpath + `compileDebugUnitTestKotlin`/`compileDebugUnitTestJavaWithJavac`, passing `-PphoneRaw`, `-PpolarRaw`, `-Ppolar2Raw`, `-PcsvOut`, `-Ptruth`, `-PjsonOut` without touching `BuildConfig` or busting `Rule 8.6` build cache.
