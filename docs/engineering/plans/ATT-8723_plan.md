**Ticket**: `ATT-8723` (`2 SP`, `tier-a`, `REQ-CON-062`, `TST-CON-062`) | **Target Release**: `V5.0.0` | **Branch**: `feature/ATT-8723` | **Date**: 2026-11-24

## 1. Architectural Design, Thread Safety & Upgrade-Path Behavior (SWE.2 / SWE.3)
- **Dedicated Helper (`BleDisReconnectBackfillHelper.kt` in `com.atrainingtracker.banalservice.devices.bluetooth_le`)**:
  - Stateless `@JvmStatic` Kotlin `object` keeping `MyBTLEDevice.java` strictly `<= 1,500` LoC (`+3` LoC: `1,494 -> 1,497/1,500`) and `DevicesDatabaseManager.java` untouched (`1,665/1,671`):
    1. `fun needsManufacturerBackfill(currentManufacturerName: String?): Boolean` — returns `true` iff `currentManufacturerName == null || BleDisStringSanitizer.containsNul(currentManufacturerName) || BleDisStringSanitizer.sanitize(currentManufacturerName) == null`.
    2. `fun isCharacteristicReadQueued(queue: Queue<MyBTLEDevice.GattOperation>?, charUuid: UUID): Boolean` — scans `queue` for `ReadCharacteristicOp` matching `charUuid` (belt-and-suspenders dedup).
    3. `fun enqueueMissingManufacturerRead(device: MyBTLEDevice, gatt: BluetoothGatt?): Boolean` — guards `gatt == null || device.mIsShutDown || device.isGattPaused || device.deviceId <= 0L`; checks `needsManufacturerBackfill(device.manufacturerName)` and `!isCharacteristicReadQueued(device.mGattQueue, UUID_CHARACTERISTIC_MANUFACTURER_NAME)`; resolves `gatt.getService(UUID_SERVICE_DEVICE_INFORMATION)?.getCharacteristic(UUID_CHARACTERISTIC_MANUFACTURER_NAME)` and calls `device.enqueueReadCharacteristic(char)`.
    4. `fun onDisCharacteristicRead(device: MyBTLEDevice, gatt: BluetoothGatt?, snapshot: BluetoothGattCharacteristic?): Boolean` — checks `snapshot?.uuid == UUID_CHARACTERISTIC_MANUFACTURER_NAME` and `!device.mIsShutDown && gatt != null`; decodes `val clean = BleDisStringSanitizer.readSanitizedString(snapshot) ?: return false`; posts `device.applyBackfilledManufacturerName(gatt, clean)` onto `device.mHandler` (immediately returning on the Binder thread so `onGattOperationCompleted()` advances `mGattQueue` without waiting on SQLite).
    5. `fun enqueueMissingPolarDisReads(device: MyBTLEDevice, context: Context?, gatt: BluetoothGatt?, hasPmd: Boolean, hasPftp: Boolean): Int` — guards `!(hasPmd || hasPftp) || gatt == null || device.mIsShutDown || device.isGattPaused`; resolves `address = device.address`; checks `PolarOfflineCapabilityStore.getPolarDeviceId(context, address)`: if non-null, hydrates `PolarOfflineGattCoordinator.registerDeviceAliases(existingPolarId, address)` (preserving cold-start SDK alias matching without a GATT round-trip), else enqueues `0x2A25` if present and not queued; checks `BleDisStringSanitizer.sanitize(PolarOfflineCapabilityStore.getModelNumber(context, address)) == null` and enqueues `0x2A24` (before `0x2A25`, preserving exact `BTLEHeartRateDeviceTest` queue order) if present and not queued.
- **Minimal Wiring in `MyBTLEDevice.java` (`1,494 -> 1,497/1,500` LoC, `+3` LoC)**:
  1. `mGattCallback.onCharacteristicRead()` (`L754`, inside `if (status == GATT_SUCCESS ... && snapshot != null)`): add `BleDisReconnectBackfillHelper.onDisCharacteristicRead(this, gatt, snapshot);` (guarantees `GATT_SUCCESS` + immutable cloned snapshot; blocks failed-read stale bytes).
  2. `readNextCharacteristic(expectedGatt)` (`L1454`, immediately after `configureServices(gatt);`): add `BleDisReconnectBackfillHelper.enqueueMissingManufacturerRead(this, gatt);` (covers ALL 7 BLE subclasses incl. `BTLERadarDevice` which skips `super.configureServices(gatt)`, while placing `0x2A29` strictly behind telemetry CCCD & Radar/Polar setup).
  3. Package-private 1-liner: `void applyBackfilledManufacturerName(BluetoothGatt gatt, String name) { synchronized (mGattLock) { if (mIsShutDown || mIsGattPaused || mBluetoothGatt == null || gatt != mBluetoothGatt) return; } setManufacturerName(name); }` (re-verifies active handle under `mGattLock`, then updates `mCachedManufacturerName` + `Devices.db` via `MyDevice.setManufacturerName` outside `mGattLock`).
- **Conditional Polar Wiring in `BTLEHeartRateDevice.java` (`597 -> ~583` LoC, `-14` LoC)**:
  - Replace unconditional `if (hasPmd || hasPftp)` DIS `0x2A24`/`0x2A25` block (`L260-274`) with `BleDisReconnectBackfillHelper.enqueueMissingPolarDisReads(this, mContext, gatt, hasPmd, hasPftp);` strictly before `super.configureServices(gatt)`.
- **Upgrade-Path Impact for Existing Users (`coding_standards.md` §5.6)**: Existing paired BLE sensors with missing/cleared `manufacturerName` automatically backfill a clean sanitized manufacturer string on their next normal connection with zero user re-pairing; already-populated sensors incur zero additional GATT traffic; Polar sensors with populated `PolarOfflineCapabilityStore` save 2 GATT reads per reconnect while preserving cold-start SDK alias matching.
- **UI Consistency**: `N/A - 0 UI/Compose/string changes`.
