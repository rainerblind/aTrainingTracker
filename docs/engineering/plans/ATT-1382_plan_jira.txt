h2. Technical Architecture & Modifications

h3. 1. Navigation Drawer Hierarchy & Vector Asset Creation

h3. 2. Standard Tabbed Header Surface & Tab Row (KnownLocationsScreen.kt)
* *Header Surface*: Surface(color = MaterialTheme.colorScheme.primaryContainer) with Modifier.statusBarsPadding() and titleLarge text.
* *Tab Row*: PrimaryTabRow(containerColor = MaterialTheme.colorScheme.surfaceContainerHighest, divider = {}) with "Liste" and "Karte" tabs.
* *Pager*: HorizontalPager(state = pagerState) with 2 pages, synchronized bidirectionally with PrimaryTabRow.

h3. 3. Intelligent Fallback Map Centering (KnownLocationsViewModel.kt)
* Introduce getFallbackMapLocation(): resolves location with max hitCount (argmax(hitCount)), null if empty.
* Map centers on fallback location when opening map tab without GPS/selection; defaults to Munich if empty.

h3. 4. Custom Theme-Colored Map Markers
* Render custom BitmapDescriptor markers with primary theme pin body and contrasting white heart glyph.
* Eliminate default red Google Maps markers. Maintain 200m circular geofences.

h3. 5. List Item Card Standardization (MappableListItem)
* Wrap list cards in MappableListItem (ElevatedCard, 16dp rounded corners, 2dp elevation).
* Include Name, formatted Altitude chip, Provenance badge, Starts count badge, 5-decimal coordinates, and context overflow menu.

h3. 6. 9-Language Localization Parity
* Update German: drawer_start_locations and known_locations_title to "Lieblingsorte", known_locations_empty_title to "Keine Lieblingsorte".
* English: "Favorite Locations", "No Favorite Locations".
* 100% parity across all 9 locales (EN, DE, ES, FR, IT, JA, NL, PL, PT).
