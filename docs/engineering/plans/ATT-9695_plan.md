## 1. SWE.2 Architectural Decomposition & Concurrency Model

- **Layer 1 — `BANALService.java` (`1,085 -> ~1,115 / 1,500` LoC, lock-free `volatile`)**:
  - Add `private volatile BSportType mResolvedBSportType = BSportType.UNKNOWN;` (cleared inside `clearInferredSportTelemetry()`, which runs on `RESET_ACCUMULATORS_INTENT`, `onDestroy()`, and `SpeedAndLocationDevice_ATTFused.resetOriginAndEkf()`).
  - Add `public void setResolvedBSportType(@NonNull BSportType resolvedSport)` storing `(resolvedSport == BSportType.BIKE || resolvedSport == BSportType.RUN) ? resolvedSport : BSportType.UNKNOWN`, mirrored on `BANALServiceComm.setResolvedBSportType(@NonNull BSportType)` and static `BANALService.updateActiveResolvedBSportType(@NonNull BSportType)`.
  - Add `public BSportType getEffectiveBSportType()` & static `getEffectiveActiveBSportType()`: returns `mUserSelectedBSportType` if `mHaveUserSelectedSportType`; else `primary = getBSportType()`, returning `primary` if `!= UNKNOWN && != CONFLICT`; else `mResolvedBSportType`. Leaves `getAuthoritativeBSportType()` (`REQ-FIL-030.2`) and `getBSportType()` (`REQ-FIL-030.3`) strictly unchanged.
- **Layer 2 — `TrackerService.java` (`3,184 -> ~3,190 / 3,220` LoC)**:
  - Add private 4-line helper `propagateResolvedBSportType(@Nullable BSportType bSport)` calling `banalService.setResolvedBSportType(bSport)` (or `BANALService.updateActiveResolvedBSportType(bSport)` when `mBanalService == null`) if `bSport != null`.
  - Invoke right beside `SmartphoneRawTelemetryRecorder.updateSportState(...)` in `createNewWorkout()` (`:2275`), `onSearchingFinished()` (`:2303`), and `applyResumedState()` (`:1908`). Zero extra SQLite queries (reuses already-resolved `bSport`).
- **Layer 3 — `SmartphoneImuCadenceEstimator.kt` (`1,073 -> 1,120 / 1,500` LoC, pure-JVM `@Synchronized`) & `KinematicSportTypeDiscriminator.kt` (`533 -> 537 / 1,500` LoC)**:
  - Add `const val UNKNOWN_WALK_CONFIRM_DWELL_MS = 25_000L` (rejecting `18–20 s` pre-ride driveway bike-pushing in `2026-11-22_081402`), `private var unknownWalkStartTsMs: Long = Long.MIN_VALUE`, and lock-free `@Volatile var isRunningOrWalkingActive: Boolean = false; private set` (updated whenever `activeCategory` mutates via helper `setActiveCategory(cat)` so readers need zero locks).
  - Add `MIN_BIKE_CARRIAGE_VOTE_SPEED_MPS = 1.8` in `KinematicSportTypeDiscriminator.kt` gating `BIKE_*` carriage votes (`+1.2 * dt`) so walking-speed `BIKE_FRONT_POCKET` flickers (`1.1–1.56 m/s` on `2026-11-23_171814`) never latch Tier 3 `BIKE` while preserving `>= 2.0 m/s` MTB climbs.
  - Inside `syncModeState(mode, sportContext, timestampMs)`:
    - Before `resolveCategory(...)`, maintain `unknownWalkStartTsMs`: if `mode == WALKING_TRANSITION && sportContext == UNKNOWN`, initialize to `timestampMs` if `Long.MIN_VALUE` or reset if `timestampMs < unknownWalkStartTsMs`; else if `!(mode == STATIONARY && hasActiveCadenceSession && activeCategory == RUNNING_STEP && sportContext == UNKNOWN)`, reset `unknownWalkStartTsMs = Long.MIN_VALUE`.
    - In `resolveCategory(mode, sportContext, timestampMs)`:
      - `WALKING_TRANSITION` -> `RUNNING_STEP` if `sportContext == RUNNING` OR (`sportContext == UNKNOWN && unknownWalkStartTsMs != Long.MIN_VALUE && timestampMs - unknownWalkStartTsMs >= UNKNOWN_WALK_CONFIRM_DWELL_MS`), else `SUPPRESSED` (`CYCLING`/`OTHER` always `SUPPRESSED`).
      - `STATIONARY` -> keep `activeCategory` only when `hasActiveCadenceSession` AND `sportContext != OTHER` AND `!(sportContext == CYCLING && isRunningCategory(activeCategory))` AND `!(sportContext == RUNNING && isBikeCategory(activeCategory))`; else `SUPPRESSED`.
    - Reset `unknownWalkStartTsMs = Long.MIN_VALUE` and `isRunningOrWalkingActive = false` in `suppressAll()` and `reset()`.
- **Layer 4 — `SpeedAndLocationDevice_ATTFused.kt` (`1,473 -> 1,489 / 1,500` LoC, zero nested locks, Gate 3 Watchpoint 1)**:
  - Add `@Volatile private var mLastObservedSportHint: SportContextHint = SportContextHint.UNKNOWN` (reset in `resetOriginAndEkf()`, which also calls `BANALService.updateActiveResolvedBSportType(BSportType.UNKNOWN)` in its non-`BANALService` fallback branch).
  - Update `resolveActiveBSportType()` to query `(mContext as? BANALService)?.effectiveBSportType ?: BANALService.getEffectiveActiveBSportType()`.
  - Update `resolveSportContextHint()`: if `mExplicitSportHintForTest != null` return it; else if `activeSport == BSportType.UNKNOWN && isUserSportLocked()` return `SportContextHint.OTHER`; else `SportContextHint.fromBSportType(activeSport)`.
  - Add `private fun isStridesAllowed(sportHint: SportContextHint): Boolean = sportHint == SportContextHint.RUNNING || (sportHint == SportContextHint.UNKNOWN && cadenceEstimator.isRunningOrWalkingActive)` (reads `@Volatile`, zero lock nesting with `this` / `mCadenceLock` / `mYawRateLock`).
  - In `updateCarriageClassification()` (1 Hz): publish `mCachedCarriageMode = mode` under `mYawRateLock` strictly BEFORE checking `hint != mLastObservedSportHint`; on hint change call `handleSportTypeChanged(timestampMs)` (which syncs `mLastObservedSportHint = sportHint`); in `else if (modeChanged)` also call `if (!isStridesAllowed(hint)) unregisterStridesSensor()`.
  - In `handleSportTypeChanged()` (ordered: `mYawRateLock` -> `mCadenceLock` `onModeOrSportChanged` -> `!isStridesAllowed` `unregisterStridesSensor` -> `flushCadenceAndStrideOutputs`) and `applyCadenceAndStrideSensors()`: gate `STRIDES` via `isStridesAllowed(resolveSportContextHint())` while preserving non-retroactive `mLastEstimatorTotalStrides` sync.
- **SWE.3 Maintenance**: Sync `docs/architecture/detailed_design/banal_service.md` (`IF-SWE-03`, `mResolvedBSportType`, `getEffectiveBSportType()`) and `tracker_service.md` (`onSearchingFinished`/`createNewWorkout`/`applyResumedState` propagation) in Stage 4/5.
