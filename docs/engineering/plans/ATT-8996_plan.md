# Stage 3: Implementation Plan — ATT-8996

**Ticket**: `ATT-8996` (`2 SP`, `tier-a`, `REQ-CON-060`, `TST-CON-060`) | **Target Release**: `V5.0.0` | **Branch**: `feature/ATT-8996` | **Date**: 2026-11-24

## 1. Architectural Design, Thread Safety & Upgrade-Path Behavior (SWE.2)
- **Shared Sanitizer (`BleDisStringSanitizer.kt` in `com.atrainingtracker.banalservice.devices.bluetooth_le`)**:
  - Pure-JVM stateless `object BleDisStringSanitizer` with `@JvmStatic` API (Java-callable, reusable by `ATT-8723`):
    - `fun sanitize(raw: String?): String?` — strips every `'\u0000'` (`raw.replace("\u0000", "").trim().takeIf { it.isNotEmpty() }`).
    - `fun readSanitizedString(characteristic: BluetoothGattCharacteristic?): String?` — reads `characteristic?.getStringValue(0)` (falling back to `characteristic.value?.let { String(it, StandardCharsets.UTF_8) }` if `getStringValue(0)` is `null`), then returns `sanitize(...)`.
    - `fun containsNul(value: String?): Boolean` — returns `value != null && value.indexOf('\u0000') >= 0`.
    - `fun sanitizeExistingDevicesTable(db: SQLiteDatabase): Int` — queries `Devices4 (_id, name, manufacturerName)` using `use { cursor -> ... }`, checks each row (`raw != null && (containsNul(raw) || raw != raw.trim())`), applies `sanitize(raw)` (`putNull` when sanitized is `null`), updates strictly dirty rows via `db.update(DEVICES, values, "_id=?", arrayOf(id))`, and returns updated row count. Stateless, idempotent, zero dialect dependence on SQLite `CHAR(0)`/`TRIM`, zero lock nesting.
- **BLE GATT / GAP / Polar DIS Read Wiring**:
  - `BTSearchForNewDevicesEngine.java`: `L117` (`mNameMap.put(addr, BleDisStringSanitizer.sanitize(gatt.getDevice().getName()))`), `L198` (`0x2A29` -> `readSanitizedString`, put in `mManufacturerMap` if non-null), `L202` (`0x2A24` -> `readSanitizedString`), `L208` (`0x2A25` -> `readSanitizedString`).
  - `BTLEHeartRateDevice.java`: `L396` (`0x2A24` -> `readSanitizedString`), `L399` (`0x2A25` -> `readSanitizedString`).
  - `BTLERadarDevice.java`: `L783` (`0x2A24` -> `readSanitizedString`, so NUL-only `"\u0000"` yields `null` and falls back cleanly to `completeLightControlRegistration(gatt, null, false, false, true, true)`).
  - `PolarPmdStreamCoordinator.kt`: `L213-215` (`recordDisCharacteristic` sanitizes both `key` and `value` via `BleDisStringSanitizer.sanitize(...)`).
- **`PolarOfflineCapabilityStore.kt` & `PolarOfflineGattCoordinator.kt`**:
  - Replace Kotlin `.trim()` with `BleDisStringSanitizer.sanitize(...)` in `isValidCanonicalPolarId`, `recordDisMetadata`, `recordSdkDeviceType`, `seedLegacyDeviceTypeIfUnknown`, `classifyModelNumber`, `getModelNumber`, `getPolarDeviceId`, and `normalizeMac`.
  - Self-healing reads in `getModelNumber` & `getPolarDeviceId`: when raw persisted SharedPreferences value differs from sanitized result (`raw != null && raw != sanitized`), write back `putString(key, sanitized)` (or `remove(key)` if `sanitized == null`) asynchronously via `apply()` so dirty values are permanently cleaned on first read.
  - `PolarOfflineGattCoordinator.kt`: sanitize `name` / `manufacturer` in `isPolarH10Name`, `isPolarVeritySenseName`, and `hasExplicitNonPolarManufacturer` (`+1` LoC: `1,485 -> 1,486 / 1,500`).
- **`Devices.db` Sanitization & v14 -> v15 Migration (`coding_standards.md` §2.2, §2.3, §5.6)**:
  - `DevicesDatabaseManager.java` (`1,657 -> ~1,664 / 1,671` LoC): sanitize `name`/`manufacturerName` inline on write (`insertNewBluetoothDeviceIntoDB`, `insertNewAntDeviceIntoDB`, `setManufacturerName`) and read (`getManufacturerName`, `getDeviceName`, `getAllDevicesForCache`, `getDeviceIdAndNameLists`, `getCriticalBatteryDevices`, `getSensorsForSportType`, `getAllRemoteSensors`); bump `DevicesDbHelper.DB_VERSION = 15`, add `case 15:` in `onCreate()` (100% schema parity with `CREATE_DEVICE_DB_14`), and invoke `BleDisStringSanitizer.sanitizeExistingDevicesTable(db)` in `onUpgrade(oldVersion <= 14 && newVersion >= 15)`. `DatabaseSchemaRegistry` references `DevicesDbHelper.DB_VERSION` directly (`Rule 2.2`).
  - `RawDeviceDataProvider.kt:46-47` & `DeviceDataRepository.kt:588`: sanitize cursor reads (`MANUFACTURER_NAME`, `NAME`) and `NAME` updates via `BleDisStringSanitizer.sanitize(...)`.
  - **Upgrade-Path Impact for Existing Users**: Existing `Devices.db` v14 databases (e.g., Pixel 10 `"Polar Electro Oy\u0000"`) and restored v14 `.attbackup` archives are automatically cleaned on open with zero schema change, zero data loss, and zero behavioral change for already-clean rows; dirty `PolarOfflineCapabilityStore` SharedPreferences entries self-heal transparently on first read.
- **UI Consistency**: `N/A - 0 UI/Compose/string changes`.
