# Stage 1 Analysis — ATT-9177: Polar Verity Sense Optical PPI in Morning HRV Check & Baseline Isolation

## 1. Problem Statement & Motivation
Morning resting HRV readiness checks currently assume an ECG chest strap, creating friction when athletes want a quick waking `rMSSD` check using a slip-on **Polar Verity Sense** optical armband. Optical PPG pulse-to-pulse intervals (PPI) exhibit systematic offsets vs ECG R-R intervals (~6–15% MAPE) and mild pulse-wave damping that can trigger false-positive ECG "smoothed stream" warnings in `HrvSignalQualityAnalyzer` and silently contaminate an athlete's existing 60-day ECG chest-strap Smallest Worthwhile Change (SWC) baseline if mixed into the same cohort.
