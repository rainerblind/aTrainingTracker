## 2. Proposed Architecture & Downstream `ATT-9349` Replay Contract

- **Files & Path**: `files/raw_sensor/<fileBaseName>.phone_raw.csv.gz` (active `.phone_raw.csv.gz.tmp`, lazy open on first frame -> zero empty files when disabled or non-ATTFused GPS active).
- **Bounded Zero-OOM Writer (`REQ-STB-023` parity)**: `Channel<PhoneRawTelemetryRow>(capacity = 8192, onBufferOverflow = BufferOverflow.DROP_OLDEST, onUndeliveredElement = { droppedFrameCount.incrementAndGet() })`, single `Dispatchers.IO` consumer, single reusable `StringBuilder` (`appendCsvLine`, **zero `String.format` per row**), periodic flush (`~5 s` / `256` rows) through `GZIPOutputStream(..., syncFlush = true)` so mid-workout crash salvage retains nearly 100% of frames; `stop()` joins writer, writes atomic rename, and cancels its private `CoroutineScope`.
- **Crash-Recovery Salvage (`REQ-STB-025` parity)**: `PhoneRawSidecarRecovery` mirrors `PolarRawSidecarRecovery` (`.tmp` -> `.salvage` small-chunk `GZIPInputStream` read + strict CSV row validation -> valid `.phone_raw.csv.gz` or resume append), triggered both in `TrackerService.applyResumedState()` and as export-time fallback in `RawSensorFileExporter` / uploaders.
- **Self-Describing Schema for `ATT-9349` Pure-JVM Replay**:
  - Header: `# metadata: {"schemaVersion":1,"appVersion":"...","deviceModel":"...","sportId":...,"sessionStartTimeMs":...}` + CSV columns `elapsedRealtimeNs,epochMs,channel,v0,v1,v2,v3,v4,v5`.
  - Channels: `ACC(ax,ay,az)`, `GYRO(gx,gy,gz)`, `ROTVEC(qx,qy,qz,qw)`, `BARO(pressureHpa,altM)`, `STEP()`, `GNSS(lat,lon,altM,speedMps,bearingDeg,accM)`, `WHEEL(speedMps,var)`, `STATE(sportId,bSportCode,carriageCode)`.
  - Pure-JVM `PhoneRawTelemetryReader` parses metadata & streams typed `PhoneRawTelemetryRow` records with truncated-gzip resilience for `ATT-9349`.

## 3. Chesterton's Fence Archaeology

- **Original Requirement ID & Target**: `REQ-SET-117` (`ATT-8019`), `REQ-EXP-044` (`ATT-8019`), `REQ-STB-023` (`ATT-9343`), `REQ-STB-025` (`ATT-9344`), `REQ-DAT-032.2` (`BackupRulesXmlValidationTest`), `REQ-PRO-129.2` (`ArchitectureConformanceContractTest` monolith LoC ceilings).
- **Architectural Rationale**: Raw sidecars intentionally live outside `WorkoutSamples.db` as compressed GZIP files under `files/raw_sensor/` to prevent SQLite write amplification/OOM, use `DROP_OLDEST` bounded queues + zero-`String.format` formatting to hold flat heap under 50–200 Hz streaming, and remain strictly opt-in / retention-pruned to protect flash storage and battery.
- **Invariant Preservation**: Existing `.polar_raw.csv.gz` format/path/recovery/export behavior stays 100% byte-compatible; `FileFormat.RAW_SENSOR` enum & DB columns stay unchanged; default toggle is `OFF` (`false`) for zero runtime/storage overhead; `SpeedAndLocationDevice_ATTFused.kt <= 1,500`, `TrackerService.java <= 3,559`, `TuningPreferencesDataStore.kt <= 2,410`, `TrainingApplication.java` untouched.
- **Refactor / Removal Policy**: No existing behavior is removed; `PolarRawTelemetryRecorder` stays focused on Polar BLE while `RawSensorSidecarFiles` generalizes multi-file export/pruning cleanly across both Polar and smartphone sidecars.

## 4. System Invariants

1. **Zero Overhead When Disabled**: With `recordSmartphoneRawTelemetryEnabled == false` (default), `0` sensor allocations, `0` background writers, and `0` `.phone_raw.csv.gz*` files are created.
2. **Bounded Memory & Non-Blocking Sensor Thread**: `Channel(8192, DROP_OLDEST)` + `trySend` never blocks `SensorEventListener` / `LocationListener`; `0` `String.format` per row; `CoroutineScope` cancelled on `stop()`.
3. **Crash-Safe & Multi-File Export Parity**: Truncated `.phone_raw.csv.gz.tmp` recovers cleanly on resume or export; local Downloads, Dropbox, and Google Drive export ALL present `RAW_SENSOR` sidecars (`.polar_raw.csv.gz`, `.phone_raw.csv.gz`, or both) without failing when one is absent.
4. **Privacy, Backup & Retention Hygiene**: `raw_sensor` excluded from Android Auto Backup & device transfer; `SensorDiagnosticBundlePackager` respects `includeGps`; `PolarRawTelemetryPruner` cascades deletes & retention across both sidecar types.
