## Context & Problem Statement
Four high-duplication patterns span the persistence, migration, tracking, and aftermath layers:
1. **10 Java `*DatabaseManager` classes** duplicate identical non-`volatile` `mDatabase` double-checked locking + `ATT-289` reopen-if-closed `getDatabase()` boilerplate.
2. **10 production files** (22 call sites) reimplement ad-hoc `PRAGMA table_info(...)` column checks and `ALTER TABLE ... ADD COLUMN` helpers.
3. **`TrackingViewsRepository.kt`** duplicates `withContext(Dispatchers.IO)` + `withContext(Dispatchers.Main) { configUpdateTrigger.value++ }` across 25 mutation methods, while Kotlin DB managers repeat `beginTransaction()/setTransactionSuccessful()/endTransaction()` and `Cursor` iteration loops (Java already has `CursorUtils`).
4. **Spatial bounding-box, polyline/stream downsampling, and ascent/descent math** are duplicated across finalization, altitude-shift, crop, legacy import, ERTS recomputation, routes, and segments.

## Independent Peer Review & Verification (4-Augen-Prinzip on `7522ab4d`)
Live audit against `sprint/2026-11-21_03_Nacht` (`7522ab4d`) verified all ticket claims and caught critical drift & hidden invariants:
- **`*DatabaseManager` Inventory (18 total = 10 Java + 8 Kotlin)**: All **10 Java managers** (`DevicesDatabaseManager`, `SportTypeDatabaseManager`, `KnownLocationsDatabaseManager`, `LapsDatabaseManager`, `TrackingViewsDatabaseManager`, `WorkoutSamplesDatabaseManager`, `WorkoutSummariesDatabaseManager`, `ExportStatusDatabaseManager`, `SegmentsDatabaseManager`, `PebbleDatabaseManager`) share the exact non-`volatile` `mDatabase` + `ATT-289` reopen pattern. Kotlin managers (8, incl. new `HrvReadinessDatabaseManager`, `WorkoutRrDatabaseManager`) use Kotlin delegates/properties and stay out of `BaseDatabaseManager`.
- **Test Reflection Coupling (`mDatabase`) — Critical Invariant**: **12 test files** (`SegmentsDatabaseManager{Deduplication,Pr,TTL}Test`, `KnownLocationsDatabaseManager{,Home}Test`, `KnownLocationsManualCalibrationTest`, `WorkoutSummaries{DatabaseManager,CardioPowerTrend}Test`, `TrackingViews{DatabaseManager,RealSqliteMigration}Test`, `LapsDatabaseManagerTest`, `MeasuredNfrBenchmarkTest`) invoke `Subclass::class.java.getDeclaredField("mDatabase")`. Moving `mDatabase` into `BaseDatabaseManager` will throw `NoSuchFieldException` unless `BaseDatabaseManager` exposes `@VisibleForTesting setDatabaseForTesting(SQLiteDatabase)` / `closeDatabase()` and those 12 tests are updated cleanly.
- **`PRAGMA table_info` Inventory (10 files, 22 sites — up from 8)**: Original 8 (`ExportStatusDatabaseManager:756`, `ImportEngine:576`, `WorkoutRepository:670,2021`, `WorkoutSummariesDatabaseManager:2686,2719`, `WorkoutClusterDatabaseManager:787`, `TrackingViewsDatabaseManager` [12 sites], `TrackerService:2982`, `SportTypeDatabaseManager:899`) **plus 2 new files**: `DevicesDatabaseManager:1464` and `MultisportLapCoordinator:536`. `TrackerService.getTableColumnNames` (`@VisibleForTesting public static`) must remain a delegating facade preserving `ATT-4968` double-quoted table identifier escaping (`REQ-TRK-051.1`). `ImportEngine:576` needs full column metadata (`name, type, notnull, dflt_value, pk`).
- **`TrackingViewsRepository.kt` (860 LoC)**: **28×** `withContext(Dispatchers.IO)` (3 pure reads + **25×** mutations) and **25×** `configUpdateTrigger.value++` (2 return values: `moveTabView(): Int`, `copyTabView(): List<Long>`). A generic `private suspend fun <T> mutateViewConfig(block: () -> T): T` replaces all 25 blocks.
- **`StreamSummaryCalculator` Audit & AC2 Corrections**:
  - `WorkoutSummariesDatabaseManager.updateMapAndStreams` (`L1369-1393`) and `migrateSpatialBoundsStatic` (`L2978-3014`) compute **bounding boxes** from decoded polylines (not ascent).
  - `shiftAltitudeData` Case A (`L1484-1497`) & Case B (`L1517-1530`) live in **`WorkoutSummariesDatabaseManager.java`** (not `WorkoutSamplesDatabaseManager` as cited in Jira comment #3) and use raw positive/negative delta sums.

  - `LegacyImportEngine.recalculateStats` (`L1079-1131`) uses 5-min moving average (`windowSize = 300`, `ATT-301`) truncated to `Int`, `PolyUtil.simplify(points, 10.0)`, 5-sample stride (`(i+1) % 5 == 0` if `size > 5`), and bounding box.
  - `TrackerService.finalizeLiveSession` (`L3185-3197`), `WorkoutSummariesDatabaseManager.migrateOneWorkout` (`L3101-3145`), `ErtsPostWorkoutRecomputer` (`L126, L776-798` — new 8th stream site), `SegmentsDatabaseManager` (`L341, L785`), and `RoutesDatabaseManager` (`L150, L1031`) duplicate bounding-box and/or simplify+encode+subsample logic. `LiveWorkoutSession.java` (`L278-326`) performs stateful 1-Hz incremental encoding and remains separate.
- **Layering & Ratchet Guardrails (`ArchitectureConformanceContractTest`)**: `trainingtracker/database/` forbids net-new `com.atrainingtracker.*.ui` imports and `banalservice/database/` must stay at `0`. Place `BaseDatabaseManager<H>`, `SqliteSchemaUtils`, and `DatabaseExtensions` in `com.atrainingtracker.database` (alongside `CursorProvider.java`) and `StreamSummaryCalculator` in `com.atrainingtracker.trainingtracker.util` (`docs/coding_standards.md` §1.1). Bonus ratchets: removing `NumericalEncodingUtils` from `ErtsPostWorkoutRecomputer.kt` ratchets `BASELINE_ALLOWED_DATABASE_UPWARD_UI_IMPORTS` (`10 -> 9`), and shrinking `WorkoutSamplesDatabaseManager.java` (`1,533 -> <=1,500` LoC) ratchets `MAX_MONOLITH_FILE_LOC_BASELINE` (`15 -> 14`).

## Requirements Archaeology (Chesterton's Fence — `REQ-PRO-022`)
- **Original Requirement ID & Target**: `REQ-DAT-043` (`TryWithResourcesCursorAuditTest`, `CursorUtils`), `REQ-TRK-051.1` (`TrackerService.getTableColumnNames`), `REQ-MIG-041.3` (`DatabaseConnectionManager.getActiveDatabases`), `REQ-DAT-023` (`LegacyImportEngine`/`TrackerService` Douglas-Peucker + compact streams).
- **Historical Origin & Commit Trace**: `ATT-289` (`773e3eb2` closed-DB reopen during backup), `ATT-4968` (`25f1e2c6` PRAGMA table_info bypassing API<=34 prepared-statement cache staleness), `ATT-3550`/`ATT-6123` (`REQ-DAT-043` cursor leak guard), `ATT-9244` (`33a060a1` `PebbleDatabaseManager.close()`/`isDatabaseOpen()`), `ATT-301` (5-min moving average ascent/descent).

- **Preservation of Core Invariants**: Keep `public SQLiteDatabase getDatabase()` with `volatile mDatabase` + `ATT-289` helper close/reopen on `BaseDatabaseManager`; keep `PebbleDatabaseManager.close()`/`isDatabaseOpen()` and `ExportStatusDatabaseManager` test hooks; preserve `ATT-4968` quoted-table PRAGMA; preserve byte-for-byte caller-specific ascent/downsampling/polyline outputs via pre-refactor Golden-Value tests; zero DB schema version increments (`DatabaseSchemaRegistry` parity unchanged).
