# Stage 1 Analysis: ATT-8128 — SQLite DatabaseManager, DeviceDataRepository & WorkoutDataMapper Fixes

**Ticket**: `ATT-8128` (`tier-a`, 2 SP, Epic `ATT-8119`) | **Branch**: `feature/ATT-8128` (base `03c1a8c3`) | **Target Release**: `V5.0.0` | **Req**: `REQ-DAT-048`

## 1. Problem Domain & Root Causes
Hand-written SQLite boilerplate and localized UI-string matching across database managers, `DeviceDataRepository`, `WorkoutDataMapper`, and `WorkoutRepository` cause silent `NULL -> 0` corruption, full-table scans, cursor leaks, redundant SQLite reads, unfiltered unpaired remote devices, and locale-switch regressions.

## 3. Scope Bounding & Non-Goals
- **In Scope**: The 7 verified defect areas above (`REQ-DAT-048.1`–`.5`) and targeted unit/contract tests (`TST-DAT-044`).
- **Out of Scope**: SQLite schema version bumps (`DB_VERSION` untouched), `WorkoutClusterRepository.moveOrAssignWorkoutToCluster` (covered by `TrackOnMapClusterActionViewModelTest`), UI copy/string changes (`0` `strings*.xml` edits), and unrelated `ATT-8120` Stage-2 refactorings.

## Change Impact Analysis
1. **Requirements & Specifications**: Adds net-new `REQ-DAT-048` (`REQ-DAT-048.1`–`.5`, `Derived (SW-only)`) and `TST-DAT-044` (`TST-DAT-044.1`–`.5`) in `req_data_migration_export_part2.md` / `tst_data_migration_export.md`; refines `REQ-STB-021.4` (`LastActiveDateFormatter` retains ThreadLocal zero-churn caching while upgrading write format to UTC ISO-8601 with backward-compatible legacy parsing). `SYS.2`/`SYS.3` unchanged (`REQ-PRO-131`).
2. **Architecture & Detailed Design**: No new database tables, schema versions, modules, or upward/downward layer crossings (`ArchitectureConformanceContractTest` baselines preserved). `WorkoutSamplesDatabaseManager.java` shrinks below `1,500` LoC; `WorkoutSummariesDatabaseManager.java`, `DevicesDatabaseManager.java`, and `WorkoutRepository.kt` remain strictly within monolith ceilings; `docs/architecture/detailed_design/workout_repository.md` symbols remain valid (`DetailedDesignParityContractTest`).
3. **Codebase & Callers**: Trailing optional `val sensorType: SensorType? = null` on `ExtremaDataRow` is 100% source-compatible with all previews and tests; `reloadWorkoutData(workoutId: Long)` retains exact binary signature; `LastActiveDateFormatter.parseToEpochMillis()` unifies `DeviceStatusRow` and `DeviceSortOrder` parsing with 100% backward compatibility for pre-`ATT-8128` locale rows; `WorkoutSummariesDatabaseManager` callers already handle `@Nullable`.
4. **Tests & Verification**: Updates `DevicesDatabaseManagerLastActiveTest` (for UTC ISO-8601 + legacy parity) and adds targeted unit tests across all 5 sub-requirements plus contract suites (`ArchitectureConformanceContractTest`, `TryWithResourcesCursorAuditTest`, `DetailedDesignParityContractTest`, `DatabaseSchemaRegistryParityContractTest`). Because `WorkoutRepository.kt` and DB managers are modified (`INSTALL_REQUIRED=true`), Stage 5 includes a live `emulator-5554` boot smoke test + `Rule 8.5` PNG inspection.
