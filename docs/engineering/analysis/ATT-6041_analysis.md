* **Current Behavior**: Organic feature growth across `ui/map/` and `ui/clusters/` left three distinct duplication hotspots: (1) 5 parallel marginal histogram `Canvas` loops across `ElevationProfile.kt:1091-1134` and `TelemetryMetricGraph.kt:726-759, 761-799, 1497-1532, 1664-1707` with diverging geometry/alpha/clamping flags; (2) 4 copy-pasted time/distance X-axis tick `while` loops in `ElevationProfile.kt:777-839` and `TelemetryMetricGraph.kt:906-976`; and (3) `ClusterMapPreviewLiveMap`/`Polylines`/`Markers`/`InspectionContent` (`WorkoutClusterComponents.kt:654-830`, ~190 LoC) manually duplicating Lite-Mode `GoogleMap` setup, `DarkMapStyle`, `DarkMapAntiFlashOverlay`, and markers instead of delegating to `PathPreviewMap.kt`.

## 2. Root Cause Analysis & Independent Hypothesis Verification
* **Root Cause**: Incremental additions (`REQ-UI-220`, `REQ-UI-251`, `REQ-UI-431`, `REQ-UI-443`, `REQ-UI-446`, `REQ-UI-493.3`) cloned inline `Canvas` loops and Lite-Mode `GoogleMap` wrappers rather than extracting shared parameterized primitives.

  * **5 Marginal Histogram Loops Confirmed (With Subtle Divergences)**: All 5 loops exist across two bin DTOs (`LinearHistogramBin` Double bounds vs `TelemetryHistogramBin` Int bounds): (a) `ElevationProfile.kt:1091-1134` (`drawRect`, fg alpha `1.0f`, `rectHeight <= 0f -> continue`, `durationSec > 0L` gate); (b) `TelemetryMetricGraph.kt:726-759` (zoned `HISTOGRAM`, `drawRect`, fg `1.0f`, currently calls `.coerceAtLeast(1f)` at `:741` without explicit `durationSec > 0L` gate); (c) `TelemetryMetricGraph.kt:761-799` (non-zoned portrait, `drawRect`, fg `1.0f`, `rectHeight <= 0f -> continue`, `durationSec > 0L` gate); (d) `AlignedMarginalLinearDistribution` (`:1497-1532`, `drawRoundRect(2.dp)`, fg `0.85f` asserted by `TelemetryMetricGraphHrvUiTest.kt:237,509`); (e) `AlignedMarginalZoneDistribution` (`:1664-1707`, `drawRoundRect(2.dp)`, fg `0.85f`, `.coerceAtLeast(1f)` at `:1678`, plus `"${bin.percentage.toInt()}%"` overlay when `rectHeight >= 12.dp && durationSec > 0L`). Shared helper MUST filter/clamp `[dataMin, dataMax]` first (`Rule 70`), check `rectHeight <= 0f -> continue` before any optional `minBarHeightPx`, draw unconditional `0.15f` background tracks (`Rule 69`), gate foreground on `durationSec > 0L && barWidthPx > 0f`, and parameterize `cornerRadiusPx`, `foregroundAlpha`, and optional `onBinDrawn`.
  * **4 X-Axis Tick Loops Confirmed (With Distinct Rendering Hooks)**: `ElevationProfile.kt:777-839` draws bottom ticks (`height -> height - 10f`) *only* when `ElevationProfileZoomMath.shouldRenderTickLabel` passes (`minSpacing = 24.dp`), using locale-aware distance formatting; `TelemetryMetricGraph.kt:906-976` draws full-height vertical gridlines for *every* in-bounds tick and gates labels via `TelemetryMetricUtils.shouldRenderMilestoneLabel` (`minSpacing = 12.dp`) + `TelemetryMetricUtils.formatMilestoneLabel`. Helper MUST separate `onTickInBounds` from `onLabelRendered` and accept `(step, formatLabel, shouldRenderLabel)`.
  * **`PathPreviewMap` & `WorkoutClusterComponents` Live Drift**: `PathPreviewMap.kt` (`676` LoC) already has `paths: List<MappablePath> = emptyList()`, `7` active callers (`RouteItem`, `CropWorkoutScreen`, `WorkoutSummary` ×2, `WorkoutClusterSplitSheet`, `MoveLapBoundaryOnMapSheet`, `CreateLapOnMapSheet`), and `ATT-8736` (`REQ-MAP-068`) Web Mercator initial camera seeding + `MapEffect` retry framing.   * **Explicit Exclusions Verified**: `ClusterNamingDialog` (`ImportBackupTabsScreen.kt:992-1022`) is the sole `GoogleMap` in that file, intentionally **interactive** (`200.dp`, no `liteMode`, localized marker titles) — MUST stay untouched.
