## 3. Acceptance Criteria (Given-When-Then)

- **Given** a manipulated ZIP archive with `../` traversal entries or unsafe remote filenames in an Auto-Import cloud folder, **When** `AutoImportManager.syncIncremental` or `LegacyImportEngine.bulkRecoverFrom*` executes, **Then** both route through `CloudWorkoutSourceScanner` & `SecureZipExtractor`, reject every traversal/symlink/zip-bomb payload (`failedCount` incremented, zero escaped files), apply `RateLimitException` backoff, and still import valid sibling workouts with accurate dedupe/skip/fail counts and clean cancellation.
- **Given** a valid `.attbackup` archive passed to `BackupRestoreViewModel.analyzeImport` followed by `performIncrementalImport` (or dismissed via `clearState()` / `onCleared()`), **When** preview and incremental import execute, **Then** the archive is copied and unpacked via `SecureZipExtractor.extractBackupArchive` **exactly once**, atomic SQLite `ATTACH` import reads directly from the validated staging directory, and all temporary files and staging directories are unconditionally deleted on completion, error, or cancellation.
- **Given** TCX, GPX, and FIT workouts/courses and RR beat streams across live/post-workout/resting HRV callers, **When** parsed or evaluated, **Then** `TcxTrackpointParser.kt` and `TCXFileWriter.buildLap` do not exist, all formats implement `WorkoutParser`, TCX/GPX consume single-pass streaming callbacks without intermediate trackpoint lists, and all 4 HRV callers delegate to `HrvRmssdCalculator` with documented thresholds.
