# Stage 2 Requirement & Test Specification: Post-Workout ERTS Pause-Gap Decoupling (`ATT-9242`)

- **Ticket**: `ATT-9242` (`tier-a`) | **Target Release**: `V5.0.0` | **Localization Parity**: `N/A - 0 string changes`
- **Reserved IDs**: `REQ-FIL-045` (`.1`–`.3`) <-> `TST-FIL-045` (`.1`–`.3`) | **System Reqs**: `SYSREQ-TRK-003`, `SYSREQ-TRK-004`, `SYSREQ-TRK-005`

## 1. Formal Requirements (`REQ-FIL-045`)
- **`REQ-FIL-045.1` (Pause-Aware Timing Reconstruction & Recomputer Integration)**:
  - `ErtsPostWorkoutRecomputer.readWorkoutSamples()` SHALL read `SensorType.TIME_ACTIVE` alongside `SensorType.TIME_TOTAL` and `time`. `reconstructTimingWithPauses()` SHALL detect pauses at row `i > 0` via: (a) wall pause `(parsedTs - oneHzTs) > 5_000L` (overflow-safe), (b) `TIME_TOTAL` pause `extraGapSec >= 5L`, OR (c) paired `TIME_TOTAL`/`TIME_ACTIVE` pause `deltaTotal > 0L && deltaActive >= 0L && (deltaTotal - deltaActive) > 2L && extraPairGapSec >= 2L` (where `extraPairGapSec = deltaTotal - (i - prevPairIdx)`), advancing `ts` via `timeActivePauseTs = oneHzTs + extraPairGapSec * 1000L` merged with `max(wallPauseTs, timeTotalPauseTs, timeActivePauseTs)` so `oneHzTs` stays wall-clock-synchronized across repeated `3–4 s` auto-pauses while staying immune to `{0, 2}` beats, constant `TIME_ACTIVE` with nulls, and `<= 6 s` SQLite batch-flush stalls.
  - Whenever `pauseGapMask[i] == true` from ANY pause branch AND `(timeTotalSec == null || timeActiveSec == null)`, `reconstructTimingWithPauses()` SHALL reset `prevPairTotalSec = null; prevPairActiveSec = null; prevPairIdx = -1` so stale pre-pause pairs never false-trip on post-pause rows.
  - `ErtsPostWorkoutRecomputer` SHALL propagate `isPauseGap` into `RawSampleRow`, `RawOdometrySample`, and `RawAltitudeSample`, reset `BarometricAltitudeFilter` at pause boundaries, run `detectAndCompensateBaroResetSteps()` independently per pause-delimited contiguous segment (blocking null-baro masking, cross-pause `preVals`/`postVals`, and Segment 1 `cumulativeShift` leakage while preserving `<= 5 s` non-pause crash-recovery steps), avoid crossing pause boundaries in `inferLegacyCarriageModeAt()`, and pass `pauseGapMask` to `computeAuthoritativeAverageSpeedMps()` in BOTH `updateWorkoutSummaries()` (`:801`) and `updateExtrema()` (`:916`) as well as guarding `!rawRows[i].isPauseGap` in `estimateRawReferenceDistanceMeters()`.
- **`REQ-FIL-045.2` (Segment-Independent Odometry ERTS Smoothing & Zero Pause Distance)**:
  - `ExtendedRtsOdometrySmoother.smoothSamples()` SHALL partition `samples` into contiguous active segments at every pause boundary (`sample.isPauseGap || isTimestampPauseGap(prevTs, currTs)` with overflow-safe `MAX_ACTIVE_SAMPLE_GAP_MS = 5_000L`) in the shared global `(refLat, refLon)` frame (preserving `result.size == samples.size`, no-GNSS segment fallback to prior ENU/heading, and 1-sample segments). `resolveInitialHeadingRad()` SHALL compute relative chord displacement `(dE = eastM - firstEast, dN = northM - firstNorth)` from `segment[firstValidIdx]` (never global `(0, 0)`), applying caller `explicitHeadingRad` strictly to Segment 0 (`Double.NaN` for Segment 1+) to prevent 180° heading inversion on out-and-back rides.
  - `ExtendedRtsOdometrySmoother.smoothSnapshots()` SHALL accept `@JvmOverloads pauseGapMask: BooleanArray? = null`, decouple backward RTS (`C_k = 0`) across every pause boundary, and emit `deltaDistanceMeters = 0.0` at `k == 0` and every pause boundary `k`.
- **`REQ-FIL-045.3` (Segment-Independent Altitude/Slope ERTS Smoothing & Ascent/Descent Continuity)**:
  - `ExtendedRtsAltitudeSlopeSmoother.smooth()` SHALL partition `samples` into contiguous active segments at every pause boundary (`sample.isPauseGap || isTimestampPauseGap(prevTs, currTs)` with `MAX_ACTIVE_SAMPLE_GAP_MS = 5_000L`), running forward EKF and backward RTS independently per segment (`deltaDist = 0.0` and `verticalSpeedMps = 0.0` on every pause-resume row).
  - For BOTH `n == 1` and `n > 1` segments, `smoothContiguousSegment()` SHALL carry prior `ascentOffset`/`descentOffset` monotonically (never resetting `ASCENDING`/`DESCENDING` to `0.0` on a trailing 1-sample segment), re-anchor per-segment hysteresis to the segment's first smoothed altitude, fall back to `fallbackInitialAlt` (never `0.0`) when all altitudes in a segment are `NaN`, scan for the first finite `rawAltitudeM` when applying `rawAlt - inheritedBaroBias` on baro-only (`!hasReference && hasBaroData`) segments, and forward `inheritedBaroBias` unchanged across `n == 1` or `!hasBaroData` (DEM-only) segments.

## 2. Acceptance Criteria (Given-When-Then) & Test Cases (`TST-FIL-045`)
- **`TST-FIL-045.1` (`ErtsPostWorkoutRecomputerTest`) — Criterion 1 (`Zum Bäcker #59`) & Multi-Pause Timing/DB Parity**:
  - *Given* a `Zum Bäcker #59` SQLite workout (`TIME_ACTIVE_s = 391`, `TIME_TOTAL_s = 570`) with `4 s`, `17 s` (`0.88 m/s` resume), `134 s` (`TIME_TOTAL: 241 -> 375`, `TIME_ACTIVE: 218 -> 219`, `3.84 m/s` resume), and `> 10 min` (`610 s`) pauses across 2 laps (`LAP_NR = 1, 2`) plus untouched device-attributed columns.
  - *When* `ErtsPostWorkoutRecomputer.recomputeWorkout()` executes.
  - *Then* every pause-resume row emits `0.0 m` `DISTANCE_m` delta and `0 m/h` `VERTICAL_SPEED`; `DISTANCE_TOTAL_m` stays within `±3%` of live active distance (`~1,948 m`); `SPEED_AVERAGE_mps` and `Extrema(SPEED_mps, AVG)` match true active average (`~5.0 m/s`, including null `TIME_ACTIVE_s` fallback parity); `Laps.db` / `DISTANCE_m_LAP` parity holds; device columns stay byte-identical; `reconstructTimingWithPauses()` advances `timestampMs` across multiple consecutive `4 s` auto-pauses (preventing wall-clock desync), resets `prevPair*` across a `TIME_TOTAL` pause landing on a `TIME_ACTIVE == null` row (zero false pause on the next row), resists `{0, 2}` beats / `6 s` flush stalls / constant `TIME_ACTIVE` with nulls; and `detectAndCompensateBaroResetSteps()` stays isolated per segment (no cross-pause shift leakage or null-baro masking).
- **`TST-FIL-045.2` (`ExtendedRtsOdometrySmootherTest`) — Out-and-Back Heading, Multi-Pause Odometry & Defense-in-Depth**:
  - *Given* an out-and-back ride (East `950 m`, `134 s` pause, turnaround heading West back to Home with explicit `initialHeadingRad = 0.0`), multi-pause tracks (`4 s` `isPauseGap`, `17 s`, `134 s`, `610 s`), 1-sample & no-GNSS post-pause segments, direct `smoothSnapshots()` pause-gap call, and `Long.MIN_VALUE`/`Long.MAX_VALUE`/backwards-timestamp edge cases.
  - *When* `smoothSamples()` and `smoothSnapshots()` execute.
  - *Then* Segment 2 resolves initial heading West (`~±PI`, NOT `0 rad` East), every pause-resume point has `deltaDistanceMeters == 0.0`, segments match independent single-segment smoothing identically, `result.size == samples.size`, all outputs are finite, and `isTimestampPauseGap` never overflows `Long`.
- **`TST-FIL-045.3` (`ExtendedRtsAltitudeSlopeSmootherTest`) — Multi-Pause Altitude/Slope, 1-Sample Tail & Bias Carryover**:
  - *Given* multi-pause climbs/descents (`4 s` `isPauseGap`, `17 s`, `134 s` at `3.84 m/s`, `610 s` pause with `+12 m` baro weather drift), a workout ending in a trailing 1-sample post-pause segment (with baro-only bias & all-`NaN` fallback cases), and a DEM-only middle segment bridging baro bias to a baro-only final segment.
  - *When* `ExtendedRtsAltitudeSlopeSmoother.smooth()` executes.
  - *Then* pause-resume rows emit `verticalSpeedMps == 0.0`, zero phantom `g * v * dt_pause` jump (`|alt - trueAlt| <= 2.0 m`), trailing 1-sample segment preserves cumulative `ascentM`/`descentM` & `fallbackInitialAlt` (never resetting to `0.0`), baro bias survives across `n == 1`/DEM-only segments without datum jump, `|slopePercent| <= 35%`, and `TST-FIL-033.1`/`.3`, `TST-FIL-040.4`, `TST-STB-025.4` remain green.
