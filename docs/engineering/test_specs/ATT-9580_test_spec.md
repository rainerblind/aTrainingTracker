## 1. Requirement Specification (`REQ-PER-057` — Priority: `High`, Type: `Functional`, Verification: `Unit, Integration`)

| Sub-ID | Normative Contract (`SHALL` / `MUST`) |
|---|---|
| `REQ-PER-057.1` | **Decoupled Cold-Enrichment Progress Gate (`hasCompletedFullRefresh`)**: `WorkoutClusterRepository` SHALL declare `hasCompletedFullRefresh` (`AtomicBoolean(false)`), `clusterStateVersion` (`AtomicLong(0L)`), and `statePublishLock` **above `init {}`** and set `hasCompletedFullRefresh = true` strictly upon normal `refreshClusters()` completion (never in `loadAllClustersLightweight()`). `refreshClusters(forceShowProgress, forceCheckIntegrity)` SHALL evaluate `showProgress = forceShowProgress || (needsEnrichment && !hasCompletedFullRefresh.get())`, execute the silent fast-path (`!needsEnrichment && !forceShowProgress && !forceCheckIntegrity`) **before** any `_migrationStatus` write, and call cooperative `yield()` after each `_migrationStatus` progress write (`Loading`, `Healing`, `Previews`) when `showProgress == true`, guaranteeing observable cold progress even after `init` lightweight hydration while staying strictly silent on warm persisted-preview restarts (`TST-PERF-010`) and same-session revisits (`TST-PERF-009`, including un-enrichable indoor/no-GPS clusters). |
| `REQ-PER-057.2` | **Version-Guarded State Publication, SQLite Writeback Guard & Bounded Retry**: `WorkoutClusterRepository` SHALL guard in-memory `_allClusters` / `_clusterStats` publication and `clusterStateVersion` increments under a fast, non-blocking `synchronized(statePublishLock)` (zero DB I/O or suspending calls -> deadlock-free with recursive `recalculateClustersWithProgress()` -> `refreshClusters()` and synchronous `ATT-9607` `syncClusterAfterWorkoutDeletion()`). `refreshClusters()`, `syncClusterAfterWorkoutDeletion()`, and `propagateClusterRename()` SHALL increment `clusterStateVersion` atomically on publication, and `refreshClusterStats()` SHALL synchronize its `_clusterStats.value` write under `statePublishLock` (DB query outside lock). `loadAllClustersLightweight()` SHALL capture `startVersion = clusterStateVersion.get()` before reading SQLite, abort stale SQLite writebacks (`healUntrimmedClusterNames` / `clusterDb.updateCluster`) if `clusterStateVersion.get() != startVersion`, publish `_allClusters`/`_clusterStats` strictly when `clusterStateVersion.get() == startVersion`, and perform **at most 1 bounded retry** when `clusterStateVersion.get() != startVersion && _allClusters.value.isEmpty() && !hasCompletedFullRefresh.get()` so concurrent deletion/rename on an empty cache never leaves map overlays empty. `init` SHALL skip `loadAllClustersLightweight()` if `hasCompletedFullRefresh.get()` is already `true`. |
| `REQ-PER-057.3` | **Guaranteed Progress Cleanup on Failure & Cooperative Cancellation**: In `refreshClusters()`, `try { ... } finally { if (showProgress) _migrationStatus.value = null }` SHALL open **immediately before** the first `_migrationStatus.value = Loading` assignment (after the fast-path return). Combined with cooperative `yield()` checkpoints after progress writes, any exception or coroutine cancellation clears `_migrationStatus` to `null` while leaving `hasCompletedFullRefresh == false` so retries still display progress; normal completion publishes `_clusterStats` and `_allClusters` before clearing `_migrationStatus` (`Rule 74`). |
| `REQ-PER-057.4` | **Injectable IO Dispatcher & Deterministic Verification**: `WorkoutClusterRepository`'s `internal constructor` SHALL accept an optional `ioDispatcher: CoroutineDispatcher = Dispatchers.IO` (preserving `getInstance(context)` and `getInstance(context, scope)` signatures verbatim) used by `init`, `loadAllClustersLightweight()`, `refreshClusters()`, `refreshClustersAsync()`, and `refreshClusterStats()` so tests can verify deterministic interleavings and intermediate `migrationStatus` emissions without `StateFlow` conflation. |

## 3. Acceptance Criteria (Given-When-Then)

- **Given** SQLite has an un-enriched cluster (`previewPaths.isEmpty()`, `hitCount > 0`) and `init` lightweight hydration already populated `_allClusters.value`, **When** `refreshClusters()` executes, **Then** `migrationStatus` deterministically emits progress (`yield()` after each update), `previewPaths` persist to SQLite, `_allClusters.value` reflects enriched paths, and `migrationStatus` clears to `null`.
- **Given** a simulated app restart after `previewPaths` persisted to SQLite (`TST-PERF-010`), **When** a fresh `WorkoutClusterRepository` runs `init` and `refreshClusters()`, **Then** the fast path returns before any `_migrationStatus` write (`0` non-null emissions) and persisted `previewPaths` load intact.
- **Given** `loadAllClustersLightweight()` reads stale rows while `refreshClusters()` or `syncClusterAfterWorkoutDeletion()` commits newer state, **When** `loadAllClustersLightweight()` resumes, **Then** stale SQLite writebacks and stale `_allClusters`/`_clusterStats` overwrites are skipped; if `_allClusters` is still empty and `!hasCompletedFullRefresh`, one bounded retry hydrates fresh rows.
- **Given** an exception or coroutine cancellation during `showProgress == true` enrichment, **When** `refreshClusters()` exits, **Then** `finally` resets `migrationStatus` to `null` and leaves `hasCompletedFullRefresh == false`.
