## 1. Requirement Summary (`REQ-DAT-047` [Planned])
- **`REQ-DAT-047.1` (`BaseDatabaseManager<H>`)**: `com.atrainingtracker.database.BaseDatabaseManager<H extends SQLiteOpenHelper>` SHALL encapsulate `protected volatile SQLiteDatabase mDatabase` and `protected final H mDbHelper` with thread-safe DCL `public SQLiteDatabase getDatabase()` (`ATT-289` closed-DB helper close/reopen), `closeDatabase()`, `isDatabaseOpen()`, and `@VisibleForTesting setDatabaseForTesting(SQLiteDatabase)`. All 10 Java `*DatabaseManager` classes (`Devices`, `SportType`, `KnownLocations`, `Laps`, `TrackingViews`, `WorkoutSamples`, `WorkoutSummaries`, `ExportStatus`, `Segments`, `Pebble`) SHALL extend it, preserving `DatabaseConnectionManager.getActiveDatabases()` (`REQ-MIG-041.3`), `PebbleDatabaseManager.close()`/`isDatabaseOpen()`, existing test hooks, and zero DB schema bumps.
- **`REQ-DAT-047.2` (`SqliteSchemaUtils`)**: `com.atrainingtracker.database.SqliteSchemaUtils` SHALL unify all 10 `PRAGMA table_info` files / 23 sites (`ExportStatusDatabaseManager`, `ImportEngine`, `WorkoutRepository`, `WorkoutSummariesDatabaseManager`, `WorkoutClusterDatabaseManager`, `TrackingViewsDatabaseManager`, `MultisportLapCoordinator`, `TrackerService`, `DevicesDatabaseManager`, `SportTypeDatabaseManager`) via `@JvmStatic` `getTableColumnNames` (case-insensitive `TreeSet`, `ATT-4968`/`REQ-TRK-051.1` quoted-table escaping), `hasColumn`, `addColumnIfNotExists`, and `getTableColumnInfos` (`ImportEngine` metadata) with deterministic `.use` cursor closure (`REQ-DAT-043`) and a delegating `TrackerService.getTableColumnNames` facade.
- **`REQ-DAT-047.3` (Functional Combinators & `mutateViewConfig`)**: `com.atrainingtracker.database.DatabaseExtensions` SHALL provide `Cursor.mapRows` (`.use`-closed) and `SQLiteDatabase.inTransaction` (commit/rollback) adopted across Kotlin DB managers/callers (complementing Java `CursorUtils`); `TrackingViewsRepository.kt` SHALL unify all 25 `Dispatchers.IO` + `Dispatchers.Main { configUpdateTrigger.value++ }` mutations via `private suspend fun <T> mutateViewConfig(block: () -> T): T` preserving `moveTabView(): Int` and `copyTabView(): List<Long>`.
- **`REQ-DAT-047.4` (Parameterized `StreamSummaryCalculator` & Architecture Ratchets)**: `com.atrainingtracker.trainingtracker.util.StreamSummaryCalculator` SHALL consolidate `GeoBounds`, polyline simplify+encode, parameterized stream downsampling (step-size + last-index, 5-sample legacy stride, distance-weighted missing-altitude interpolation) + `NumericalEncodingUtils` encoding, and ascent/descent (`RAW_DELTA`, nullable-gap-preserving `RAW_DELTA`, `MOVING_AVERAGE` 300-sample `ATT-301`) across `WorkoutSummariesDatabaseManager`, `WorkoutRepository.cropWorkout`, `LegacyImportEngine.recalculateStats`, `TrackerService.finalizeLiveSession`, `ErtsPostWorkoutRecomputer`, `RoutesDatabaseManager`, and `SegmentsDatabaseManager` with bit-for-bit Golden-Value parity per caller variant. Enforce `ArchitectureConformanceContractTest` downward ratchets (`ErtsPostWorkoutRecomputer.kt` upward UI import `10 -> 9`, `WorkoutSamplesDatabaseManager.java` monolith exit if `<= 1,500` LoC), `TryWithResourcesCursorAuditTest`, and `docs/architecture.md` SWE.2 updates (`Rule 8.8`).

## 2. Acceptance Criteria (Given-When-Then)
1. **DB Lifecycle & Reopen**: *Given* any of the 10 Java `*DatabaseManager` singletons (incl. post-`quiesceAllDatabases()` closed handles), *When* `getDatabase()` is called concurrently or after close, *Then* `BaseDatabaseManager` returns an open `SQLiteDatabase` via `volatile` DCL + `ATT-289` reopen and `DatabaseConnectionManager.getActiveDatabases()` succeeds.
2. **Schema Introspection**: *Given* any of the 10 `PRAGMA table_info` callers (plain or quoted tables, `ImportEngine` metadata, `TrackerService` dynamic columns), *When* schema checks or idempotent `ADD COLUMN` execute, *Then* `SqliteSchemaUtils` returns identical case-insensitive results with zero leaked cursors.
3. **Functional Combinators**: *Given* `TrackingViewsRepository` mutations and Kotlin DB `mapRows`/`inTransaction` blocks, *When* writes succeed or throw, *Then* `mutateViewConfig` runs on `Dispatchers.IO` and increments `configUpdateTrigger` on `Dispatchers.Main` returning `T`, `mapRows` closes cursors deterministically, and `inTransaction` rolls back on exception.
4. **Golden-Value Stream Parity**: *Given* representative GPS/altitude/distance workout fixtures for each caller variant (`updateMapAndStreams`, `shiftAltitudeData` Case A & B, `migrateSpatialBoundsStatic`, `migrateOneWorkout`, `cropWorkout`, `LegacyImportEngine`, `TrackerService`, `ErtsPostWorkoutRecomputer`, `RoutesDatabaseManager`, `SegmentsDatabaseManager`), *When* `StreamSummaryCalculator` executes, *Then* outputs match pre-refactor baselines bit-for-bit.
