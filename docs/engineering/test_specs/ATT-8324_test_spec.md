## 1. Requirements Reference & Governance Constraints
No new `REQ-*` or `TST-*` IDs are created. All 12 mapped requirements in `docs/requirements/` (`REQ-MAP-017`, `REQ-PER-001`, `REQ-DAT-003`, `REQ-PER-003..009`, `REQ-UI-120`, `REQ-UI-125`) keep `[Implemented]` status until all linked TSTs pass Stage 4/5 verification.
- **Multi-TST REQ Promotion Guard**: `REQ-PER-001` (`TST-PERF-002`, `TST-PERF-004`, `TST-BUG-002`) and `REQ-PER-006` (`TST-PERF-007`, `TST-PERF-009`, `TST-PERF-010`) require ALL linked TSTs to have updated `Component` mappings and backing tests before `[Verified]` promotion.
- **Robolectric `GoogleMap` Isolation (`TST-PER-010`, `TST-PERF-006`, `TST-PER-017`)**: Compose UI tests render `PeriodsTabsScreen` with `isPlayServiceAvailable = false` and `PeriodList(emptyList())` / `MigrationStatus` so Play Services `GoogleMap(...)` is never instantiated under Robolectric; `PeriodMapScreen` deterministic heatmap state (`workoutIdToHeatmapPathMap`) is verified via `PeriodsViewModel`.
- **Zero `src/main/` File Reads (`ATT-8199` / `REQ-PRO-133`)**: All tests assert runtime behavior via JUnit/MockK/Robolectric/`createComposeRule()`, keeping `SourceTextReadingAuditContractTest` at `0` `src/main/` reads.
- **9-Locale Localization Parity (`TST-PER-017`)**: Zero new string keys added; existing `no_periods_available` and `no_periods_available_hint` across all 9 locales (`values/`, `-de`, `-es`, `-fr`, `-it`, `-ja`, `-nl`, `-pl`, `-pt`, zero `&#10;`) are verified via `TranslationParityTest`.
- **Chesterton's Fence (`TST-PERF-005` Heading)**: Existing inline sub-criteria text was moved from the `### TST-PERF-005` heading into `- **Test Description**:` in `docs/tests/tst_aftermath_periods.md` without removing any normative assertions, preventing markdown heading parser noise.
