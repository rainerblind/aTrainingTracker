## 3. Acceptance Criteria (Given-When-Then)

- **Given** `recordSmartphoneRawTelemetryEnabled` was persisted as `true` via `saveTuningConfig` or `updateRecordSmartphoneRawTelemetryEnabled(true)`, **When** the process restarts (`TuningPreferencesDataStore.setInstanceForTesting(null)`) and `SmartphoneRawTelemetryRecorder.isEnabled(context)` or `SettingsDataStoreJavaHelper.isRecordSmartphoneRawTelemetryEnabled(context)` is called synchronously on the main thread, **Then** both return `true` immediately in $O(1)$ with zero `runBlocking` and zero thread parking.
- **Given** `resetToDefaults()` or `updateRecordSmartphoneRawTelemetryEnabled(false)` executes, **When** a cold restart follows, **Then** both accessors immediately return `false`.
- **Given** a unit test injects `dataStoreOverride = InMemoryPreferencesDataStore()`, **When** `TuningPreferencesDataStore` is constructed and mutated, **Then** `SharedPreferences` is never accessed and in-memory state updates synchronously.
- **Given** `DataStoreHotPathContractTest` executes, **When** scanning `SettingsDataStoreJavaHelper.kt` and `SmartphoneRawTelemetryRecorder.kt`, **Then** zero `runBlocking` DataStore reads exist.
