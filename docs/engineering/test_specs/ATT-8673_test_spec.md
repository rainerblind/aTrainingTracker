## 3. Acceptance Criteria (Given-When-Then)

- **Given** a connected radar outside a workout, mid-ride (started in manual or auto), or while paused, **When** switching from manual mode to `Automatik` via `setAutoMode()` or `cycleNextMode()` (`OFF -> AUTO` + debounce flush), **Then** hardware and UI transition immediately to the computed automatic mode (`OFF`/`SOLID`/`DAY_FLASH` daytime; `PELOTON`/`SOLID`/`NIGHT_FLASH` night/tunnel; StVZO clamped), mid-ride starts sensors without `collectLatest` kill-races, and paused state leaks zero sensor listeners.
- **Given** rapid `OFF -> AUTO -> PELOTON -> SOLID` with real DataStore, **When** `cycleNextMode()` executes within 250 ms and flushes after 400 ms, **Then** zero premature GATT writes occur during tapping and strictly 1 write (`SOLID`) transmits on flush; on Night/Tunnel `onWorkoutStopped()`, the tail light turns `OFF` and never resuscitates.
- **Given** an active brake light during manual mode, **When** switching to `Automatik` and hold expires, **Then** active braking is never preempted, hold expiry immediately applies computed auto mode, and parallel stress testing produces zero AB-BA deadlocks.
