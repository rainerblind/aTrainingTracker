# Ticket Deliverable: ATT-9013 — Default workout imports to silent route cluster creation named after the first workout

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-281`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**: During bulk or single workout imports (`LegacyImportEngine.recalculateStats()`), every spatial track whose `suggestCluster(...)` returns `null` unconditionally invokes `listener?.onNewClusterCandidate(...)`, stalling bulk Strava/FIT/TCX/GPX imports behind `ClusterNamingDialog` and `Semaphore(3)` backpressure. Meanwhile, background `AutoImportManager` passes `listener = null` and leaves all novel routes unclustered.
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Add `askOnNewClusterDuringImport` boolean preference (default `false` = silent automatic cluster creation) in `TuningPreferencesDefaults`, `TuningConfig`, `TuningPreferencesDataStore`, `TrainingApplication`, `BackupRestoreViewModel`, `AdvancedTuningScreen`, `ClusterTuningSection`, `PreImportTuningBottomSheet`, and `ClusterTuningContent` (single source of truth across Advanced Settings & Pre-Import Sheet; standalone `ClusterTuningScreen` was previously decommissioned per `LegacyPackageDecommissioningTest`). Localized toggle strings across all 9 locales (`EN, DE, ES, FR, IT, JA, NL, PL, PT`). Add `WorkoutClusterEngine.createAutoClusterFromImport(...)` seeding a genuinely new `WorkoutCluster` (bypassing `learnFromWorkout`'s name-merge fallback), stripping `#N` via `stripHitCount`, resolving collisions via `findUniqueClusterName` (`REQ-PER-041`), falling back to `KnownLocationsRepository` / `WorkoutAutoNamingHelper.generateClusterSeedName` or `cluster_default_name_format` for untitled workouts, preserving `ensureStartingLocationAnchor(start)` (`REQ-UI-186`), and assigning with `forceIdentity = false` to preserve imported workout titles. Wire into `LegacyImportEngine.recalculateStats()` (shared by `AutoImportManager`, `StravaBulkExportImporter`, and manual/cloud imports).
  * *Out-of-Scope*: No changes to spatial similarity formulas (`REQ-SET-065`), `BulkImportBatchContext` deferral (`REQ-STB-021.3` already avoids per-workout `refreshClusters()`), `ClusterNamingDialog` interactive behavior when opted in (`REQ-MIG-025`), or SQLite table schemas.
* **Chesterton's Fence / Impact**: Preserves `REQ-MIG-025` (interactive `ClusterNamingDialog` & "Leave Unclustered" when `askOnNewClusterDuringImport == true`), `REQ-SET-047` (`learnFromWorkout` name-merge preserved for manual edits/route sync), `REQ-PER-041` (`findUniqueClusterName` `"<Base> var N"` suffixing), `REQ-MIG-054` (`UPLOAD_TO_STRAVA = 0` guard), and `ImportBackupTabsScreen.kt <= 1,500` LoC. `SYS.2`/`SYS.3`: `SYSREQ-DEX-002`, `SYSREQ-DEX-004`.

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**: Store `askOnNewClusterDuringImport` (`false` default) in `TuningPreferencesDataStore` (`KEY_CLUSTER_ASK_ON_NEW_DURING_IMPORT` in `ALL_KEYS`) with null-safe `TrainingApplication.askOnNewClusterDuringImport()`. Expose the toggle directly in `ClusterTuningContent` via `TuningToggleItem` (`strings_auto_import.xml` across 9 locales). Keep `createNewClusterFromWorkout` (`forceIdentity = true`) untouched for manual UI actions and add `createAutoClusterFromImport` (`forceIdentity = false`) for silent import seeding. When `askOnNewClusterDuringImport == true` and `listener == null` (`AutoImportManager`), remain non-blocking.
* **SWE.2 Architecture / Files Touched**:
  * Production: `TuningPreferencesDataStore.kt`, `TrainingApplication.java`, `ClusterTuningContent.kt`, `ClusterTuningSection.kt`, `AdvancedTuningScreen.kt`, `BackupRestoreViewModel.kt`, `ImportBackupTabsScreen.kt`, `WorkoutClusterEngine.kt`, `LegacyImportEngine.kt`, `app/src/main/res/values*/strings_auto_import.xml` (9 locales).
  * Tests: `SilentImportClusterCreationTest.kt` (new), `ClusterTuningUiBehaviorTest.kt`, `ClusterImperialAndLocaleUiTest.kt`, `LegacyImportEngineWorkoutNameTest.kt`, `TuningPreferencesDataStoreClusterTest.kt`, `AutoImportManagerTest.kt`, `TranslationParityTest.kt`.
  * Living Docs: `docs/requirements/req_data_migration_export_part2.md` (`REQ-MIG-060`), `docs/tests/tst_data_migration_export.md` (`TST-MIG-060`), synced master indexes.
  * `docs/architecture.md`: No new subsystem or DB manager; extends existing `WorkoutClusterEngine` & `TuningPreferencesDataStore`.
