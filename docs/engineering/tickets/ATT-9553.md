# Ticket Deliverable: ATT-9553 — MapScreenWithTrack: Show compact peek header for selected Climbs instead of opening fullscreen immediately

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-66`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**:
  * In `app/src/main/java/com/atrainingtracker/trainingtracker/ui/map/MapScreenWithTrack.kt`, `MapPeekSelection.Climb` explicitly overrode `isSheetBacked = false`, returning `0.dp` for `sheetPeekHeight` and `Unit` in `BottomSheetScaffold`'s `sheetContent`, while rendering `ClimbDetailSheet` (which wraps `ClimbOnMapScreen` in `EntityDetailSheetScaffold` — a fullscreen `ModalBottomSheet` with `skipPartiallyExpanded = true`).
  * Consequently, tapping any Climb overlay on the central map (`MapScreenWithTrack`) immediately opened a fullscreen modal sheet instead of peeking cleanly at the bottom with only its compact header visible like Routes (`RouteOnMapScreen`) and Segments (`SegmentOnMapScreen`).
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Promote `MapPeekSelection.Climb` to `isSheetBacked = true` in `MapScreenWithTrack.kt`; add standardized `BottomSheetDesign.PeekHeightClimb = 192.dp`; render `ClimbOnMapScreen` inside `BottomSheetScaffold`'s `sheetContent` with `useStatusBarsPadding = false`, `key(selection.id)`, and dynamic `onHeaderHeightMeasured = { measuredHeaderHeight = it }`; clear `peekSelection` when a user manually swipes/hides any sheet-backed peek to `SheetValue.Hidden`; update `MapPeekSelectionSaverAndUiComposeTest` and `BottomSheetVisualContractTest`; verify visually via Compose Light/Dark PNG and live `emulator-5554` session.
  * *Out-of-Scope*: `ClimbDetailSheet.kt` (kept intact and reusable for `RouteOnMapScreen.kt:447` and `ClimbDetailSheetContractTest.kt`), live tracking cockpit `LiveClimbSheet` (intentionally opens `SheetValue.Expanded` per `docs/design_guidelines.md §5.8`), and `strings*.xml` (`Localization Parity: N/A - 0 new or modified UI strings`).
* **Chesterton's Fence / Impact**:
  * Preserves `MapScreenWithTrack` exact public 5-parameter signature (`REQ-UI-2790.3`, `InterfaceSignatureDriftContractTest`), `ClimbDetailSheet` modal reuse in `RouteOnMapScreen`, `ClimbOnMapScreen` normalized elevation scrubbing (`REQ-UI-338`), `Location` expansion lock (`REQ-UI-238`), `BackHandler` dismissal, `MapScreenWithTrack.kt <= 1,500` LoC (`ArchitectureConformanceContractTest`), and zero composition-time snapshot writes (`Rule 66`).
  * `SYS.2`/`SYS.3` impact: `NONE` (SWE UI presentation parity bugfix).

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  * `ClimbOnMapScreen` already implements `MapDetailLayout` with `useStatusBarsPadding = false`, `MinimumDragHandle()`, and `onHeaderHeightMeasured: ((Dp) -> Unit)? = null` mirroring `SegmentOnMapScreen`. Hosting `key(selection.id) { ClimbOnMapScreen(...) }` directly inside `MapScreenWithTrack`'s `BottomSheetScaffold` eliminates the fullscreen modal jump with zero duplication and automatically frames `ClimbHeader` + 3-row `ClimbDetails` at the exact measured header height (`measuredHeaderHeight + navBarHeight`, defaulting to `BottomSheetDesign.PeekHeightClimb = 192.dp` before first layout pass).
  * Wrapping `ClimbOnMapScreen` in `key(selection.id)` guarantees `MapDetailLayout.headerHeightPx` resets when switching between two Climbs so `onHeaderHeightMeasured` and camera bounds re-evaluate cleanly.
  * Observing `snapshotFlow { scaffoldState.bottomSheetState.currentValue }` clears `peekSelection = null` whenever the user manually swipes/dismisses the sheet to `SheetValue.Hidden`, releasing `BackHandler` and enabling immediate re-tap of the same Climb.
* **SWE.2 Architecture / Files Touched**:
  * Production: `app/src/main/java/com/atrainingtracker/trainingtracker/ui/components/core/BottomSheetDesign.kt`, `app/src/main/java/com/atrainingtracker/trainingtracker/ui/map/MapScreenWithTrack.kt`.
  * Tests: `app/src/test/java/com/atrainingtracker/trainingtracker/ui/map/MapPeekSelectionSaverAndUiComposeTest.kt`, `app/src/test/java/com/atrainingtracker/trainingtracker/ui/components/core/BottomSheetVisualContractTest.kt`.
  * `docs/architecture.md`: unchanged (no new subsystem/service/DB/prefix family).
