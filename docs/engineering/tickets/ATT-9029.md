# Ticket Deliverable: ATT-9029 — Add full-screen workout map mode with spatial and base-map layer toggles

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-68`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**: In Workout Details (`TrackOnMapScreen` $\rightarrow$ `WorkoutDetailTabbedContent` $\rightarrow$ `MapDetailLayout`), the workout map is embedded inside a tabbed viewport (`MODE_B_SPLIT_MAP` or `MODE_C_FULL_MAP`) constrained by `WorkoutHeader` and `PrimaryScrollableTabRow`, exposing only technical track-type toggles (`TrackLayersMenuButton`) when `showTechnicalTracks = true`. Athletes cannot inspect their workout geographically in full screen, toggle spatial overlays (`Primary Track`, `Technical Tracks`, `Segments`, `Routes`, `Markers / Favorite Locations / Extrema`, `Climbs`, `Lap Highlights`), or switch base map styles (`Normal`, `Terrain`, `Satellite`, `Hybrid`).
* **In-Scope / Out-of-Scope**:
  * *In-Scope*:
    1. Entry from embedded Workout Details map via `onMapClick` (empty-map tap, distinct from pan/drag and marker taps) AND an explicit floating circular **Expand / Fullscreen** icon button (`Icons.Default.OpenInFull`) in `mapTopEndActions`.
    2. Full-screen edge-to-edge workout map modal (`FullScreenWorkoutMapDialog` / `FullScreenWorkoutMapContent`) rendered without workout header or tab bar chrome while retaining underlying `WorkoutDetailTabbedContent` composition state (`Rule 47`).
    3. Clean **Close (`X`)** floating button (`Alignment.TopStart`) and system `BackHandler` returning cleanly to the exact Workout Details tab.
    4. Material 3 `AppModalBottomSheet` layer selector (`WorkoutMapLayersSheet`, mirroring `MapScreenWithTrack`'s color-swatch + `Checkbox` layer rows and `SingleChoiceSegmentedButtonRow` for the 4 mutually exclusive base map types) persisting `WorkoutMapLayerConfig` (`enabledLayers` + `baseMapType`) in `MyPreferenceManager` DataStore with downgrade-safe defaults.
    5. Clean extensibility hooks (`bottomOverlay`, `selectedDistance`, `activeScrubPath`, `activeScrubPoint`) so follow-up `ATT-9030` can dock its collapsible metric scrubber graph without refactoring.
    6. 9-language localization parity in `res/values*/strings_workout_details.xml`.
  * *Out-of-Scope*: Collapsible bottom metric scrubber graph & bidirectional scrub distance sync (`ATT-9030`), changes to `MapScreenWithTrack` general map behavior, database schema migrations, and `MapDetailLayout.kt` bloat (`0` LoC added to `MapDetailLayout.kt` to stay well under the `1,500` LoC monolith ceiling).
* **Chesterton's Fence / Impact**: Preserves `MapDetailLayout` (`1,395` LoC, `onMapClick` already wired to `ATrainingTrackerMap`), `WorkoutDetailTabbedContent` `HorizontalPager` gesture isolation & tab preservation (`Rule 47` / `Rule 73`), `TrackLayersMenuButton` (`REQ-REV-016.2` / `TrackOnMapTestTags`), `DarkMapStyle.resolveMapProperties` default behavior for all existing maps (`REQ-MAP-021`), and `TrackOnMapAftermathViewModel` plain-JVM test safety (`Build.VERSION.SDK_INT == 0` lazy guard for `LiveClimbsRepository` and `KnownLocationsRepository`). `SYS.2`/`SYS.3`: `Derived (SW-only)` refining `SYSREQ-TRK-004` (unchanged).

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  * **Separate Full-Screen Window via `Dialog(usePlatformDefaultWidth = false, decorFitsSystemWindows = false)`**: Mirrors `LapEditBottomSheet`, inherits host `MaterialTheme` directly (preserving AMOLED/dark surface tokens without re-wrapping `ATrainingTrackerTheme`), syncs system-bar icon contrast strictly on the Dialog's own `DialogWindowProvider.window` via `LaunchedEffect(dialogView, isDark)`, avoids Android `SurfaceView` Z-fighting between embedded and full-screen `GoogleMap` instances, preserves underlying `WorkoutDetailTabbedContent` composition (`HorizontalPager` tab & scroll state), works identically whether `TrackOnMapScreen` is hosted full-screen (`WorkoutSummariesTabbedScreen`, `WorkoutClustersScreen`) or inside a `BottomSheetScaffold` (`PeriodMapScreen`, `WorkoutClusterHeatmapScreen`), and handles system Back natively alongside `BackHandler`.
  * **Base-Map Type Resolution & Reactive Cold-Start Hydration**: Add `DarkMapStyle.resolveExplicitMapProperties(mapType, isDark, darkMapStyleOptions)` and optional `mapTypeOverride: MapType? = null` on `ATrainingTrackerMap` so `NORMAL` preserves `DarkMapStyle` in dark mode while `TERRAIN`, `SATELLITE`, and `HYBRID` render their requested tile types cleanly in both Light and Dark/AMOLED themes without altering existing map callers. In `TrackOnMapAftermathViewModel`, reactively collect `LiveClimbsRepository.allStoredClimbs` and `KnownLocationsRepository.locationsFlow` in `viewModelScope` using atomic `_uiState.update { ... }` so cold-start workouts update immediately as SQLite hydration completes and preserve hydrated climbs/locations across workout switches.
  * **DataStore Persistence & Non-`BEST` Fallback**: Persist `FULLSCREEN_WORKOUT_MAP_ENABLED_LAYERS` and `FULLSCREEN_WORKOUT_MAP_BASE_TYPE` in `MyPreferenceManager` alongside `enabledTrackTypesFlow` with `safeEnumValueOfOrNull` downgrade-safe defaults (`DEFAULT_ENABLED` = `{PRIMARY_TRACK, SEGMENTS, ROUTES, MARKERS, LAP_HIGHLIGHTS}`, excluding `CLIMBS` by default matching `GeneralMapLayer.DEFAULT_ENABLED`; unset `baseMapType = null` resolves theme-aware via `WorkoutBaseMapType.defaultForTheme(isDark)` $\rightarrow$ `NORMAL` dark vector style in Dark/AMOLED mode preventing daytime glare per `REQ-MAP-021`, `TERRAIN` in Light mode, while explicit selections override in both themes). `resolveFullscreenWorkoutMapContent` deduplicates against the actually emitted `addedPrimaryTrack` so non-`BEST` fallback technical tracks remain toggleable when `PRIMARY_TRACK` is unchecked. Collect reactively without one-shot `isInitialized` form guards (`Rule 82`).
  * **UI Guidelines Compliance**: Use `AppModalBottomSheet` (`§5.3`, `§5.8`), `SingleChoiceSegmentedButtonRow` with `icon = {}`, `labelSmall`, `maxLines = 1`, `softWrap = false`, `TextOverflow.Ellipsis` for the 4 short base-map labels (`Standard` / `Gelände` / `Satellit` / `Hybrid`, `§1.4`, `§5.6`), `HorizontalDivider` sectioning (no nested cards), and `48.dp+` full-width `toggleable` rows with `12.dp` color swatches + Material 3 `Checkbox` mirroring `MapScreenWithTrack`.
