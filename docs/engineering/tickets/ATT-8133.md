# Ticket Deliverable: ATT-8133 — Consolidate Geodesy, Polyline Projection & Cluster Synchronization

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-8120`

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**:
  1. **Duplicated Polyline Projectors & `RouteAutoDetector` $\cos(\phi)$ Distortion**: Besides `geo/PolylineProgressTracker.kt` (defining `geo.PolylineProjection`), seven separate segment/polyline projectors exist across `routes/ForkRouteMatcher.kt` (introducing a duplicate `routes.PolylineProjection`), `routes/RouteSegmentMatcher.kt`, `routes/ReturnCorridorSnapper.kt`, `routes/TurnByTurnNavigationEngine.kt`, `climbs/ClimbDeduplicator.kt`, `routes/WaypointDistanceCalculator.kt`, and `routes/RouteAutoDetector.kt`. Specifically, `RouteAutoDetector.distanceToSegmentMeters()` (`RouteAutoDetector.kt:200-203`) computes segment parameter `r` on raw `(lat, lng)` degrees without $\cos(\phi)$ longitude scaling, introducing ~33–36 % East-West/diagonal geometric distortion at 50° N (also affecting `TurnCueDetector.kt:373`).
  2. **Divergent Route Elevation Gain Algorithms**: `GpxRouteImporter.kt` applies 2.0 m hysteresis while `TcxCourseParser.kt` sums raw positive deltas (`0.0 m`), causing identical GPX and TCX routes to report divergent elevation gains.
  3. **Hidden SQLite Writes in Read Query & Heavyweight Rename Reloads**: `WorkoutClusterEngine.getClusterScores()` (`WorkoutClusterEngine.kt:1119`) executes hidden `dbManager.updateCluster(healed)` writes while scoring clusters. On cluster/route renames, `RoutesRepository.syncClusterNameChange()` calls `routesDb.getRouteByClusterId()` (loading all `route_points`/`route_waypoints`) and then `refreshRoutes()` (reloading every route and thousands of `route_points`), while `WorkoutClusterRepository.updateCluster()` / `onRouteSyncedClusterRename()` trigger full `refreshClusters()` DB scans.
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Introduce pure-JVM `geo/GeoMath.kt` with canonical equirectangular $\cos(\phi)$ `projectPointOntoSegment()`, `distanceToSegmentMeters()`, `projectOntoPolyline()`, single canonical `com.atrainingtracker.trainingtracker.geo.PolylineProjection`, and `calculateElevationGain()` / `calculatePathElevationGain()` (2.0 m hysteresis); migrate all 7 projectors + `GpxRouteImporter`/`TcxCourseParser` onto `GeoMath` and remove `routes.PolylineProjection`; make `WorkoutClusterEngine.getClusterScores()` strictly read-only; add metadata-only `RoutesDatabaseManager.updateRouteNameByClusterId()` and in-place rename propagation in `RoutesRepository` and `WorkoutClusterRepository` with zero `route_points` reloads; update `docs/architecture.md` and living docs (`REQ-GEO-003` / `TST-GEO-003`).
  * *Out-of-Scope*: Point-to-point distance Haversine vs. WGS-84 ellipsoid consolidation (`ATT-6035`), `WorkoutCluster` centroid/bounds/altitude encapsulation (`ATT-6047`), SQLite schema version changes, and UI/string changes (`Localization Parity: N/A`).
* **Chesterton's Fence / Impact**: Preserves `REQ-GEO-001`/`REQ-GEO-002` (windowed forward segment continuity, virtual gates, 3D altitude/grade interpolation), `REQ-PER-040`/`REQ-PER-041` (immediate non-recursive cluster-route-workout rename sync & whitespace self-healing), and `REQ-MAP-024`/`REQ-MAP-026`/`REQ-MAP-028`/`REQ-MAP-029`/`REQ-CLM-011`. `SYS.2`/`SYS.3`: `SYSREQ-TRK-004`, `SYSREQ-TRK-009`.

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**: Place `GeoMath` (`object GeoMath`, `SegmentProjection`, and canonical `PolylineProjection`) in `com.atrainingtracker.trainingtracker.geo` using pure-JVM equirectangular $\cos(\phi)$ scaling and `GeoUtils.haversineDistanceMeters` (zero Android `Location` dependency). Consolidate `PolylineProgressTracker`, `ForkRouteMatcher`, `RouteSegmentMatcher`, `ReturnCorridorSnapper`, `TurnByTurnNavigationEngine`, `ClimbDeduplicator`, `RouteAutoDetector`, and `WaypointDistanceCalculator` onto `GeoMath`. Keep `getClusterScores()` purely in-memory when reflecting authoritative `actualCounts` (leaving persistence healing to explicit refresh paths). Replace full-geometry route reads on rename with `RoutesDatabaseManager.updateRouteNameByClusterId()` + in-place `_allRoutes`/`_allClusters` updates via unified `propagateClusterRename()`.
* **SWE.2 Architecture / Files Touched**:
  * Production: `geo/GeoMath.kt` (new), `geo/PolylineProgressTracker.kt`, `routes/ForkRouteMatcher.kt`, `routes/RouteDivergenceDetector.kt`, `routes/ForkNavigationRepository.kt`, `routes/RouteSegmentMatcher.kt`, `routes/ReturnCorridorSnapper.kt`, `routes/TurnByTurnNavigationEngine.kt`, `routes/RouteAutoDetector.kt`, `routes/WaypointDistanceCalculator.kt`, `routes/GpxRouteImporter.kt`, `routes/TcxCourseParser.kt`, `climbs/ClimbDeduplicator.kt`, `database/WorkoutClusterEngine.kt`, `database/WorkoutClusterRepository.kt`, `database/RoutesDatabaseManager.kt`, `repositories/RoutesRepository.kt`, `ui/routes/RoutesViewModel.kt`.
  * Tests: `geo/GeoMathTest.kt` (new), `routes/RouteAutoDetectorTest.kt`, `routes/ForkRouteMatcherTest.kt`, `routes/RouteDivergenceDetectorTest.kt`, `database/EditWorkoutClusterTest.kt`, `repositories/RoutesRepositorySyncTest.kt`, `database/WorkoutClusterRepositoryTest.kt`, `ui/routes/RoutesViewModelTest.kt`.
  * Docs: `docs/architecture.md`, `docs/requirements/req_maps_navigation.md`, `docs/tests/tst_maps_navigation.md`, `docs/engineering/tickets/ATT-8133.md`.
