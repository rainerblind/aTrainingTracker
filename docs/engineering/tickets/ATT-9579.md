# Ticket Deliverable: ATT-9579 — Decouple WorkoutClusterEngine from WorkoutSummariesDatabaseManager.WorkoutSummaries import (REQ-DAT-042.6)

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-176`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**: Discovered during 2026-KW47 weekly full test execution (`ATT-9569`): `RepositoryEngineCleanlinessContractTest.testTST_DAT_038_2_phaseBEngines_zeroProhibitedDatabaseImports` failed on `WorkoutClusterEngine.kt` (`import com.atrainingtracker.trainingtracker.database.WorkoutSummariesDatabaseManager`). `WorkoutClusterEngine.kt:26` imported `WorkoutSummariesDatabaseManager.WorkoutSummaries` solely to index the untyped `Map<String, Double>` returned by `ClusterWorkoutDataPort.getWorkoutBounds(workoutId)` at three sites: `migrateHistory()` (lines 662–665), `createNewClusterFromWorkout()` (lines 905–908), and `moveWorkoutToCluster()` (lines 1280–1283). Additionally, a fourth site in `splitCluster()` (lines 1522–1525) hardcoded `"BoundMinLat"`..`"BoundMaxLng"` instead of `"boundMinLat"`..`"boundMaxLng"` (`WorkoutSummaries.BOUND_*`), silently yielding `null` bounds during remaining-cluster recalculation.
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Add canonical `ClusterWorkoutDataPort.BOUND_MIN_LAT`/`BOUND_MIN_LNG`/`BOUND_MAX_LAT`/`BOUND_MAX_LNG` constants and typed `ClusterWorkoutDataPort.getWorkoutRouteBounds(workoutId: Long): WorkoutBoundsDto` (with default adapter over `getWorkoutBounds` and direct override in `SummariesManagerClusterWorkoutDataPort`), update all four call sites in `WorkoutClusterEngine.kt` (`migrateHistory`, `createNewClusterFromWorkout`, `moveWorkoutToCluster`, `splitCluster`), remove the `WorkoutSummariesDatabaseManager` import from `WorkoutClusterEngine.kt`, and add/verify unit test assertions for typed bounds propagation across split/creation/port lookup plus `SportTypesRepository` isolation in `EditWorkoutClusterTest`.
  * *Out-of-Scope*: No SQLite schema changes, no `WorkoutRepository` (`ui/aftermath/`) signature changes, no UI/Compose or string changes, no changes to `WorkoutSummariesDatabaseManager` column names or `docs/architecture/interfaces.md` (`getWorkoutBounds` is not listed in `IF-SWE-05`).
* **Chesterton's Fence / Impact**: Preserves `REQ-DAT-042.1` (zero public `Cursor`/`SQLiteDatabase`/`*DatabaseManager`/`*DbHelper` getters on `WorkoutRepository` and `WorkoutClusterRepository`), `REQ-DAT-042.6` (zero prohibited database imports in Phase B engines), `REQ-PRO-130.2` (zero upward `.ui.*` imports in `WorkoutClusterEngine`), and `REQ-PRO-129.2` (LoC ceiling on `WorkoutClusterEngine.kt`). `SYS.2`/`SYS.3`: `SYSREQ-DEX-001` (unchanged).

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**: Reuse the existing `WorkoutBoundsDto(minLat, minLng, maxLat, maxLng)` data class already defined in `com.atrainingtracker.trainingtracker.database` (`WorkoutClusterDatabaseManager.kt`) and already used by `ClusterWorkoutDataPort.forEachWorkoutBoundsForCluster(clusterId, block: (WorkoutBoundsDto) -> Unit)`. Exposing `getWorkoutRouteBounds(workoutId: Long): WorkoutBoundsDto` on `ClusterWorkoutDataPort` (with `BOUND_*` constants and a default adapter over `getWorkoutBounds` so `WorkoutRepository` inherits typed bounds automatically without modifying `ui/aftermath/`) eliminates stringly-typed `WorkoutSummaries.BOUND_*` references in `WorkoutClusterEngine` and fixes the `"BoundMinLat"` key mismatch bug in `splitCluster()`.
* **SWE.2 Architecture / Files Touched**:
  * Production:
    * `app/src/main/java/com/atrainingtracker/trainingtracker/database/ClusterWorkoutDataPort.kt`
    * `app/src/main/java/com/atrainingtracker/trainingtracker/database/WorkoutClusterEngine.kt`
  * Tests:
    * `app/src/test/java/com/atrainingtracker/trainingtracker/database/WorkoutClusterSplitTest.kt`
    * `app/src/test/java/com/atrainingtracker/trainingtracker/database/EditWorkoutClusterTest.kt`
  * `docs/architecture.md`: No structural change (existing `ClusterWorkoutDataPort` boundary and `WorkoutBoundsDto` reused).
