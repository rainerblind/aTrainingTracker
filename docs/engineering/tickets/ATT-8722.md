# Ticket Deliverable: ATT-8722 — Manufacturer Lookup: Use Garmin FIT SDK (`com.garmin.fit.Manufacturer`) with Map Overrides and Fix 337–350 Array Index Shift

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-5910`
* **Status**: Verified (`REQ-CON-063`, `TST-CON-063`)

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**:
  * `app/src/main/java/com/atrainingtracker/banalservice/devices/Manufacturer.java` currently stores a flat 347-element `String[] manufacturerString` array (lines 30–377) indexed directly by `manID` (`Manufacturer.getName(int manID)`).
  * This creates two defects: (1) new ANT+/FIT manufacturer IDs must be manually appended and padded with `"Unknown"` placeholders even though `com.garmin:fit:21.141.0` (`com.garmin.fit.Manufacturer`) already ships `getStringFromValue(Integer)` backed by a 223-entry `Map<Integer, String>` (`1..73`, `76..150`, `255`, `257..329`, `5759` `ACTIGRAPHCORP`); and (2) omitted FIT Profile IDs (`336`, `338`, `343`, `344`) shifted every entry in `manufacturerString` from `337` (`"Runna"`) through `350` (`"Cadence App"`) down by 1–4 array slots (e.g., `getName(337)` returns `"Zepp"` instead of `"Runna"`, `getName(341)` returns `"Real Velo"` instead of `"Carv"`, and `getName(350)` returns `null` instead of `"Cadence App"`).
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Replace the flat `manufacturerString` array lookup in `Manufacturer.java` with a sparse pure-Java `Map<Integer, String>` (`MANUFACTURER_OVERRIDES`) checked before `com.garmin.fit.Manufacturer.getStringFromValue(manID)` + `formatFitToken()` display formatting, fixing all IDs `337`–`350` and covering `151`–`153`, `330`–`335`, and `5759` (`ACTIGRAPHCORP`), and add comprehensive unit tests in `ManufacturerTest.kt`.
  * *Out-of-Scope*: Upgrading `com.garmin:fit` in `app/build.gradle` (already `21.141.0`), migrating `Manufacturer.java` to Kotlin (`ADR-001` keeps `Manufacturer.java`), or editing `strings*.xml` (`Localization Parity: N/A - 0 string changes`).
* **Requirement Archaeology & Chesterton's Fence Audit**:
  * *Target & Origin*: Refines `REQ-CON-001` via net-new `REQ-CON-063`; flat array last expanded in `8f5fe2fe` ("Feature: Updating the ANT+ Manufacturer list.") which introduced the `337`–`350` index shift.
  * *Preserved Invariants*: `Manufacturer.getName(int manID)` public signature and curated display names for existing IDs (`1..329`, e.g. `"Garmin"`, `"SRM"`, `"Wahoo Fitness"`, `"Saris / CycleOps"`, `"4iiiis"`, `"Concept 2"`, `"o-synce"`, `"FSA"`, `"Lishun Electric & Communication"`); `null` return for unmapped/unknown/negative IDs (`-1`, `0`, `74`, `75`, `336`, `338`, `343`, `344`, `65535`) so `DeviceManager.java`, `ANTBikeRadarDevice.kt`, `MyANTDevice.java`, and `DeviceData.kt` (`R.string.devices_unknown_manufacturer`) behave cleanly without overwriting persisted names with English `"Unknown"`.
  * *`SYS.2`/`SYS.3` impact*: `NONE` (reuses `SYSREQ-TRK-001`).

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  * **Sparse Override/Extension Map + FIT SDK + Token Formatter**: Lookup order in `Manufacturer.getName(int manID)`: (1) return `null` when `manID <= 0`, (2) check pure-Java `Collections.unmodifiableMap` `MANUFACTURER_OVERRIDES` (preserving curated acronyms/punctuation/brand names for `2..323` and `5759 -> "ActiGraph"`, plus ANT+ extension IDs `151..153`, `330..335`, `337`, `339..342`, `345..350` beyond `fit:21.141.0`), (3) query `com.garmin.fit.Manufacturer.getStringFromValue(manID)` and format non-empty SCREAMING_SNAKE_CASE tokens via `formatFitToken()` (`_` -> space, leading `_` stripped, Title Case via `Locale.ROOT`), returning `null` if empty/unknown.
  * **Pure-Java `HashMap` over `Map.ofEntries` / `SparseArray`**: `minSdkVersion` is `26` and unit tests run on plain JVM (`returnDefaultValues = false`), so `Collections.unmodifiableMap(HashMap)` is 100% compatible with both Android 8+ and plain JVM without Robolectric.
* **SWE.2 Architecture / Files Touched**:
  * Production: `app/src/main/java/com/atrainingtracker/banalservice/devices/Manufacturer.java`.
  * Tests: `app/src/test/java/com/atrainingtracker/banalservice/devices/ManufacturerTest.kt` (new).
  * Living Docs: `docs/requirements/req_tracking_cockpit_part3.md`, `docs/tests/tst_tracking_cockpit_part2.md`, `docs/requirements.md`, `docs/tests.md`; `docs/architecture.md` unchanged.
