## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  * **Modular `ui/settings/zones/` Package**: Moving `ZoneSettingsScreen`, `HrvDfaA1SettingsContent`, `ZonesSettingsViewModel`, and shared `ZoneLivePreviewTileCard` out of `activities/ZonesSettingsActivity.kt` into `ui/settings/zones/` eliminates the unregistered `ComponentActivity`, removes the 1,894-LoC monolith from `ArchitectureConformanceContractTest`'s allowlist, and deduplicates the live cockpit-theme `SensorFieldView` preview container across HR/Power and HRV DFA α1 tabs.
  * **Minimal Internal RFC-4180 CSV Writer**: `CSVFileWriter.java` only requires `writeNext(String[])` with RFC-4180 comma/quote/newline escaping. Embedding a 45-LoC package-private `Rfc4180CsvWriter` (`Closeable`) inside `exporter/writer/` removes 493 LoC of 2005 JDBC-tainted `opencsv` code while preserving exact CSV output compatibility.
  * **Strict Hardware-Authentic Radar Protocol Decoding**: Removing `PACKET_TYPE_THREAT` (`0x00`) and `PACKET_TYPE_V2_THREAT` (`0x01`) synthetic decoders from `BTLERadarDevice.java` ensures production code exclusively parses real Garmin Varia V1 (`(header & 0x0F) == 0x02`) and RearVue 820 V2 (`2 + 9*N`) BLE frames.
* **SWE.2 Architecture / Files Touched**:
  * **Deleted**: `AdvancedTuningDialog.kt`, `ClusterTuningScreen.kt`, `ZonesSettingsActivity.kt`, `ZonesSettingsViewModel.kt` (moved), `TrackOnMapHelper.java`, `ui/util/Event.kt`, `DynamicalPowerHrEngine.kt`, `ui/components/FastScrollbar.kt`, `ui/components/BottomSheetUtils.kt`, `au/com/bytecode/opencsv/*` (+ `package.html`), `smartwatch/pebble/*` (7 Java + 2 test files), `ConfigViewsActivityClassic.java`, `ConfigViewsFragment.java`, `ConfigViewFragment.java`, 3 obsolete XML layouts (`pebble_config_list_5.xml`, `main_activity_without_navigation.xml`, `tabbed_config_views.xml`), and 7 `icon_pebble.png` drawables.
  * **Created**: `ui/settings/zones/ZoneSettingsScreen.kt`, `ui/settings/zones/HrvDfaA1SettingsSection.kt`, `ui/settings/zones/ZonePreviewComponents.kt`, `ui/settings/zones/ZonesSettingsViewModel.kt`, `exporter/writer/Rfc4180CsvWriter.java`, `LegacyPackageDecommissioningTest.kt`.
  * **Modified**: `NavRoutes.kt`, `ATrainingTrackerApp.kt`, `TrackOnMapScreen.kt`, `HrvRampTestScreen.kt`, `HrvRampTestViewModel.kt`, `HrvRampTestConfig.kt`, `TrainingApplication.java`, `MyHelper.java`, `BTLERadarDevice.java`, `CSVFileWriter.java`, `DatabaseSchemaRegistry.kt`, `TrackingViewsDatabaseManager.java` (comment), `AndroidManifest.xml`, `app/build.gradle`, `app/proguard-rules.pro`, 9 `FastScrollableBox` callers, affected unit/contract tests, and `docs/architecture.md`, `docs/architecture/adr_006_incremental_compose_navigation.md`, `docs/system/system_context.md`, `docs/system/system_architecture.md`.
