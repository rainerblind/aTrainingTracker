# Ticket Deliverable: ATT-6037 — Compose- & Coroutine-Performance: ElevationProfile Canvas Hoisting, MapState Decoupling & Shared Base OkHttpClient

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-6033`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**:
  1. **Per-frame Canvas allocations in `ElevationProfile.kt`**: Every redraw during pinch-zoom, pan, scrubbing, or live tracking allocates 3 `android.graphics.Paint()` objects per climb badge (L847, L854, L883), runs an $O(n)$ `climb.pathPoints.maxByOrNull` summit scan per climb per draw (L838), allocates a `PathEffect.dashPathEffect` (L996), and allocates up to ~998 `androidx.compose.ui.graphics.Path()` instances (one per segment in `cachedData.segments`, L921).
  2. **Unremembered `MutableStateFlow` in `MapScreenWithTrack.kt`**: Collects `viewModel.currentLocation` at top level (L179) and wraps it into a fresh `MutableStateFlow(currentLocation)` per recomposition (L369), forcing `ATrainingTrackerMap` to re-subscribe on every recomposition.
  3. **Defeated `mapState` decoupling in `TrackingViewModel.kt` / `SensorGridScreen.kt`**: `observeMapState()` copies 12 map fields back into `_uiState` on every GPS speed/bearing/track tick (L552–567), and `SensorGridScreen` reads `state.mapState`/`state.mapRoutes` from `uiState` and collects `currentLocationFlow` at top level, recomposing the sensor grid on every GPS update.
  4. **Uncoordinated `OkHttpClient` instantiations**: 9 production call sites instantiate `OkHttpClient()` directly (creating isolated `ConnectionPool`s and `Dispatcher` thread pools, e.g., up to ~101 clients during a Strava starred-segments sync), while 3 sites build custom-timeout clients (`StravaHelper`, `ElevationService`, `GoogleDriveClient`) without sharing a base pool.
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Package A (`ElevationProfile.kt` Paint/Path/PathEffect/climb-summit hoisting & color-run fill coalescing + `MapScreenWithTrack.kt` direct `viewModel.currentLocation` forwarding); Package B (`TrackingViewModel.kt`, `SensorGridScreen.kt`, `TrackingElevationProfileSection.kt`, `TrackingTabGridContent.kt`, `TrackingViewModelMapStateTest.kt`); Package C (`AppHttpClient.kt` shared base client + all 12 production `OkHttpClient` sites preserving custom timeouts and test injections).
  * *Out-of-Scope*: `AthleteProfileScreen.kt` (cosmetic P3, non-animated); `SegmentsRepository.syncSegmentsAsync` exception handling (`ATT-6165`); `LiveSegmentsRepository` immutability/race (`ATT-6172`). Zero string/localization changes (`N/A - 0 new or modified UI strings`).
* **Chesterton's Fence / Impact**:
  * Preserves `TrackingScreenState` backward-compatible default properties (`TrackingMapIsolationContractTest`, `TrackingTabWysiwygContractTest`, `InterfaceSignatureDriftContractTest`).
  * Preserves `SensorGridScreen.kt` `<= 1,953` LoC monolith ratchet (`ArchitectureConformanceContractTest`) by extracting `TrackingElevationProfileSection.kt`, and keeps `ElevationProfile.kt` `<= 1,500` LoC.
  * Preserves `Rule 66` (`SegmentIndexHolder` plain holder, zero snapshot state writes during composition).
  * Preserves custom HTTP timeouts (`StravaHelper`: 15/15/20 s; `ElevationService`: 5/5/5 s; `GoogleDriveClient`: 30/60/60 s) and test injections (`StravaHelper.httpClient`, `ElevationService` constructor, `GoogleDriveClient` constructor, `StravaUploader` constructor).
  * `SYS.2`/`SYS.3` impact: `NONE` (internal SWE performance & resource-hygiene optimization).

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  * *Package A*: Precompute climb summit/span metadata via `remember(climbs)` (`precomputeClimbDrawData`), hoist 6-entry `ClimbCategory` `Paint` cache via `remember(density, colorScheme)`, hoist single reusable `Path` (`remember { Path() }`) and `PathEffect`, and coalesce contiguous same-color fill runs (`drawElevationSegmentsCoalesced`) before drawing crisp top stroke segments. Forward `viewModel.currentLocation` directly in `MapScreenWithTrack`.
  * *Package B*: Remove `_uiState.update` copy-back in `TrackingViewModel.observeMapState()` and volatile `_mapState.value` reads in `loadSensorFieldStates()`. Pass `mapStateFlow = viewModel.mapState` from `TrackingTabGridContent` into `SensorGridScreen` without collecting it at the parent scope; collect `mapStateFlow` strictly inside `TrackingMapContainer` (`collectAsStateWithLifecycle`) and collect `currentLocationFlow` + distinct `activeNavigatedRoute` strictly inside `TrackingElevationProfileSection` when `showElevationProfile == true`.
  * *Package C*: Introduce `AppHttpClient` (`com.atrainingtracker.trainingtracker.util`) exposing `@JvmStatic val shared: OkHttpClient` and `@JvmStatic fun newBuilder(): OkHttpClient.Builder` so all 9 default callers reuse `AppHttpClient.shared` and all 3 custom-timeout callers derive via `AppHttpClient.newBuilder()`, sharing a single `ConnectionPool` and `Dispatcher`.
* **SWE.2 Architecture / Files Touched**:
  * Production: `app/src/main/java/com/atrainingtracker/trainingtracker/ui/map/ElevationProfile.kt`, `ElevationProfileDrawHelpers.kt`, `MapScreenWithTrack.kt`, `MapContentScope.kt` (`Rule 66` plain `mutableListOf` + monotonic `contentRevision: Long` passed to `Render(currentZoom, contentRevision)` so Kotlin 2.4.10 Compose Strong Skipping always recomposes layer toggles & track updates at constant zoom with zero infinite recompositions), `ATrainingTrackerMap.kt`, `app/src/main/java/com/atrainingtracker/trainingtracker/ui/tracking/tracking/TrackingViewModel.kt`, `SensorGridScreen.kt`, `TrackingElevationProfileSection.kt`, `TrackingTabGridContent.kt`, `app/src/main/java/com/atrainingtracker/trainingtracker/util/AppHttpClient.kt`, `onlinecommunities/strava/StravaHelper.kt`, `StravaAuthRepository.kt`, `StravaDataPurgeManager.kt`, `exporter/uploader/StravaUploader.kt`, `segments/SegmentsRepository.kt`, `repositories/RoutesRepository.kt`, `elevation/ElevationService.kt`, `cloud/googledrive/GoogleDriveClient.kt`.
  * Tests: `TrackingViewModelMapStateTest.kt`, `ElevationProfilePerformanceComposeTest.kt`, `SensorGridMapDecouplingComposeTest.kt`, `AppHttpClientPoolSharingTest.kt`.

1. **Package A**: Refactor `ElevationProfile.kt` to hoist `Paint`s, `Path`, `PathEffect`, and climb summit/span cache with coalesced color-run fill drawing; refactor `MapScreenWithTrack.kt` to forward `viewModel.currentLocation` directly without unremembered `MutableStateFlow`.
