# Ticket Deliverable: ATT-9022 — Redesign workout classification UI for Routine vs Special tags with Epic badge and filter

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-68`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**: `EditWorkoutScreen` currently renders `Commute`, `Indoor`, and `Race` as three equal tiles in a single cramped row, giving everyday routine conditions (`Commute`, `Indoor`) the same visual prominence as special milestones (`Race`) and offering no UI control for the persisted `epic` flag (`ATT-9021` / `REQ-DAT-050`). Likewise, `WorkoutHeader` displays no `Epic` badge, and `WorkoutFilterCriteria` / `WorkoutFilterBottomSheet` / `ActiveFilterChipsRow` provide no way to filter for `Epic` workouts.
* **In-Scope / Out-of-Scope**:
  * *In-Scope*:
    1. **Two-Tier Classification UI** (`EditWorkoutScreen.kt`): Replace the 3-tile row with two clear visual groups:
       - *Routine Context*: `Commute` (`Icons.Default.Commute`) and `Indoor` (`Icons.Default.Home`, `R.string.indoor_short`) in calm low-emphasis styling, preserving mutual exclusion (`EditWorkoutViewModel.updateIsCommute` / `updateIsTrainer`).
       - *Special Distinction*: `Race` (`Icons.Filled.EmojiEvents`, `tertiaryContainer`/`tertiary` accent) and `Epic` (`Icons.Filled.AutoAwesome`, warm gold/amber `TTColor` distinction tokens) as elevated, independently toggleable special tags (can be combined, e.g. `Race + Epic`, calling `updateIsRace` / `updateIsEpic`).
    2. **Prominent `Epic` Badge** (`WorkoutHeaderData.kt`, `WorkoutData.kt`, `WorkoutHeader.kt`): Add `var epic: Boolean = false` to `WorkoutHeaderData`, map from `WorkoutData.epic`, and render a distinct high-visibility `Epic` badge alongside any `Race` badge in both Portrait (`FlowRow` preventing narrow-screen/German clipping) and Landscape `WorkoutHeader` layouts while `Commute`/`Indoor` stay muted secondary text.
    3. **Workout List Filtering & JSON Persistence** (`WorkoutFilterCriteria.kt`, `WorkoutFilterBottomSheet.kt`, `ActiveFilterChipsRow.kt`): Add `val isEpic: Boolean? = null` (`activeFilterCount`, `matches()`, `toJson()`, `fromJson()`), add the `Epic` `FilterChip` under Attributes in `WorkoutFilterBottomSheet`, and display a removable active `Epic` chip in `ActiveFilterChipsRow`.
    4. **Centralized Theme Tokens & 9-Language Localization**: Add Light/Dark/AMOLED `Epic` badge tokens in `Color.kt` (`TTColor.resolveEpicBadgeColors`) and localize all 5 new strings across all 9 `app/src/main/res/values*/strings_workout_details.xml` files.
  * *Out-of-Scope*: SQLite schema, `WorkoutRepository` persistence, and FIT 2.0 export/import (already completed in `ATT-9021` / `REQ-DAT-050`), Strava upload payload changes, and new database migrations.
* **Chesterton's Fence / Impact**: Refines `REQ-REV-013.1` (`EditWorkout` classification tiles) and extends `REQ-UI-236` (`Race` badge/filter) while preserving every existing contract: `EditWorkoutClassificationLayoutContractTest` (`weight(1f)`, `defaultMinSize(minHeight = 42.dp)`, `Role.Checkbox`, `Icons.Default.Commute`/`Home`/`EmojiEvents`, `R.string.indoor_short`, `tertiaryContainer`/`tertiary`), `Commute`/`Indoor` mutual exclusion, `WorkoutHeaderRaceBadgeVisualContractTest`, `WorkoutFilterCriteriaRaceTest`, and `ThemeColorCentralizationAuditTest` (zero inline `Color(0x...)` in UI files). `SYS.2`/`SYS.3`: `Derived (SW-only)` refining `SYSREQ-DEX-001` / `SYSREQ-TRK-004` (unchanged).

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  * **Two-Tier Visual Hierarchy in `EditWorkoutScreen`**: Grouping Routine (`Commute`, `Indoor`) in a muted top 2-column row (`minHeight = 42.dp`, subtle `secondaryContainer`/neutral outline when active) and Special Distinction (`Race`, `Epic`) in an elevated bottom 2-column row (`minHeight = 46.dp`, `RoundedCornerShape(10.dp)`, distinct Royal Blue `tertiary` vs Burnished Gold/Amber `TTColor` accent borders and fills) eliminates the cramped 3-column squeeze (especially in German) and visually separates everyday training context from memorable achievements.
  * **Centralized WCAG-AAA `Epic` Distinction Palette (`Color.kt`)**: Using `TTColor.resolveEpicBadgeColors(isDark)` with dedicated Light (`#FFF3CD` / `#4E3000` / `#B45309`) and Dark/AMOLED (`#422A00` / `#FFE082` / `#F59E0B`) tokens distinguishes `Epic` immediately from `Race`'s Royal Blue (`tertiaryContainer`) in Light, Dark, and AMOLED themes while passing `ThemeColorCentralizationAuditTest` cleanly.
  * **Wrapping `FlowRow` in `WorkoutHeader` Portrait Row A**: Switching Row A from a non-wrapping `Row` to `FlowRow(horizontalArrangement = Arrangement.spacedBy(8.dp), verticalArrangement = Arrangement.spacedBy(4.dp), itemVerticalAlignment = Alignment.CenterVertically)` keeps short rows on a single line while preventing `Race + Epic + FIT` badges from clipping or crushing long German sport/equipment labels (`Design Guidelines §5.13`, `§5.20`).
  * **Additive Backwards-Compatible Filter Persistence**: `WorkoutFilterCriteria.isEpic` defaults to `null` and omits `"isEpic"` from JSON when unset, preserving 100% compatibility with previously persisted filter JSON strings.
