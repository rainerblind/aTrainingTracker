# Ticket Deliverable: ATT-9245 — Fix CSVFileWriter SensorType parsing for metadata columns and nested-parentheses device names like DEM

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-281`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**: In `app/src/main/java/com/atrainingtracker/trainingtracker/exporter/writer/CSVFileWriter.java` (`doExport()`, lines 85–105), every CSV export logged 3 full `IllegalArgumentException` stack traces via `EnumUtils.safeValueOfOrNull(SensorType.class, ..., TAG)`:
  1. `WorkoutSamples.db` metadata columns `_id` and `time` (`WorkoutSamplesDbHelper.C_ID`, `WorkoutSamplesDbHelper.TIME`) were passed into `EnumUtils.safeValueOfOrNull` instead of being short-circuited before `SensorType` lookup.
  2. The greedy regex `(.*)( \(.*\)|_gps|_network|_google_fused|_att_fused)` matched up to the *last* `" ("` when device names contained nested parentheses (e.g. `ALTITUDE (Topografische Höhe (DEM))` stripped to `"ALTITUDE (Topografische Höhe"`), failing `SensorType` resolution and falling back to `SensorValueType.STRING`.
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Short-circuit `_id` and `time` in `CSVFileWriter.doExport()` prior to enum lookup; replace greedy regex stripping with deterministic first-`" ("` `indexOf(" (")` prefix extraction (before `_gps`/`_network`/`_google_fused`/`_att_fused` suffix stripping); add unit tests in `CSVFileWriterTest.kt`; document `REQ-EXP-049` / `TST-EXP-049`.
  * *Out-of-Scope*: `Rfc4180CsvWriter.kt`, `BaseFileWriter.kt`, `TrackerService.java`, `WorkoutSamplesDatabaseManager.java`, `EnumUtils.kt`, UI/Compose, and `strings*.xml` (`0` string changes).
* **Chesterton's Fence / Impact**: Preserves unsourced-first cursor ordering vs. alphabetically sorted sourced columns, `SensorValueType` serialization (`INTEGER`/`DOUBLE`/`STRING`), RFC-4180 quoting, cooperative `isCancelled()` abort/cleanup, and Java retention per `docs/architecture/adr_001_java_core_services_migration.md`. `SYS.2`/`SYS.3`: `Derived (SW-only)` refining `SYSREQ-DEX-001` (unchanged).

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**: Short-circuit `WorkoutSamplesDbHelper.C_ID` (`"_id"`) and `WorkoutSamplesDbHelper.TIME` (`"time"`) as unsourced `SensorValueType.STRING` columns (preserving cursor order and 64-bit row ID formatting without throwing `IllegalArgumentException`). Parse sourced columns via a small helper checking `columnName.indexOf(" (") > 0` first (splitting at the first `" ("` so nested parentheses like `ALTITUDE (Topografische Höhe (DEM))` or device names containing `_gps` yield the exact `SensorType` prefix), and otherwise stripping `_gps`, `_network`, `_google_fused`, or `_att_fused` suffixes.
* **SWE.2 Architecture / Files Touched**:
  * Production: `app/src/main/java/com/atrainingtracker/trainingtracker/exporter/writer/CSVFileWriter.java`
  * Tests: `app/src/test/java/com/atrainingtracker/trainingtracker/exporter/writer/CSVFileWriterTest.kt`
  * Living Docs: `docs/requirements/req_data_migration_export_part2.md`, `docs/tests/tst_data_migration_export.md` (plus synced master indexes).
  * `docs/architecture.md`: No structural change.
