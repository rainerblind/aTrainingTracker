# Ticket Deliverable: ATT-8103 — Move Export into Import & Backup as first tab and remove separate Export menu entry

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-281`

---

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**: Local workout export format toggles (TCX, GPX, Golden Cheetah JSON, CSV, FIT, Raw Sensor Data) currently live in a standalone modal bottom sheet (`ExportSettingsDialog`) opened from a separate `R.id.drawer_export` menu entry under *Synchronization*, disconnected from the central data transfer & backup hub (`ImportBackupTabsScreen`: Import, Auto-Import, Backup, Restore).
* **In-Scope / Out-of-Scope**:
  * *In-Scope*: Add `ExportTabContent.kt` (`ExportTabContent` + stateless `ExportTabContentLayout` with instant persistence via `TrainingApplication.setExportTo*()` and Light/Dark `@Preview`s) mounted as Tab 0 (`ImportBackupTabIndex.EXPORT = 0`) in `ImportBackupTabsScreen` (`Export | Import | Auto-Import | Backup | Restore`, `PrimaryScrollableTabRow` with single-line non-wrapping tabs and `edgePadding = 16.dp`); remove `R.id.drawer_export` from `AppNavigationDrawer.createDrawerGroups()`; alias `R.id.drawer_export` in `isDrawerItemSelected()` and `NavRoutes.fromDrawerItemId()` to `NavRoutes.BACKUP_RESTORE` (Tab 0) while removing `SettingsBottomSheetType.EXPORT` and dead island `ExportSettingsDialog.kt`; rename `import_backup` (and `import_backup_summary`) plus add `tab_export` across all 9 locales (`EN, DE, ES, FR, IT, JA, NL, PL, PT`); add Rule 75 `cSharedPreferences != null` null-guards on `TrainingApplication.exportTo*()` / `setExportTo*()`; update affected unit, Compose UI, and Android sweep tests.
  * *Out-of-Scope*: No changes to export writers (`TCX`/`GPX`/`FIT`/`CSV`/`GC`/`RawSensor`), `ExportManager`, `BackupManager`, `ImportEngine`, `AutoImportManager`, or SQLite schemas.
* **Chesterton's Fence / Impact**: Preserves `REQ-MIG-011`, `REQ-MIG-052`, `REQ-UI-463`, and `REQ-SET-054` invariants (all 6 export format preferences retain identical `SharedPreferences` keys and defaults; existing callers of `NavRoutes.BACKUP_RESTORE` and legacy `R.id.drawer_export` deep-links land cleanly on `ImportBackupTabsScreen` with Tab 0 = Export; `ImportBackupTabsScreen.kt` stays strictly `<= 1,500` LoC by extracting `ExportTabContent.kt`). `SYS.2`/`SYS.3`: `Derived (SW-only)` UI consolidation preserving `SYSREQ-DEX-001` & `SYSREQ-DEX-005` unchanged.

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**: Extract `ExportTabContent.kt` alongside `AutoImportTabContent.kt`, `BackupTabContent.kt`, and `RestoreTabContent.kt` using matching `ElevatedCard(RoundedCornerShape(16.dp))`, `navigationBarsPadding()`, and immediate toggle persistence (`docs/design_guidelines.md` §3 & §5). Delete `ExportSettingsDialog.kt` and `SettingsBottomSheetType.EXPORT` to enforce zero dead Composable islands (`docs/coding_standards.md` §1.12). Add `ImportBackupTabIndex` constants (`EXPORT=0, IMPORT=1, AUTO_IMPORT=2, BACKUP=3, RESTORE=4`) and optional `initialTab: Int = ImportBackupTabIndex.EXPORT` on `ImportBackupTabsScreen`.
* **SWE.2 Architecture / Files Touched**:
  * Production: `ExportTabContent.kt` (new), `ImportBackupTabsScreen.kt`, `AppNavigationDrawer.kt`, `NavRoutes.kt`, `ATrainingTrackerApp.kt`, `TrainingApplication.java`, `ExportSettingsDialog.kt` (deleted), `app/src/main/res/values*/strings.xml` (9 locales).
  * Tests: `ExportTabContentTest.kt` (replacing `ExportSettingsDialogTest.kt`), `ImportBackupTabsUiContractTest.kt`, `ImportBackupTabsSealedStateComposeTest.kt`, `AutoImportContractTest.kt`, `NavigationDrawerStateTest.kt`, `NavigationDrawerAndDialogContractTest.kt`, `SingleActivityNavigationTest.kt`, `ProcessStabilityComposeUiTest.kt`, `ModalBottomSheetDialogsIntegrityTest.kt`, `MultiLocaleUiSweepAndroidTest.kt`.
  * Living Docs: `docs/requirements/req_data_migration_export_part2.md` (`REQ-MIG-059`), `docs/tests/tst_data_migration_export.md` (`TST-MIG-059`), plus synced master indexes.
  * `docs/architecture.md`: No structural subsystem change (tab consolidation within existing `migration` UI package).
