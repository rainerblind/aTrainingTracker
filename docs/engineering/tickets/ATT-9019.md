# Ticket Deliverable: ATT-9019 — Replace ClusterNamingDialog full GoogleMap with PathPreviewMap and hoist polyline station sampling in WorkoutClusterEngine

* **Risk Tier**: `tier-b` | **Target Release**: `V5.0.0` | **Parent Epic**: `ATT-281`

## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**: During a Strava bulk archive import (`3,287` rows in `activities.csv`) on Pixel 10 (`66020DLCR002FL`), two secondary memory-churn hotspots appeared in logcat:
  1. `ClusterNamingDialog` in `app/src/main/java/com/atrainingtracker/trainingtracker/migration/ImportBackupTabsScreen.kt` (lines 791–824, 910–948) instantiates a full interactive `GoogleMap` (`maps-compose`) with manual `LatLngBounds.builder()`, `rememberCameraPositionState`, `DarkMapAntiFlashOverlay`, `LaunchedEffect` camera animation, and 3 uncached `createSensorMarker(...)` bitmap allocations per modal presentation (`VRI[Pop-up-Fenster]` surface churn and `23–46 MB` LOS churn per GC), rather than reusing the repository's Lite-Mode `PathPreviewMap` (`GoogleMapOptions().liteMode(true)` / Compose `Canvas` fallback).
  2. In `app/src/main/java/com/atrainingtracker/trainingtracker/database/WorkoutClusterEngine.kt` (`scoreClusters` / `calculateSimilarity`, lines 1109–1127 & 1216–1226), `WorkoutClusterCorridorDetector.samplePolylineStations(workoutPolyline)` is executed once per cluster (`K` times — 194× on the test device — for the exact same `workoutPolyline`), and every cluster's `previewPaths` are re-decoded via `PolyUtil.decode(previewPoly)` and re-sampled on every cluster on every workout (`N_workouts × N_clusters`), triggering 14 consecutive GC cycles.
* **In-Scope / Out-of-Scope**:
  * *In-Scope*:
    - Replace the full interactive `GoogleMap` block, manual bounds/camera `LaunchedEffect`, and `DarkMapAntiFlashOverlay` in `ClusterNamingDialog` (`ImportBackupTabsScreen.kt`) with `PathPreviewMap` (`additionalPaths = listOf(PreviewPolyline(...))`, `start`, `end`, `apex`, localized marker titles, `boundsPaddingPx = 50`).
    - Add a bounded, thread-safe LRU cache (`MAX_SENSOR_MARKER_CACHE_SIZE = 64`, caching non-null `BitmapDescriptor`s keyed by `(iconResId, pinColorArgb, iconColorArgb, densityBits)`) inside `createSensorMarker` (`MapUtils.kt`) so consecutive queue presentations and scrolling previews allocate zero duplicate marker bitmaps.
    - Add a thread-safe, generation-guarded `ClusterPreviewStationCache` in `WorkoutClusterCorridorDetector.kt` (bounded LRU for saved clusters + unsaved synthetic clusters, reusing unchanged per-polyline stations and self-validating `previewPaths` equality, plus explicit invalidation hooks wired into `WorkoutClusterEngine.dbManager` and `WorkoutClusterRepository`).
    - Hoist `WorkoutClusterCorridorDetector.samplePolylineStations(workoutPolyline)` in `WorkoutClusterEngine.scoreClusters` to run at most once per call (0× when `workoutPolyline.isNullOrEmpty()` or no cluster has `previewPaths`), delegating to private `calculateSimilarityInternal` while keeping all public `@JvmOverloads` signatures and similarity scores 100% identical.
    - Add targeted unit & Compose tests proving single-pass station sampling, cached cluster preview reuse & invalidation, identical similarity scores, bounded marker bitmap reuse, and `ClusterNamingDialog` rendering `PathPreviewMap`.
  * *Out-of-Scope*: No changes to SQLite schemas, localized XML strings (`0` `strings*.xml` edits), `WorkoutClusterEngine` scoring math/weights, `ClusterNamingDialog` form controls or callbacks, or `PathPreviewMap` multi-path/route contracts.

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  - **UI Preview (`PathPreviewMap` + `createSensorMarker` LRU cache)**: Reusing `PathPreviewMap` with `additionalPaths = listOf(PreviewPolyline(decodedPoints, trackColor, widthPx = 5f, roundCaps = true))` removes ~45 LoC of duplicated full-`GoogleMap` boilerplate from `ImportBackupTabsScreen.kt`, automatically switches `ClusterNamingDialog` to Lite Mode (`GoogleMapOptions().liteMode(true)`) + Canvas inspection fallback, and preserves start/end/apex markers + localized titles. Adding a bounded 64-entry LRU cache inside `createSensorMarker` (caching only non-null `BitmapDescriptor`s keyed by `(iconResId, pinColorArgb, iconColorArgb, densityBits)`) eliminates marker bitmap reallocation even when `ClusterNamingDialog` unmounts/remounts between queue items (when `_interactionQueue` transiently empties).
  - **Engine Corridor Caching (`ClusterPreviewStationCache` + Hoisted Sampling)**: Placing `ClusterPreviewStationCache` inside `WorkoutClusterCorridorDetector.kt` keeps `WorkoutClusterEngine.kt` comfortably below its `1,635`-LoC monolith ceiling (`ArchitectureConformanceContractTest`) and at `0` `.ui.*` imports. `ClusterPreviewStationCache` uses a private `cacheLock` (strictly leaf lock: never acquires `clusterLock`), computes `PolyUtil.decode` + `samplePolylineStations` *outside* the lock, guards cache writes with a monotonic `invalidationGeneration` counter (preventing stale re-population across concurrent invalidations), defensively copies `previewPaths.toList()`, validates `entry.previewPaths == previewPaths` on every read (immune to out-of-band/in-memory mutations), and is explicitly invalidated on every `insertCluster`/`updateCluster`/`deleteCluster`/`deleteAllClusters` in both `WorkoutClusterEngine.dbManager` and `WorkoutClusterRepository`.
* **SWE.2 Architecture / Files Touched**:
  * Production:
    - `app/src/main/java/com/atrainingtracker/trainingtracker/migration/ImportBackupTabsScreen.kt`
    - `app/src/main/java/com/atrainingtracker/trainingtracker/ui/map/MapUtils.kt`

  * Tests:
    - `app/src/test/java/com/atrainingtracker/trainingtracker/database/WorkoutClusterCorridorScoringTest.kt`

## 4. Implementation Plan
1. **Cache `createSensorMarker` descriptors (`MapUtils.kt`) & harden `tryApplyPreviewBounds` (`PathPreviewMap.kt`)**:
   - Add bounded thread-safe LRU cache (`MAX_SENSOR_MARKER_CACHE_SIZE = 64`) in `MapUtils.kt` caching non-null `BitmapDescriptor` results of `createSensorMarker` keyed by `(iconResId, pinColorArgb, iconColorArgb, densityBits)`, plus `@VisibleForTesting internal fun clearSensorMarkerCache()`.
   - Catch `NullPointerException` alongside `IllegalStateException` in `PathPreviewMap.tryApplyPreviewBounds`.
2. **Replace full `GoogleMap` with `PathPreviewMap` in `ClusterNamingDialog` (`ImportBackupTabsScreen.kt`)**:
   - Remove manual `bounds` builder, `rememberCameraPositionState`, `isMapLoaded`, `LaunchedEffect` camera animation, `DarkMapAntiFlashOverlay`, inline `GoogleMap`, and now-unused map imports.
   - Render `PathPreviewMap` (`height(200.dp)`, `RoundedCornerShape(8.dp)`, `testTag(CLUSTER_NAMING_PREVIEW_MAP_TAG)`) with `PreviewPolyline(decodedPoints, trackColor, widthPx = 5f, roundCaps = true)`, `start`/`end`/`apex`, localized marker titles, and `boundsPaddingPx = 50`.
3. **Add `ClusterPreviewStationCache` (`WorkoutClusterCorridorDetector.kt`) & hoist sampling (`WorkoutClusterEngine.kt` + `WorkoutClusterRepository.kt`)**:
   - Implement thread-safe, generation-guarded LRU `ClusterPreviewStationCache` (`maxClusters = 512`, `maxUnsaved = 64`, incremental reuse of unchanged polylines, defensive copy, `invalidateCluster(id)` / `invalidateAll()`).
   - Hoist `samplePolylineStations(workoutPolyline)` once in `WorkoutClusterEngine.scoreClusters(...)` (gated on `workoutPolyline.isNotEmpty() && clusters.any { it.previewPaths.isNotEmpty() }`) and delegate to private `calculateSimilarityInternal(..., preSampledWorkoutStations)` while keeping public `@JvmOverloads` signatures and scores 100% unchanged and `WorkoutClusterEngine.kt <= 1,635` LoC.
   - Wire explicit cache invalidations in `WorkoutClusterEngine.dbManager` (`insertCluster`/`updateCluster`/`deleteCluster`/`deleteAllClusters`), `resetForTesting`, and `WorkoutClusterRepository` mutation paths.
4. **Write targeted unit & Compose tests**:
   - Extend `WorkoutClusterCorridorScoringTest.kt` to verify: (a) `samplePolylineStations(workoutPolyline)` executes at most `1×` per `scoreClusters`/`suggestCluster` across `K = 25` clusters (and `0×` when previews are empty), (b) `PolyUtil.decode` is cached/reused across workouts (`1×` per cluster preview instead of `N × K`) and properly invalidated on cluster mutation (`updateCluster`/`deleteCluster`/`deleteAllClusters`/in-memory `previewPaths` change), (c) 100% identical floating-point similarity scores vs. uncached baseline, and (d) concurrent multi-threaded scoring + invalidation produces zero exceptions or stale scores.
   - Create `ClusterNamingDialogPathPreviewTest.kt` verifying: (a) `ClusterNamingDialog` renders `PathPreviewMap` across consecutive queue items with start/end/apex markers and updated bounds (under `LocalInspectionMode` + live `createComposeRule()`), (b) `createSensorMarker` caches non-null descriptors with zero duplicate `BitmapDescriptorFactory.fromBitmap` calls across consecutive queue remounts and never caches `null`, and (c) `ImportBackupTabsScreen` has zero direct `GoogleMap` instantiation.
5. **Verify, capture emulator evidence & close Stage 5**:
