## 1. Problem, Scope & Change-Request Impact Analysis
* **Problem / Root Cause**:
  1. **13 unreferenced legacy Screen `Fragment` wrappers**: All top-level navigation in `ATrainingTrackerApp.kt` runs on Jetpack Compose `NavHost` (including `PeriodsScreen` day-click routing since `ATT-8125`), yet 13 obsolete `*Fragment` classes (`PeriodsFragment`, `EquipmentFragment`, `RoutesFragment`, `WorkoutClustersFragment`, `TrackingTabsFragment`, `BackupRestoreFragment`, `StarredSegmentsFragment`, `DevicesTabbedContainerFragment`, `SportTypeListFragment`, `MapFragmentWithTrack`, `WorkoutSummariesTabbedFragment`, `ZoneSettingsFragment`, `WorkoutSummariesListFragment`) remain in `app/src/main/java` with zero live production callers (only unused imports in `MainActivityWithNavigation.kt` or dead cross-references among themselves).
  2. **9 orphaned `*SettingsDialogFragment` subclasses, `AppBottomSheetDialogFragment` & `ActivityTypeSelectionHelper`**: All 10 settings bottom sheets are rendered directly inside `ATrainingTrackerApp.kt`'s `ModalBottomSheet` via `SettingsBottomSheetType`, leaving `DisplaySettingsDialogFragment`, `DropboxSettingsDialogFragment`, `ExportSettingsDialogFragment`, `GoogleDriveSettingsDialogFragment`, `SearchSettingsDialogFragment`, `StravaSettingsDialogFragment`, `UnitsSettingsDialogFragment`, `ActivityTypeSelectionDialogFragment`, `AdvancedTuningDialogFragment`, `AppBottomSheetDialogFragment`, and `ActivityTypeSelectionHelper` completely unreferenced at runtime.
  3. **Dead fields/imports in `MainActivityWithNavigation.kt` & `DialogFragment` bridges around pure Compose dialogs**:
     * `MainActivityWithNavigation.kt` retains unused Fragment/DialogFragment imports, dead fields (`mFragment`, `mDrawerLayout`, `mStartAndNotResume`, `mAlreadyTriedToRequestDropboxToken`), dead `onSaveInstanceState` `putFragment`, and the legacy `StartOrResumeInterface` bridge.
     * `TrackingTabsScreen.kt` invokes `EditDeviceFragmentFactory.create(...)` (which wraps `EditDeviceDialog`'s `AppModalBottomSheet` inside a `DialogFragment`, creating a double window) and launches `StartOrResumeDialog` (`DialogFragment`) + `StartOrResumeInterface` despite pure Compose `StartOrResumeAlertDialog` already existing in `StartOrResumeDialog.kt`.
     * `MainActivityWithNavigation.showGPSDisabledAlertToUser()` instantiates legacy Java `GPSDisabledDialog` (`DialogFragment` + `AlertDialog.Builder`).
* **In-Scope / Out-of-Scope**:

## 2. Decision & Architecture Impact
* **Design Decision & Rationale**:
  * **Activity-Hosted Compose Dialog State (`MainActivityWithNavigation` + `ATrainingTrackerApp`)**: Match the existing pattern used by `antDialogState`, `firstJubileeCelebrationState`, and `garageNudgeState`: add `var showStartOrResumeDialogState: Boolean by mutableStateOf(false)` and `var showGpsDisabledDialog: Boolean by mutableStateOf(false)` on `MainActivityWithNavigation`, rendered directly in `ATrainingTrackerApp` via `StartOrResumeAlertDialog` and `GPSDisabledAlertDialog`. Single-source Activity state guarantees deduplication between `onResume()` `checkUnfinishedWorkout()` and `ControlNavigation.ShowRecoveryDialog`.
  * **Pure Compose `EditDeviceDialog` in `TrackingTabsScreen`**: Store `var editingDeviceId by rememberSaveable { mutableStateOf<Long?>(null) }` in `TrackingTabsScreen` (identical to `DevicesTabbedScreen`), set it on both `TabNavigationEvent.EditDevice` and `ControlNavigation.ToEditDevice`, and render `EditDeviceDialog(deviceId, onDismiss = { editingDeviceId = null })` as a sibling overlay. For isolated non-`MainActivityWithNavigation` hosts, `TrackingTabsScreen` also provides a pure Compose `StartOrResumeAlertDialog` fallback state for `ControlNavigation.ShowRecoveryDialog`.
  * **Pure Compose `GPSDisabledAlertDialog.kt`**: Material 3 `AlertDialog` with `Icons.Default.LocationOff` header icon, `R.string.gps_disabled_on_device` body, `Button(R.string.gps_goto_settings)` launching `Settings.ACTION_LOCATION_SOURCE_SETTINGS`, `TextButton(R.string.Cancel)`, and `DialogProperties(dismissOnBackPress = false, dismissOnClickOutside = false)` matching `GPSDisabledDialog.java` (`setCancelable(false)`).
* **SWE.2 Architecture / Files Touched**:
  * **Deleted (27 files)**: 13 `*Fragment.kt`, 9 `*SettingsDialogFragment.kt`, `AppBottomSheetDialogFragment.kt`, `ActivityTypeSelectionHelper.kt`, `EditDeviceFragmentFactory.kt`, `StartOrResumeInterface.java`, `GPSDisabledDialog.java`.
  * **Created (2 files)**: `GPSDisabledAlertDialog.kt`, `LegacyUiDecommissioningComposeTest.kt`.
  * **Modified (Production)**: `MainActivityWithNavigation.kt`, `ATrainingTrackerApp.kt`, `TrackingTabsScreen.kt`, `StartOrResumeDialog.kt`, `DevicesTabbedViewModel.kt` (KDoc), `AppModalBottomSheet.kt` (KDoc).
  * **Modified (Tests & Governance)**: `StartOrResumeDialogContractTest.kt`, `StartOrResumeDialogLayoutTest.kt`, `PeriodsNavigationFilterTest.kt`, `ModalBottomSheetDialogsIntegrityTest.kt`, `DropboxSettingsDialogTest.kt`, `AdvancedTuningModularityTest.kt`, `WorkoutSummariesTabbedScreenTest.kt`, `MainActivityWithNavigationInteropTest.kt`, `SourceTextReadingAuditContractTest.kt` + `app/source-reading-baseline.txt` (ratchet `105 -> 104`), `docs/architecture.md`, `docs/system/sysreq_live_tracking.md`.
