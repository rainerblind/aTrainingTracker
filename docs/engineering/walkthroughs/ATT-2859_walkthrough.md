## 1. Executive Summary

During Sprint 2026-42.4 review, commit `8e218312` was rejected because legacy multi-color sport and sensor icons had been replaced with generic monochrome Material Design icons, destroying the app's established visual identity. The commit was reverted on `sprint/2026-42.4` and bounced back to Analysis.

Ticket **ATT-2859** in Sprint 2026-42.5 implements a faithful, mathematically precise vector migration:
1. **Faithful Visual Redraw**: Re-created all 16 target sport and sensor icons as scalable Android XML VectorDrawables in root `app/src/main/res/drawable/` strictly preserving their multi-color geometry, badge layouts, and sRGB color profile:
   - `bsport_bike.xml`: Multi-color cyclist with black wheels/saddle (`#000000`), bold red bicycle frame (`#FF0000`), and blue aerodynamic rider (`#0000FF`).
   - `bsport_run.xml`: Distinctive blue stick-figure runner (`#0000FF`).
   - `bsport_other.xml`: Multi-color stopwatch with rich gold ring (`#FFC700`), red top crown button (`#FF0000`), green right button (`#008F00`), and dark blue left button (`#00008F`).
   - ANT+ sensor badges (`hr.xml`, `bike_spd.xml`, `bike_cad.xml`, `bike_speed_and_cadence.xml`, `bike_pwr.xml`, `run_spd.xml`, `temp.xml`): Black rounded-square background (`#000000`) with crisp white (`#FFFFFF`) glyphs and uppercase technical acronyms ("HR", "SPD", "CAD", "S & C", "PWR", "TEMP").
   - BLE sensor badges (`bt_hr.xml`, `bt_bike_spd.xml`, `bt_bike_cad.xml`, `bt_bike_speed_and_cadence.xml`, `bt_bike_pwr.xml`, `bt_run.xml`): Official Bluetooth blue rounded-square background (`#0A3D91`) with crisp white (`#FFFFFF`) glyphs and lowercase protocol text.
2. **Selective Raster Purge**: Safely purged 106 obsolete multi-density raster files (`.png`) across `drawable-ldpi/` through `drawable-xxxhdpi/` for the 16 migrated assets, dead `bsport_*_gray.png` files, and dead `btle_hr.png`, while retaining active non-migrated assets in density buckets.
3. **Tooling & Reproducibility**: Implemented `tools/generate_all_vectors.py` with `tools/requirements.txt` (`Pillow>=10.0.0`) and added provenance XML header comments linking each vector asset to its reference raster source.
4. **Technical Protocol Badge Emblem Invariant**: Documented invariant in `SportTypeSelector.kt` KDoc clarifying that technical acronyms in sensor badges represent universal technical emblems, while user-facing text is localized via `strings.xml`.
5. **DOM Contract Tests**: Authored `VectorAssetResolutionContractTest.kt` verifying XML schema, root vector element, viewport attributes, DOM element path fill colors, root tint omission, and pathData non-degeneracy (`length >= 10` and `M` commands).
6. **Clean-Room Verification**: Passed the full clean-room unit test suite (`./gradlew testDebugUnitTest`) with 100% pass rate.

## 2. Changes Implemented

### 2.1 Scalable Android XML VectorDrawables (`app/src/main/res/drawable/`)
16 scalable XML VectorDrawables generated in root `res/drawable/`:
- `bsport_bike.xml` (192x192 viewport, 3 path elements with `#000000`, `#FFFF0000`, `#FF0000FF`)
- `bsport_run.xml` (192x192 viewport, 1 path element with `#FF0000FF`)
- `bsport_other.xml` (192x192 viewport, 4 path elements with `#FFFFC700`, `#FFFF0000`, `#FF008F00`, `#FF00008F`)
- ANT+ Badges (`hr.xml`, `bike_spd.xml`, `bike_cad.xml`, `bike_speed_and_cadence.xml`, `bike_pwr.xml`, `run_spd.xml`, `temp.xml`): 96x96 viewport, black rounded-square background (`#FF000000`) and white foreground path (`#FFFFFFFF`).
- BLE Badges (`bt_hr.xml`, `bt_bike_spd.xml`, `bt_bike_cad.xml`, `bt_bike_speed_and_cadence.xml`, `bt_bike_pwr.xml`, `bt_run.xml`): 96x96 viewport, Bluetooth blue rounded-square background (`#FF0A3D91`) and white foreground path (`#FFFFFFFF`).

### 2.2 Provenance Header Comments
Each generated XML file includes an explicit provenance header:
```xml
<!--
  Generated by tools/generate_all_vectors.py from legacy reference raster asset.
  Source Reference: drawable-xxxhdpi/bsport_bike.png
  Invariant: Faithful multi-color vector geometry / technical protocol badge emblem (REQ-UI-375).
-->
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="24dp"
    android:height="24dp"
    android:viewportWidth="192"
    android:viewportHeight="192">
...
```

### 2.3 Technical Emblem Invariant Documentation (`SportTypeSelector.kt`)
Added architectural KDoc to `SportTypeSelector.kt`:
```kotlin
/**
 * Renders the sport type selection control for tracking workouts.
 *
 * Technical Protocol Badge Emblem Invariant:
 * The sport and sensor icons (such as [R.drawable.bsport_bike], [R.drawable.bsport_run],
 * and sensor badges with acronyms like "HR", "SPD", "CAD") are technical emblems defined as
 * density-independent vector drawables preserving exact visual multi-color geometry and badge designs.
 * While user-facing descriptive labels are localized via [R.string] entries across all 9 supported languages,
 * protocol and metric acronyms embedded directly in sensor badge emblems represent universal technical
 * standards and must remain unlocalized.
 *
 * @param currentSport Currently selected sport type.
 * @param onSportSelected Callback invoked when a sport type item is selected.
 * @param modifier Optional modifier for styling and layout.
 */
```

### 2.4 Purge of Superseded Rasters
Purged 106 legacy raster PNGs across density folders:
- 16 migrated icons across `drawable-mdpi`, `-hdpi`, `-xhdpi`, `-xxhdpi`, `-xxxhdpi`, `drawable/`
- Dead `bsport_bike_gray.png`, `bsport_run_gray.png`, `bsport_other_gray.png`
- Dead `btle_hr.png`
- Retained all non-migrated drawables (`arrowhead.png`, `connect_with_strava.png`, `stat_sys_battery_*.png`, etc.).

### 2.5 Tooling & Contract Tests
- `tools/requirements.txt`: Added `Pillow>=10.0.0` for environment reproducibility.
- `tools/generate_all_vectors.py`: Standalone extraction script located in root `tools/` (excluded from Android build packaging).
- `VectorAssetResolutionContractTest.kt`: Added DOM inspection, path fill color verification, root tint omission verification, and `testAllVectorPaths_haveNonTrivialPathData()`.
- `SportTypeSelectorContractTest.kt`: Updated assertions to check vector XML resolution without legacy PNG references.
