* *Scope Boundary*: Modifications are tightly constrained to `TrackingTabsViewModel.kt`, `TrackingTabsScreen.kt`, and new unit test suite `TrackingTabsViewModelTest.kt`.

h3. 2. State Machine & Edge Detection Soundness
* *Rising-Edge Guard*: The planned guard (`previousMode != null && previousMode != TRACKING && previousMode != PAUSED && mode == TRACKING`) guarantees that navigation occurs exclusively when transitioning into `TRACKING` from `READY` (or `IDLE`).
* *Cold Start & Rotation Protection*: Initializing when tracking is active (`previousMode == null`) does not emit navigation, protecting active sessions from tab resets.
* *Pause/Resume Neutrality*: Transitioning from `PAUSED` to `TRACKING` does not emit navigation, preserving the athlete's active tab.

h3. 3. Safety Valves & Invariants

* *INV-UI-03*: Page 0 Control tab remains accessible via left-swipe or tab tap.
* *Deadlock Prevention*: Smooth animation is guarded by `try ... catch` against unmounted pager state.
